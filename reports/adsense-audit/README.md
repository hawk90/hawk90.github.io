double-check-*는 비교/감사 시점 기록이다. 그 안의 “기존 보고서 수정 없음”은 독립 검토 당시를 뜻하며 이후 이번 정리에서 published-* 정본을 갱신했다. coverage JSON의 scores는 원래 평가 기준값이므로 현재 점수표로 사용하지 않는다. coverage 생성기도 과거 커밋에서 기준값을 읽어 비교 기준을 유지한다.

Modern Embedded Recipes 152편 평가는 modern-embedded-recipes-loop-* 별도 범위다. 신규1편·평가 후 변경59편은 coverage의 후속 목록을 따른다. double-check-evidence-*는 일부 묶음의 초벌 근거 기록이며 최종 점수표가 아니다. 기존 미커밋 embedded-performance-engineering-loop-01.md도 비교용 부분평가로 보존했다.

원문·발행 상태·URL은 변경하지 않았다. 삭제·병합·추가 발행은 실행하지 않았다. 모든 현재 점수는 잠정이다.
