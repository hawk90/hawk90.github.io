## 검사 포인트

- QEMU CXL Type 3 에뮬레이션 글은 노트북 환경에서 실제 재현 가능한 명령·버전·검증 결과가 있는지 확인한다.
- Linux CXL 드라이버 글은 `cxl_pci`, `cxl_core`, region, DAX 계층 설명이 실제 커널 버전과 연결되는지 확인한다.
- 두 글 모두 CXL 표준·Linux 커널·QEMU의 빠른 변경 영향을 받으므로, 작성 시점·버전·지원 범위를 명확히 하는지 확인한다.
- 외부 링크가 없다는 자동 신호만으로 출처 부재를 확정하지 않고, CXL 공식 자료·QEMU 문서·Linux 커널 문서가 인용 또는 명시되는지 확인한다.
- 에뮬레이션 동작, region 생성, DAX 사용 가능 여부와 같은 주장은 환경 조건과 관찰 결과를 함께 기록한다.
- Abseil·Folly와 달리 Modern Embedded Recipes는 이 단계에서 일괄 제외하지 않는다.
