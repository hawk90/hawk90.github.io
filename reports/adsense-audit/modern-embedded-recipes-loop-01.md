# Modern Embedded Recipes — 루프 01 (seriesOrder 0~9)

> 분석 단계: 루브릭 기반 1차 정성 평가  
> 대상: 공개 글 10편  
> 기준: [AdSense 공개 글 평가 루브릭](../../docs/adsense-audit/rubric.md)  
> 상태: 검사·분류 보고서 완료 — 원문 수정·비공개 처리 없음

## 결론

이번 루프의 10편은 모두 독자가 이해하기 쉬운 문제 상황과 일관된 기술 설명 구조를 갖고 있다. 특히 각 글에 `어떤 상황에서 쓰나`, `측정 / 비교`, `자주 보는 함정`, `정리`가 있어 단순 API 목록보다는 실전 지향성이 보인다.

반면 다음 공통 위험이 있다.

- 9개 본문 글이 거의 동일한 8개 섹션 템플릿을 사용한다.
- 9개 본문 글에서 공개 외부 출처 URL이 추출되지 않았다. 내부 관련 링크와 출처 표기는 별도 확인이 필요하다.
- 본문 산문은 7편이 2,500자 미만이다. Google의 공식 분량 기준은 아니지만, 코드·표를 제외한 설명만으로 독창성과 완결성이 충분한지 검토해야 한다.
- UART·SPI·I2C·PWM 글은 실전 신호가 상대적으로 약하다. 실제 보드·계측기·파형·실패 조건이 있는지 확인해야 한다.

따라서 이번 루프의 기본 판정은 `보강`이며, 허브인 `00-preface`는 독립 글이 아니라 시리즈 안내 페이지로 `유지`하는 것이 적절하다. 현재 단계에서 draft 전환이나 삭제를 결정할 근거는 부족하다.

## 공통 평가

### 강점

- 제목이 다루는 하드웨어·신호 주제가 본문과 대체로 일치한다.
- `어떤 상황에서 쓰나`가 있어 초보적인 정의만 나열하지 않고 사용 맥락을 제시한다.
- `측정 / 비교`와 `자주 보는 함정`은 AdSense의 “사용자가 다시 방문할 이유”를 만들 수 있는 좋은 골격이다.
- 코드보다 산문이 짧지 않아 코드만 던지는 형태는 아니다.
- 시리즈 전체에서 디지털 신호 → 인터페이스 → 변환기 → PWM으로 이어지는 학습 흐름이 자연스럽다.

### 보강해야 할 공통 요소

- 보드·MCU·측정 장비·클럭 조건·전원 조건을 글마다 구체화한다.
- “측정 / 비교” 절에는 실제 측정값이나 최소한 재현 가능한 측정 절차를 넣는다.
- UART·SPI·I2C의 설명은 서로 겹치므로, 각 버스의 선택 기준과 실패 파형을 차별화한다.
- 외부 1차 자료를 연결하되, 링크를 추가하는 것만으로 독창성이 생긴다고 보지 않는다. 자료를 어떻게 해석했는지가 본문에 있어야 한다.
- 공통 설명은 시리즈 허브로 옮기고, 개별 글에는 해당 주제만의 판단 기준을 남긴다.

## 점수 해석

예비 점수의 합계는 A~G 100점 기준을 유지했다. 낮은 점수의 주된 원인은 글자 수 자체가 아니라 다음 세 가지다.

1. 실전 조건과 측정 결과가 일반적인 설명보다 약함
2. 외부 1차 자료와 작성자의 해석 연결이 확인되지 않음
3. 9편 모두 같은 구조라 시리즈 전체가 cookie-cutter처럼 보일 가능성

이 점수만으로 글을 삭제하지 않는다. 기술 글은 코드와 회로 설명 자체가 가치가 될 수 있으므로, 다음 루프에서 실제 예제·파형·수치·실패 조건을 확인한 뒤 점수를 확정한다.
