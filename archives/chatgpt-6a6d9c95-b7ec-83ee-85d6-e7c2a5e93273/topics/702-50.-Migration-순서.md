# 50. Migration 순서

현재 구조에서 위 구조로 한 번에 옮기지 않는다.

## 1단계

```text
Content Type
Content Status
Topic Registry
```

만 추가한다.

기존 UI는 그대로 둔다.

## 2단계

Manifest와 Publication Policy를 도입한다.

검색·Sitemap 중 하나만 먼저 연결한다.

## 3단계

홈 Featured와 Topic Hub를 Domain Query로 전환한다.

## 4단계

관련 글·검색·RSS·Sitemap을 동일 Manifest에 통합한다.

## 5단계

기존 중복 helper와 parser를 제거한다.
