# 2주 계획: 기반과 대표 콘텐츠

첫 2주의 목표는 UI를 크게 바꾸는 것이 아니다.

> 사이트가 무엇을 대표하고 어떤 글을 신뢰할 것인지 결정한다.

---

## Sprint 1 — 1주차: 정책과 데이터 구조

### 목표

A~H 전체 작업이 의존하는 최소 규칙을 확정한다.

### 작업 1. 저장소 목적 선언

관련 항목:

```text
A-01
```

결과:

```text
이 저장소의 1차 목적은 Hawk 기술 지식베이스 운영이다.
범용 테마 기능은 실제 콘텐츠 운영 요구보다 우선하지 않는다.
```

### 작업 2. 콘텐츠 상태와 타입 확정

관련 항목:

```text
C-01
C-02
C-05
```

상태:

```text
current
needs-review
historical
superseded
archived
```

타입:

```text
guide
concept
debug-note
experiment
source-walkthrough
reference
```

### 작업 3. Topic registry 생성

초기 Topic:

```text
cpp
linux-systems
firmware-bootloader
gpu-cuda
pcie-cxl
```

필요하면 FPGA를 별도 Topic으로 둘 수 있지만, 초기 구조에서는 Firmware나 PCIe 관련 하위 주제로 두고 실제 문서 분포를 본다.

### 작업 4. Publication Policy 작성

관련 항목:

```text
E-04
H-08
```

각 상태가 다음에 포함되는지 정의한다.

```text
render
search
sitemap
rss
hub
featured
ads
```

### 작업 5. 최소 schema 정의

대표 문서부터 적용할 필드:

```yaml
type:
topic:
status:
updated:
lastVerified:
```

선택:

```yaml
testedWith:
prerequisites:
next:
related:
supersedes:
```

### 작업 6. 기본 validation 구현

관련 항목:

```text
H-02
H-05
```

우선 검사:

```text
enum
Topic 존재
날짜 형식
문서 ID
relation target
featured 상태
```

### 1주차 완료 조건

```text
[ ] 저장소 목적 선언
[ ] 상태 5종 정의
[ ] 타입 6종 정의
[ ] Topic registry 5개
[ ] Publication Policy 문서화
[ ] 최소 schema 적용 가능
[ ] 기본 content validation 실행
```

## Sprint 2 — 2주차: 대표 문서 선정과 검증

### 목표

사이트 전체를 대표할 문서 20개를 선정하고, 그중 5개를 바로 공개 가능한 상태로 만든다.

### 작업 1. 대표 문서 20개 선정

권장 배분:

| Topic | 목표 수 |
|---|---:|
| PCIe & CXL | 5 |
| Firmware & Bootloader | 4 |
| C++ | 4 |
| GPU & CUDA | 4 |
| Linux & Systems | 3 |

문서 수보다 역할 다양성이 중요하다.

```text
Guide
Concept
Source Walkthrough
Debug Note
Experiment
```

가 적절히 섞여야 한다.

### 작업 2. 대표 문서 감사표 작성

필드:

```text
문서 ID
Topic
Type
Status
현재 검색 의도
중복 후보
환경 필요
보완 작업
Featured 가능 여부
```

### 작업 3. 첫 5개 문서 보완

우선 조건:

```text
기술적으로 비교적 유효함
수정량이 작음
사이트 전문성을 보여줌
다른 문서의 시작점임
```

각 글에서 수행:

```text
제목
description
type/topic/status
환경·버전
사실·관찰·가설 구분
한계
상위 Hub
다음 문서
```

### 작업 4. 구판 노출 방지

명백한 구판은 우선:

```text
needs-review
historical
superseded
```

중 하나로 지정하고 Featured 후보에서 제외한다.

### 2주차 완료 조건

```text
[ ] 대표 문서 20개 감사표
[ ] 20개 모두 type/topic/status 지정
[ ] 최소 5개 current 검증
[ ] 첫 Featured 후보 4~5개 확정
[ ] 명백한 구판의 Featured 노출 차단
```
