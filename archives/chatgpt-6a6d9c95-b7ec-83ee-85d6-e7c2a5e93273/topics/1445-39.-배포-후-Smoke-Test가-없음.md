# 39. 배포 후 Smoke Test가 없음

Deploy Job 성공은 실제 URL이 정상이라는 뜻이 아니다.

배포 후 최소한 다음을 확인한다.

```text
홈 200
대표 Article 200
Topic Hub 200
Search Index 200
CSS·JS 대표 자산 200
404 동작
Sitemap 200
RSS 200
```

GitHub Pages 반영 지연이 있을 수 있으므로 무한 재시도가 아니라 제한된 Retry 정책을 둔다.
