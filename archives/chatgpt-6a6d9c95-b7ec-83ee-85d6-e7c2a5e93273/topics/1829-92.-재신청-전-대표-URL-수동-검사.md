# 92. 재신청 전 대표 URL 수동 검사

자동 점수보다 직접 확인한다.

각 대표 URL에서 질문한다.

```text
이 페이지 하나만 검색 결과에서 봐도 가치가 있는가?
제목이 약속한 질문을 충분히 해결하는가?
직접 경험 또는 독창적 분석이 있는가?
현재 상태와 환경을 알 수 있는가?
다음 읽기 경로가 있는가?
광고가 없어도 완성된 페이지인가?
```

10~20개 대표 URL 모두 만족하도록 한다.
