# 31. 실제 경험과 학습 정리를 구분하지 않음

모든 글이 같은 어조로 쓰이면 독자는 다음을 구분하기 어렵다.

```text
직접 구현
직접 실험
회사에서 본 문제
공식 문서 학습
추론
AI 보조 정리
```

## 신뢰도 강화 표기

```text
직접 확인
소스코드 분석
공식 사양 기반
실험 결과
가설
학습 정리
```

이 구분은 E-E-A-T라는 용어를 페이지마다 표시하자는 뜻이 아니다.

독자가 주장의 근거를 판단할 수 있게 하자는 것이다.
