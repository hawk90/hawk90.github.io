# 16. Metadata Migration과 본문 수정 분리

한 문서라도 가능하면 두 단계로 나눈다.

## 1단계

```text
ID
Topic
Type
Status
Description
Relations
```

추가.

## 2단계

```text
기술 내용 재검증
구조 재작성
환경 추가
그림·표 개선
```

Metadata 적용과 본문 의미 변경을 분리하면 Diff 검토가 쉬워진다.
