# 4. GitHub Actions 권한을 기본값에 의존

Workflow에 명시적인 권한이 없으면 Repository 설정이나 GitHub 기본 정책 변화에 영향을 받을 수 있다.

예:

```yaml
permissions:
  contents: read
  pages: write
  id-token: write
```

각 Job에 정말 필요한 권한만 준다.

Build Job:

```yaml
permissions:
  contents: read
```

Deploy Job:

```yaml
permissions:
  pages: write
  id-token: write
```

모든 Job에 다음을 주지 않는다.

```text
contents: write
actions: write
pull-requests: write
```
