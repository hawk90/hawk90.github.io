# 3. 공개 사이트와 편집 도구의 물리적 분리

좋은 경계:

```text
src/
→ 공개 사이트

scripts/
→ 로컬·CI 편집 도구

reports/
→ 내부 감사 결과
```

피해야 할 구조:

```text
src/pages/admin/
src/components/editor/
src/stores/content-admin.ts
src/api/save-post.ts
```

정적 Git 기반 블로그에서 관리자 화면이 꼭 필요한지 먼저 의심해야 한다.
