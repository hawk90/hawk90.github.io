# 54. Visual Snapshot 범위가 너무 큼

전체 페이지 Full-page Screenshot은 긴 Article에서 작은 내용 변경에도 거대한 Diff를 만든다.

선택:

```text
Header 영역
대표 Code Block
표
Status Notice
Search Dialog
```

처럼 위험 영역을 부분 Capture한다.

전체 페이지 Snapshot은 핵심 Canary에 제한한다.
