# 12. 신규 시리즈 제안

이 Hub에는 "Kernel Internals" 시리즈를 만들면 좋다.

예시:

```text
Kernel Internals #1
start_kernel()부터 init까지

Kernel Internals #2
task_struct 분석

Kernel Internals #3
Page Table Walk

Kernel Internals #4
CFS Scheduler

Kernel Internals #5
IRQ Subsystem

Kernel Internals #6
SLAB Allocator

Kernel Internals #7
VFS

Kernel Internals #8
PCI Core
```

이런 연재는 검색 유입뿐 아니라 **사이트의 정체성**을 만드는 데도 도움이 된다.
