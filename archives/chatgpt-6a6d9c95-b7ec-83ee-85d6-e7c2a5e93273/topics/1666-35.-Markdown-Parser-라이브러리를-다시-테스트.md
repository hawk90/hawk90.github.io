# 35. Markdown Parser 라이브러리를 다시 테스트

GFM 표가 기본적으로 렌더되는지 라이브러리 수준까지 검사하기보다, 현재 설정에서 필요한 대표 Markdown Fixture가 올바른 HTML을 만드는지 확인한다.

즉:

```text
라이브러리 기능
```

이 아니라:

```text
현재 Pipeline 계약
```

을 테스트한다.
