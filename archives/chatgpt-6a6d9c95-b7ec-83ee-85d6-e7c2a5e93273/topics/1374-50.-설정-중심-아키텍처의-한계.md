# 50. 설정 중심 아키텍처의 한계

모든 UI를 거대한 JSON·YAML로 정의하면 코드 수정 없이 화면을 바꿀 수 있어 보인다.

```yaml
sections:
  - type: hero
  - type: grid
  - type: carousel
  - type: articles
```

하지만 결국 자체 CMS와 렌더러를 만든 셈이다.

컴파일 타임 타입 안정성과 IDE 탐색도 약해진다.

페이지 종류가 소수라면 TypeScript와 Astro 컴포넌트가 더 단순하다.
