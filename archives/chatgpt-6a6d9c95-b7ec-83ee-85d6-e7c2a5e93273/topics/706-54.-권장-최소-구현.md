# 54. 권장 최소 구현

처음에는 다음 파일만 있어도 충분하다.

```text
src/domain/
├── content-model.ts
├── content-schema.ts
├── manifest.ts
├── publication-policy.ts
├── topic-registry.ts
├── curation.ts
└── queries.ts
```

그리고:

```text
src/components/
├── home/
├── topic/
└── content/
```

파일을 수십 개로 쪼개는 것은 실제 코드가 커진 뒤에 해도 된다.
