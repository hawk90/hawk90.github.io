# 77. Heading ID 안정성

Heading 문구를 수정하면 자동 생성 Anchor가 바뀔 수 있다.

외부 링크가 많은 중요 Heading은 명시적 ID를 고려한다.

```markdown
## BAR 크기 탐색 {#bar-size-probing}
```

모든 Heading에 수동 ID를 강제할 필요는 없다.

대표 Reference·Guide의 자주 인용되는 섹션부터 적용한다.
