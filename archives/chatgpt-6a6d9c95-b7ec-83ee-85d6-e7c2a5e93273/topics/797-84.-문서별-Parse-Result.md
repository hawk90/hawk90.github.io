# 84. 문서별 Parse Result

```ts
export interface ContentParseResult {
  headings: ContentHeading[];
  links: ContentLink[];

  codeBlocks: {
    language: string;
    role?: string;
    lineCount: number;
  }[];

  symbols: string[];
  errorMessages: string[];
}
```

이 결과 중 Manifest에 필요한 것만 넣는다.

대형 code 원문은 저장하지 않는다.
