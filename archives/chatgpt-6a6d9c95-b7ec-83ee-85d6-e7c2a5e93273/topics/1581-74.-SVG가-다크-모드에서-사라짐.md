# 74. SVG가 다크 모드에서 사라짐

SVG 내부에 검은색 선과 흰 배경이 하드코딩돼 있으면 다크 모드에서 선이 보이지 않거나 밝은 직사각형이 튄다.

선택:

```text
SVG 자체에 명확한 배경 포함
CSS Variable 기반 SVG
Light·Dark 자산 분리
```

복잡도를 보고 결정한다.

다이어그램은 테마와 상관없이 읽히는 독립 배경을 갖는 것도 좋은 방법이다.
