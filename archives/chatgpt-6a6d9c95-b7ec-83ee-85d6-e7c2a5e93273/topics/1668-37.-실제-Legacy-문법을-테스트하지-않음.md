# 37. 실제 Legacy 문법을 테스트하지 않음

새 문법만 테스트하면 기존 500개 글이 Renderer 업데이트에서 깨질 수 있다.

대표 Legacy 패턴을 Fixture로 보존한다.

```text
기존 Raw HTML
옛 Code Fence 언어명
과거 Image Path
오래된 Front Matter
```

Legacy 지원을 제거할 때 해당 Fixture와 테스트도 함께 삭제한다.
