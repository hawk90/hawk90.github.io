# 6. Semantic Token과 Primitive Token 혼동

Primitive:

```css
--gray-100
--gray-800
--blue-500
```

Semantic:

```css
--text-primary
--surface-muted
--border-subtle
--link
```

컴포넌트가 `--gray-700`을 직접 사용하면 다크 모드에서 의미가 깨질 수 있다.

권장:

```text
Palette
→ Semantic Token
→ Component
```

Component는 가능한 한 의미 Token을 사용한다.
