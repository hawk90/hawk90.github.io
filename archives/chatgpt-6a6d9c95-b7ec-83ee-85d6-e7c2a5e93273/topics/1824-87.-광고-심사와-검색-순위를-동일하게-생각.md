# 87. 광고 심사와 검색 순위를 동일하게 생각

두 시스템은 관련된 품질 원칙을 공유할 수 있지만 동일한 판정 시스템은 아니다.

```text
검색 색인됨
≠
AdSense 승인

검색 유입 있음
≠
모든 페이지 광고 적합
```

Google AdSense는 별도의 프로그램 정책과 승인 기준을 적용하며 신청을 거절할 권리를 명시한다. citeturn517910search8turn517910search41

따라서:

```text
검색 결과에 나오니 AdSense도 승인돼야 한다
```

라고 볼 수 없다.
