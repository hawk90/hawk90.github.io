# 72. Layout 컴포넌트

```text
ArticleLayout.astro
├── Breadcrumbs
├── ArticleHeader
├── StatusNotice
├── ArticleSummary
├── PrerequisiteNotice
├── ArticleToc
├── ArticleBody
├── TestedEnvironment
├── EvidenceList
├── RevisionHistory
├── ArticleRelations
├── ArticleFeedback
└── CommentsLoader
```

모든 하위 컴포넌트를 반드시 별도 파일로 분리할 필요는 없다.

반복되거나 독립적으로 복잡한 것만 분리한다.
