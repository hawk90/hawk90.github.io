# 6. Feature Flag 남용

다음과 같은 Flag가 쌓이기 쉽다.

```text
enableNewSearch
enableLegacySearch
enableTopicV2
enableOldHome
enableAdminBeta
enableOgV3
```

Feature Flag는 전환 기간에는 유용하다.

하지만 개인 정적 사이트에서 영구적으로 남으면 가능한 실행 경로가 폭발한다.

```text
2개 Flag → 4개 조합
5개 Flag → 32개 조합
10개 Flag → 1,024개 조합
```

모든 조합을 실제로 테스트하지도 않는다.

### 규칙

각 Flag에는 제거 조건이 있어야 한다.

```ts
interface TemporaryFeatureFlag {
  enabled: boolean;
  removeAfter: string;
  replacementIssue: string;
}
```

개인 프로젝트라면 더 간단히:

```text
전환 완료
→ 구 구현 삭제
→ Flag 삭제
```

가 낫다.
