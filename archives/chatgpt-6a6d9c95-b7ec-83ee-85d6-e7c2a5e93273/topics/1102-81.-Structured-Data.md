# 81. Structured Data

Article 또는 BlogPosting을 실제 표시 정보와 일치시킨다.

```text
headline
description
datePublished
dateModified
author
mainEntityOfPage
image
```

`lastVerified`는 별도 사용자 표시 정보이며 `dateModified`를 대체하지 않는다.

Debug Note를 자동으로 `HowTo`로 표시하지 않는다.
