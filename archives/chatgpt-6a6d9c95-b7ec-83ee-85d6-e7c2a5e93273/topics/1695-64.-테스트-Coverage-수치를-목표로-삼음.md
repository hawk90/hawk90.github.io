# 64. 테스트 Coverage 수치를 목표로 삼음

라인 Coverage 90%를 채우기 위해 중요하지 않은 Getter와 Mapping을 테스트할 수 있다.

반대로 Markdown Plugin·배포 Artifact 같은 중요한 영역은 코드 Coverage에 잘 나타나지 않는다.

중요한 것은:

```text
핵심 불변조건이 테스트됐는가
과거 회귀가 재발하지 않는가
실제 사용자 경로가 보호되는가
```

이다.

Coverage는 미검사 영역을 찾는 보조 도구다.
