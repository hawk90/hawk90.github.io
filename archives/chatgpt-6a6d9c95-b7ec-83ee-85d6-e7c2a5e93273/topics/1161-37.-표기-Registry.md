# 37. 표기 Registry

중앙 Terminology Registry를 문서 편집에도 활용한다.

예:

```text
MSI-X
```

를 공식 표기로 사용하고:

```text
MSIX
MSI X
```

는 검색 Alias로만 유지한다.

표기 drift 예:

```text
DeviceTree
Device Tree
device-tree
DT
```

문맥에 맞는 대표 표기를 정한다.
