# 12. 열두 번째 핵심 안티패턴

## Optional Feature Permanence  
### 실험 기능이 영구 유지 대상이 됨

개인 프로젝트에서는 기능을 빠르게 실험할 수 있다.

- Zen mode
- 코드 테마 전환
- 제목 morph
- 관리자 편집기
- Newsletter
- Resume
- 인쇄 모드

문제는 한 번 공개된 기능을 삭제하기 어려워진다는 점이다.

### 발생하는 일

- 사용자는 거의 없지만 코드 유지
- 삭제하면 회귀처럼 느껴짐
- 설정과 문서가 남음
- dependency가 제거되지 않음
- 테스트 범위 증가
- 핵심 기능 개선 시간이 줄어듦

### 기능 유지 기준

기능마다 다음을 기록하면 좋다.

```text
목적
실사용 여부
운영 비용
의존성
삭제 조건
```

예:

```text
기능: 런타임 코드 테마 변경
목적: 독자 취향
실사용 측정: 없음
비용: CSS/HTML 증가
삭제 조건: 3개월 사용률 1% 미만
```

개인 블로그라 꼭 분석 이벤트를 모두 수집할 필요는 없다. 다만 적어도 “왜 유지하는가”는 설명할 수 있어야 한다.
