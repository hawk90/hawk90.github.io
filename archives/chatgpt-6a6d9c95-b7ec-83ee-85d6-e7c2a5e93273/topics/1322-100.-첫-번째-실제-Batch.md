# 100. 첫 번째 실제 Batch

가장 추천하는 시작 단위는 다음이다.

```text
PCIe & CXL 관련 문서 15개
```

구성:

```text
대표 Guide 후보 3개
Concept 후보 4개
Debug Note 3개
Source Walkthrough 2개
Historical 후보 2개
중복 후보 1개 묶음
```

실행:

```text
1. 기존 URL 전부 고정
2. ID·Topic·Type 후보 작성
3. Status 수동 결정
4. 대표 3개만 기술 재검증
5. Debug Note를 Concept에 연결
6. Historical 환경 명시
7. Hub의 Start Here와 Featured에 연결
8. 검색 Golden Query에 PCIe 검색어 추가
```

이 Batch가 완료되면 나머지 Topic에도 같은 방법을 반복할 수 있다.
