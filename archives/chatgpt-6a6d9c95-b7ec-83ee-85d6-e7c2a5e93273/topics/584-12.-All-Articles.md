# 12. All Articles

이 영역은 자동 생성해도 된다.

## 기본 필터

```text
topic === "pcie-cxl"
status !== "archived"
status !== "superseded"
```

Historical은 별도 그룹으로 분리한다.

## 그룹

```text
Guides & Concepts
Source Walkthroughs
Debug Notes
Experiments
References
Historical
```

## 정렬

### 일반 그룹

```text
수동 우선순위
→ updated 내림차순
```

### Historical

```text
대상 버전 또는 게시일 내림차순
```

단순 전체 최신순 하나로 섞지 않는다.
