# 92. Legacy Fallback Description

자동 생성된 Description을 검색엔진에 무조건 사용하기보다 다음을 고려한다.

```text
기존 Description 있음
→ 사용

없음
→ 안전한 짧은 Excerpt 후보

후보 품질 낮음
→ 사이트 공통 설명보다 문서별 최소 문장 생성 검토
```

대표 문서만큼 강하게 검수하지 않더라도 빈 Description보다는 개선될 수 있다.
