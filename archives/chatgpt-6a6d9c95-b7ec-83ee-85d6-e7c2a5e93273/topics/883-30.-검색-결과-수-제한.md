# 30. 검색 결과 수 제한

처음부터 결과 100개를 보여주지 않는다.

권장:

```text
초기 10개
더 보기 또는 최대 30개
```

검색어가 넓으면 Topic Hub를 먼저 제안한다.

예:

```text
검색어: CUDA
```

```text
먼저 둘러보기
GPU & CUDA Topic Hub

검색 결과
1. CUDA 실행 모델
2. CUDA Memory Hierarchy
...
```
