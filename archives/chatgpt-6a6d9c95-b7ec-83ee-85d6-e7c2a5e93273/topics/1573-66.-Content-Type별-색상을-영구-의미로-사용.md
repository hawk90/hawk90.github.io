# 66. Content Type별 색상을 영구 의미로 사용

타입이 늘거나 색이 부족해지면 의미 체계가 깨진다.

```text
Guide
Concept
Debug
Experiment
Source
Reference
Historical
Status
```

타입과 상태가 모두 색상을 요구하면 충돌한다.

권장:

```text
Type
→ Text Label 중심

Status
→ 상태 Notice와 보조 색상

Interaction
→ Accent Color
```
