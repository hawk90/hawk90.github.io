# 77. 회사 내부 경험 정리

실무 경험이 강점이지만 다음은 제거·일반화해야 한다.

```text
회사명
내부 프로젝트명
Hostname
Repository URL
고객명
미공개 설계
계약 정보
내부 성능 수치
```

기술적 패턴만 남긴다.

예:

```text
사내 FPGA 서버 bm09
```

대신:

```text
CentOS 7.9 기반 FPGA Build Host
```

처럼 일반화한다.
