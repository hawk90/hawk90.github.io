# 8. 배포 환경 이름이 없음

GitHub Environment를 사용하면 Production 배포 상태와 URL을 명시적으로 관리할 수 있다.

```yaml
environment:
  name: github-pages
  url: ${{ steps.deployment.outputs.page_url }}
```

이점:

```text
어떤 Commit이 현재 배포됐는지 추적
배포 상태 확인
필요한 경우 보호 규칙 적용
```

개인 사이트에 복잡한 승인자는 필요 없지만 배포 이력 자체는 유용하다.
