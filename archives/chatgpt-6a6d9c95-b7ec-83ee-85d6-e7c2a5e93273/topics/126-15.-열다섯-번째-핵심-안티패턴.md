# 15. 열다섯 번째 핵심 안티패턴

## No Content Deprecation Strategy  
### 글은 추가되지만 사라지지 않음

기술 블로그는 시간이 지나면 정보가 낡는다.

하지만 일반적인 운영은 다음과 같다.

```text
새 글 작성
새 글 작성
새 글 작성
```

기존 글은 거의 그대로 남는다.

### 결과

- 오래된 명령
- 사라진 API
- 버전이 다른 글끼리 충돌
- 같은 주제의 구판과 신판 공존
- 사용자가 어느 글을 믿어야 할지 모름
- Google이 대표 문서를 판단하기 어려움

### 필요한 상태 모델

```text
draft
current
needs-review
historical
superseded
archived
```

### 예

```yaml
status: superseded
supersededBy: /posts/new-cuda-stream-guide/
```

기존 URL은 유지하되 상단에 명확히 표시한다.

```text
이 문서는 CUDA 11.8 기준의 이전 자료입니다.
현재 가이드는 여기에서 확인하세요.
```

삭제보다 연결된 폐기가 중요하다.
