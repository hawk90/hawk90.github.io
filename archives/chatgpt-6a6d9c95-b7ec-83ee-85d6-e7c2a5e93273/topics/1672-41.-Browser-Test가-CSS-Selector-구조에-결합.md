# 41. Browser Test가 CSS Selector 구조에 결합

나쁜 예:

```ts
page.locator(
  ".header > div:nth-child(2) > button"
);
```

DOM 구조를 조금만 바꿔도 깨진다.

권장 Selector:

```text
Role
Accessible Name
Label
Stable Test ID가 정말 필요한 곳
```

예:

```ts
page.getByRole(
  "button",
  { name: "검색" },
);
```

접근 가능한 Selector를 사용하면 Accessibility 검증도 함께 된다.
