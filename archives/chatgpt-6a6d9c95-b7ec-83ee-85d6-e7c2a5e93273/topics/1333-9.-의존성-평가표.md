# 9. 의존성 평가표

각 주요 패키지를 다음 기준으로 평가한다.

| 기준 | 질문 |
|---|---|
| 실제 사용 | 현재 Production에서 사용되는가 |
| 대체 가능 | 플랫폼 기본 기능으로 대체 가능한가 |
| 번들 영향 | Client JavaScript에 들어가는가 |
| 빌드 영향 | 모든 문서를 처리하는가 |
| 유지 상태 | 현재도 관리되는가 |
| 종속성 | 하위 패키지를 많이 끌고 오는가 |
| 제거 비용 | 제거했을 때 기능 손실이 큰가 |
