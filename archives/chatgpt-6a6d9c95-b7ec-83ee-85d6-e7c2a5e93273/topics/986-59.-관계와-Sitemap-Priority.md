# 59. 관계와 Sitemap Priority

Sitemap의 `priority`와 `changefreq`는 현대 검색엔진에서 큰 의미가 없거나 무시될 수 있으므로, 관계 그래프 점수를 Sitemap priority에 반영하는 복잡한 시스템은 만들 필요가 없다.

중요한 것은:

```text
canonical URL
정확한 lastmod
indexable 문서만 포함
```

이다.
