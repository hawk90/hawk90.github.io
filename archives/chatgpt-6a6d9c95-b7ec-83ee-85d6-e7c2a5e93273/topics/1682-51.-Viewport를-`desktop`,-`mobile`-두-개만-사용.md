# 51. Viewport를 `desktop`, `mobile` 두 개만 사용

기술 문서의 문제는 중간 폭에서 자주 발생한다.

```text
TOC가 들어가기에는 좁음
모바일 Menu로 바뀌기에는 넓음
카드 3열이 깨짐
```

대표 Viewport:

```text
좁은 모바일
넓은 모바일
작은 노트북
넓은 데스크톱
```

중 실제 Breakpoint 경계 하나를 반드시 포함한다.
