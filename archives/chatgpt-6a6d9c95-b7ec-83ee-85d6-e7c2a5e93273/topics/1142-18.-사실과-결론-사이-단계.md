# 18. 사실과 결론 사이 단계

권장 구조:

```text
관찰
→ 해석
→ 결론
→ 한계
```

예:

```text
관찰:
BAR2 mmap은 성공했지만 모든 값이 0xffffffff였다.

해석:
주소 매핑 자체보다 장치 내부 Controller 상태 문제일 가능성이 있다.

결론:
mmap 성공만으로 장치 내부 메모리가 준비됐다고 판단하면 안 된다.

한계:
DDR Controller의 실제 상태 Register는 확인하지 못했다.
```
