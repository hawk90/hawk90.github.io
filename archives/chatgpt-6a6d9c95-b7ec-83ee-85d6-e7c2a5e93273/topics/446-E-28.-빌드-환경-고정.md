# E-28. 빌드 환경 고정

재현성 없는 빌드는 성능 측정도 신뢰할 수 없다.

## 고정할 것

```text
Node 버전
package manager 버전
lockfile
Python 버전
다이어그램 도구 버전
locale
timezone
```

## 특히 날짜

게시일과 Sitemap 날짜가 CI timezone에 따라 달라지지 않게 한다.

```text
Asia/Seoul로 표시할 것
UTC로 저장할 것
```

중 하나를 명확히 결정한다.

## 완료 조건

- 로컬과 CI의 주요 버전이 일치
- 빌드 결과가 실행 locale에 따라 달라지지 않음
- 같은 commit에서 불필요한 생성 diff가 발생하지 않음
