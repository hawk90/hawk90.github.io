# C-03. 최소 metadata schema 도입

처음부터 모든 글에 거대한 front matter를 요구하면 실패한다.

대표 문서 20개부터 다음 필드만 우선 적용한다.

```yaml
type: guide
topic: pcie-cxl
status: current
updated: 2026-08-01
```

검증이 실제로 수행됐다면:

```yaml
lastVerified: 2026-08-01
```

필요한 글에는:

```yaml
testedWith:
  os: Ubuntu 24.04
  kernel: 6.8
  hardware: AMD Alveo U250
  sdk: XRT 2.13.466
```

## 필수와 선택

### 대표 글 필수

```text
type
topic
status
updated
```

### 실험·디버깅 글 권장

```text
lastVerified
testedWith
```

### 모든 글에 강제하지 않을 것

```text
difficulty
audience
readingTime
keywords
prerequisites
related
```

이런 값은 후속 단계에서 실제 필요가 확인되면 추가한다.
