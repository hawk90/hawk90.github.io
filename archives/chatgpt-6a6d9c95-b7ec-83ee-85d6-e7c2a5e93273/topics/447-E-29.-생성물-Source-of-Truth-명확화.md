# E-29. 생성물 Source of Truth 명확화

## Source

```text
Markdown
Topic registry
Hub config
alias registry
diagram source
redirect manifest
```

## Derived

```text
검색 인덱스
Sitemap
RSS
OG 이미지
optimized SVG
content graph
```

Derived data는 언제든 재생성 가능해야 한다.

## 완료 조건

- 생성 파일을 수동 수정하지 않음
- 생성물에 generator version과 input hash 존재
- source와 artifact 디렉터리가 구분됨
- stale artifact를 manifest 기준으로 정리 가능
