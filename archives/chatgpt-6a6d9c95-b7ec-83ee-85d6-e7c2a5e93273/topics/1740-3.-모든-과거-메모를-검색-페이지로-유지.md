# 3. 모든 과거 메모를 검색 페이지로 유지

블로그는 개인 지식 저장소로 시작했을 가능성이 높다.

이때 다음이 모두 하나의 게시물로 만들어진다.

```text
명령 한 줄
에러 로그 한 줄
링크 저장
강의 중 짧은 메모
용어 정의
질문과 짧은 답
```

개인 기록 관점에서는 유용하다.

하지만 검색엔진 관점에서 각각이 별도의 검색 결과가 되어야 하는지는 다른 문제다.

## 권장 분류

### 독립 페이지

```text
하나의 검색 질문을 충분히 해결
직접 분석이나 경험 존재
독립적으로 이해 가능
```

### 통합 대상

```text
같은 주제의 짧은 메모 여러 개
서로 보완돼야 의미가 생김
```

### 공개하되 색인 제외

```text
과거 기록
개인 Reference
검색 결과로서 약함
```

### 제거·Archive

```text
내용이 거의 없음
깨진 링크만 존재
테스트성 글
```
