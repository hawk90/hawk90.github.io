# 51. Plugin Architecture 불필요

개인 사이트에서 다음은 필요하지 않다.

```text
Content Plugin API
Widget Registry
Theme Extension Hook
Runtime Module Loader
```

실제로 제3자가 기능을 추가하지 않는다.

Plugin Architecture는 가능성을 위해 현재 복잡도를 지불하는 구조다.
