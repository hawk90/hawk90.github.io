# D-18. Topic Cannibalization 리포트

유사 글을 텍스트 유사도만으로 판단하지 않는다.

## 후보 생성 신호

```text
제목 유사도
동일 Topic
동일 주요 heading
공통 alias
비슷한 description
```

## 사람 검토 항목

```text
검색 의도가 같은가
문서 타입이 다른가
고유 실험이 있는가
버전이 다른가
하나가 다른 글을 완전히 포함하는가
```

## 결과

```text
유지
역할 구분
통합
Historical
Superseded
```
