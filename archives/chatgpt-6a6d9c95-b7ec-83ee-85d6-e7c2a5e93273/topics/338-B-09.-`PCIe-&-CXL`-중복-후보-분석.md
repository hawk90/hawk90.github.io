# B-09. `PCIe & CXL` 중복 후보 분석

다음 유형을 찾아야 한다.

## 개념 중복

```text
PCIe BAR란
BAR 크기 계산
BAR 크기 탐색
BAR 주소 할당
```

서로 독립적인 검색 의도가 있는지 확인한다.

권장 결과:

```text
대표 Concept:
BAR 크기 탐색과 주소 할당

보조 Debug:
BAR가 0으로 보이는 이유

Reference:
BAR bit layout
```

## CXL 구조 중복

```text
CXL memory
HDM Decoder
HPA to DPA
Linux NUMA
```

모두 하나의 거대 글로 합칠 필요는 없다.

대신 대표 Guide를 상위에 두고 세부 문서를 연결한다.
