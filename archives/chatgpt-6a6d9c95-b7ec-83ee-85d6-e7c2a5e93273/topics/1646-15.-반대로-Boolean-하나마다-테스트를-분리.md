# 15. 반대로 Boolean 하나마다 테스트를 분리

다음처럼 지나치게 쪼갤 수 있다.

```text
Current renders
Current indexes
Current searchable
Current appears in sitemap
Current supports ads
```

정책 하나의 일관된 결과를 이해하기 어렵고 테스트 수만 늘어난다.

권장 단위:

```text
하나의 상태가 주요 공개 계약을 어떻게 결정하는가
```

를 한 Case 안에서 명확히 검사한다.
