# D-13. 의미 링크와 UI 링크 분리

모든 `<a>`를 지식 관계로 계산하면 헤더·푸터·카드 링크 때문에 그래프가 왜곡된다.

## 의미 링크

```text
본문에서 설명 목적으로 연결
선행 문서
다음 문서
상위 Topic
대체 문서
```

## UI 링크

```text
헤더
푸터
태그 목록
아카이브
페이지네이션
```

콘텐츠 manifest에서는 의미 링크만 별도로 추출한다.
