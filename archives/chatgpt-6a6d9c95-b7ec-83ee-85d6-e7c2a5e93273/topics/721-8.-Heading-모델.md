# 8. Heading 모델

검색과 anchor 검증에 사용한다.

```ts
export interface ContentHeading {
  id: string;
  text: string;
  depth: 2 | 3 | 4 | 5 | 6;
}
```

H1은 일반적으로 문서 title에서 생성하므로 본문 heading manifest에는 H2 이하만 포함해도 된다.

예:

```ts
const headings: ContentHeading[] = [
  {
    id: "bar-size-probing",
    text: "BAR 크기 탐색",
    depth: 2,
  },
];
```
