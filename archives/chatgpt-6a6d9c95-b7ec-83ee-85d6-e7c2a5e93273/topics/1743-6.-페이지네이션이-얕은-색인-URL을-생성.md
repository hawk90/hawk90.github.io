# 6. 페이지네이션이 얕은 색인 URL을 생성

예:

```text
/page/2/
/page/3/
/page/17/

/tag/cpp/page/4/
```

페이지마다 글 카드 몇 개 외에는 고유 내용이 없다.

페이지네이션이 사용자 탐색에 필요할 수는 있다.

그러나 다음을 명확히 해야 한다.

```text
색인이 필요한가?
Sitemap에 들어가야 하는가?
광고가 있어야 하는가?
Canonical이 자기 자신인가?
```

## 보편적 안전 방향

페이지네이션 목록은:

```text
crawl 가능한 글 링크 유지
광고 최소화 또는 제외
Sitemap 제외 검토
고유 검색 랜딩 페이지로 기대하지 않음
```

검색엔진이 글을 발견하도록 내부 링크는 유지하되, 목록 URL 자체를 핵심 검색 콘텐츠로 만들지는 않는다.
