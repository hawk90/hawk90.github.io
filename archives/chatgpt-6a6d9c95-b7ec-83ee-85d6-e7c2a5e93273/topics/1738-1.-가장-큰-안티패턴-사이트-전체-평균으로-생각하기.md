# 1. 가장 큰 안티패턴: 사이트 전체 평균으로 생각하기

작성자는 사이트를 다음처럼 본다.

```text
기술 글 500개
긴 글 다수
코드와 실험 포함
10년 이상 축적
```

하지만 크롤러와 방문자는 URL 단위로 본다.

```text
홈
카테고리
태그
검색
페이지네이션
게시물
빈 목록
오래된 메모
```

예를 들어 색인 가능한 URL이 700개인데 다음과 같다면:

```text
가치 높은 글       80
일반 글           200
짧은 메모         250
태그·목록·페이지   170
```

사이트 전체가 강한 기술 지식베이스보다 **얕은 URL이 많이 생성되는 블로그**로 보일 수 있다.

## 핵심 전환

```text
글 개수
```

를 세는 대신:

```text
색인 가능한 URL 중
독립적인 검색 가치를 가진 URL의 비율
```

을 봐야 한다.
