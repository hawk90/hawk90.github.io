# 36. 문서 언어 일관성

한국어 문서에서 기술 용어는 다음 원칙이 실용적이다.

```text
첫 등장:
한글 설명 + 영문 원어

이후:
널리 쓰이는 표기 사용
```

예:

```text
메모리 매핑 입출력(Memory-Mapped I/O, MMIO)
```

이후 `MMIO` 사용.

모든 용어를 억지로 번역하지 않는다.

```text
Probe
Descriptor
Queue
Fence
```

처럼 개발자가 실제로 사용하는 표현은 설명 후 그대로 쓸 수 있다.
