# 37. Props Boolean 폭발

다음 형태도 위험하다.

```ts
interface Props {
  showTitle?: boolean;
  showDescription?: boolean;
  showTopic?: boolean;
  showDate?: boolean;
  showReadingTime?: boolean;
  showStatus?: boolean;
}
```

실제 허용되지 않는 조합까지 생긴다.

View Model이나 명확한 Variant로 조합을 제한한다.
