# 20. 가장 중요한 개선 우선순위

## P0. 측정부터 할 것

다음 숫자를 먼저 확보해야 한다.

```text
Search Console 색인 페이지 수
발견됨-현재 색인되지 않음
크롤링됨-현재 색인되지 않음
페이지별 노출과 클릭
상위 검색어
Core Web Vitals
검색 인덱스 파일 크기
태그·시리즈·아카이브 페이지 수
고아 문서 수
글별 내부 링크 수
```

측정 없이 SEO를 수정하면 추측에 의존하게 된다.

---

## P1. 홈을 Topic 중심으로 개편

현재:

```text
Hero
Latest Posts
```

개선:

```text
Hero
Core Topics
Start Here
Featured Guides
Latest Posts
```

---

## P1. 대표 Topic Hub 5개 작성

처음부터 모든 분야를 만들 필요는 없다.

```text
C++
Systems Programming
Firmware & Bootloader
GPU & CUDA
PCIe & CXL
```

각 허브에는 최소 다음이 있어야 한다.

```text
분야 설명
대상 독자
선행 지식
추천 학습 순서
대표 글
디버깅 글
레퍼런스
```

---

## P1. 핵심 글 20개 내부 링크 재설계

각 글에:

```text
상위 주제
선행 글
관련 개념
다음 글
```

을 추가한다.

---

## P1. 짧고 유사한 글 통합 후보 찾기

기준:

```text
읽기 시간 1~3분
유사 제목
본문 중복
같은 검색 의도
독립적인 실험이나 경험 없음
```

짧은 글이라고 무조건 합치지는 않는다. 독립적인 문제 해결 가치가 있으면 유지한다.

---

## P2. 검색 인덱스 최적화

- 코드·로그 제외
- 제목·소제목 가중치 강화
- 콘텐츠 타입 추가
- topic 필터 추가
- 인덱스 크기 측정
- 검색 모달 열 때 지연 로드

---

## P2. 콘텐츠 상태 표시

```text
Current
Updated
Needs Review
Historical
Superseded
```

---

## P2. 신뢰 구조 강화

- 작성자 경력과 전문 분야
- 실제 검증 환경
- 직접 실험 여부
- 참고 사양
- 수정일
- 오류 제보 방법
- 개인정보 처리방침
- 연락 수단
