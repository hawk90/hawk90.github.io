# 8. 빈 태그·카테고리 URL이 200으로 남음

다음 상황이 발생할 수 있다.

```text
Tag는 Registry에 존재
문서는 모두 Archive
목록은 0개
페이지는 200
```

화면:

```text
CXL.cache

등록된 글이 없습니다.
```

이 페이지에 광고나 공통 Footer 콘텐츠만 있다면 사실상 콘텐츠 없는 화면이다.

## 규칙

```text
공개 글 0개
→ 페이지 생성하지 않음
또는 404

공개 글 1개
→ 태그 페이지가 필요한지 재검토
```

빈 화면을 정상 콘텐츠 URL로 유지하지 않는다.
