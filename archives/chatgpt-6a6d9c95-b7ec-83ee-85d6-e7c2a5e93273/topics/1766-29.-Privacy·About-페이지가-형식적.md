# 29. Privacy·About 페이지가 형식적

About:

```text
안녕하세요. 개발 블로그입니다.
```

Privacy:

```text
개인정보를 중요하게 생각합니다.
```

로 끝날 수 있다.

이 페이지들이 기술 콘텐츠를 대신하지는 않지만 사이트 신뢰도와 운영 투명성을 보여준다.

## About에 유용한 정보

```text
작성자의 기술 배경
사이트가 다루는 범위
직접 경험과 학습 기록의 구분
오류 정정 방식
연락·GitHub
```

## Privacy에 유용한 정보

```text
Analytics
AdSense
Cookies
댓글 서비스
외부 Embed
데이터 보존
```

실제로 사용하지 않는 서비스를 복사한 정책 문구로 넣지 않는다.
