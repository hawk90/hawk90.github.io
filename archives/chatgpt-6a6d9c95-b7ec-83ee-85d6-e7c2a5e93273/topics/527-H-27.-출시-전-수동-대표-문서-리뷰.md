# H-27. 출시 전 수동 대표 문서 리뷰

자동화로 기술 정확성을 판정할 수 없다.

대표 문서 10개에 대해 마지막 수동 리뷰를 진행한다.

## 공통

```text
[ ] 제목이 실제 질문과 일치
[ ] description이 고유함
[ ] 핵심 결론에 근거가 있음
[ ] 관찰과 가설이 구분됨
[ ] 버전·환경이 필요하면 표시됨
[ ] 적용 범위와 한계가 있음
[ ] 구판 링크가 최신 문서를 방해하지 않음
[ ] 다음 학습 경로가 있음
```

## Source Walkthrough

```text
[ ] commit 또는 tag
[ ] file과 symbol
[ ] 현재 소스와 차이 가능성
```

## Experiment

```text
[ ] baseline
[ ] 반복 횟수
[ ] 결과 단위
[ ] 일반화 한계
```

## Debug Note

```text
[ ] 증상
[ ] 정상 기대값
[ ] 제외한 가설
[ ] 해결 후 검증
```

## 완료 조건

- 대표 글 10개 리뷰 완료 기록
- 리뷰 중 발견한 중대한 오류 수정
- 검증하지 못한 글은 `current`로 강제하지 않음
- Featured 목록과 리뷰 결과 일치
