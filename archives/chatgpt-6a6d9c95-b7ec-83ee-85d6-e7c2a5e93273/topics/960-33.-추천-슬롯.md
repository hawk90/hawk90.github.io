# 33. 추천 슬롯

일반적인 `관련 글 6개` 대신 역할 기반 슬롯을 사용한다.

```ts
export interface ArticleRecommendationSlots {
  prerequisite?: ContentDocument;
  next?: ContentDocument;
  appliedExample?: ContentDocument;
  topic?: TopicDefinition;
}
```

관계가 없으면 해당 슬롯을 비운다.

억지로 4개를 채우지 않는다.
