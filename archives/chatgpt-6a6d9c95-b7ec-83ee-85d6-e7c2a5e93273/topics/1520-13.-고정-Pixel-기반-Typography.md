# 13. 고정 Pixel 기반 Typography

예:

```css
h1 {
  font-size: 48px;
}
```

모바일에서 별도 Override가 계속 필요해진다.

반대로 모든 크기를 `vw`로 만들면 큰 화면에서 과도하게 커진다.

권장:

```css
font-size: clamp(min, preferred, max);
```

예:

```text
Article H1
Section H2
Home Hero
Topic Title
```

처럼 큰 Text에 제한적으로 사용한다.

본문 글자 크기까지 지나치게 유동적으로 만들 필요는 없다.
