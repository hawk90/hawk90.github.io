# 19. 다른 글을 요약한 링크 모음

본문:

```text
좋은 CUDA 글 모음

- NVIDIA Blog
- Stack Overflow
- Medium
- GitHub
```

링크 큐레이션 자체가 가치가 없지는 않다.

하지만 왜 선택했는지, 어떤 순서로 읽는지, 어떤 한계가 있는지 없으면 독립 콘텐츠로 약하다.

## 가치 있는 큐레이션

```text
대상 독자
추천 순서
자료별 강점
버전
중복·차이
작성자의 사용 경험
```

이 있어야 한다.
