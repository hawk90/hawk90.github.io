# 77. Architecture Decision Record

큰 기능의 유지·삭제 이유만 짧게 남길 수 있다.

예:

```text
ADR-003: 공개 Admin UI를 제거한다

결정:
콘텐츠 편집은 Git과 IDE를 사용한다.

이유:
인증·저장 API·Secret 관리 비용이
개인 정적 블로그의 편집 편익보다 크다.
```

모든 사소한 결정을 ADR로 만들 필요는 없다.
