# 64. Migration 전용 Flag

과도기에는 다음 필드를 내부 모델에 둘 수 있다.

```ts
export interface MigrationMetadata {
  migrated: boolean;
  reviewed: boolean;
}
```

하지만 장기 공개 Front Matter에 남기지 않는 편이 좋다.

대신 중앙 Migration Inventory에서 관리할 수 있다.

```yaml
pcie-bar-sizing:
  tier: representative
  reviewed: true
  action: promote
```
