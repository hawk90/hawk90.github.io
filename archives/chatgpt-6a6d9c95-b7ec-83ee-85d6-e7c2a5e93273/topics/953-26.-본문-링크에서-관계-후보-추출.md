# 26. 본문 링크에서 관계 후보 추출

본문 문맥으로 후보를 구분할 수 있다.

예:

```text
먼저 PCIe Configuration Space를 이해해야 한다.
```

→ prerequisite 후보

```text
다음 글에서는 MSI-X를 설명한다.
```

→ next 후보

```text
실제 실패 사례는 U250 BAR 분석을 참고한다.
```

→ related 후보

초기에는 자연어 분석까지 자동화하지 않아도 된다.

링크 주변 문구를 감사 리포트에 보여주는 것만으로도 수동 분류가 쉬워진다.
