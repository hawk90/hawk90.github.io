# 7. Light Mode 기준으로만 Token 설계

Light Mode에서:

```text
배경
카드
Border
Code
Callout
```

가 명확해도 다크 모드에서 모두 비슷한 검은색으로 합쳐질 수 있다.

대표적인 문제:

```text
본문 배경과 카드 배경 구분 불가
Border가 보이지 않음
Inline Code가 과도하게 밝음
Muted Text가 너무 흐림
Link와 일반 텍스트 구분 약함
```

다크 모드는 단순히 색상 반전이 아니다.

Surface 계층을 별도로 점검해야 한다.

```text
Canvas
Surface
Raised Surface
Inset Surface
Code Surface
```
