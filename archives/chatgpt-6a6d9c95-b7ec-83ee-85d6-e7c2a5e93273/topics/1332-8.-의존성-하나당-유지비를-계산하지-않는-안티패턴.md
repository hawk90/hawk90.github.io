# 8. 의존성 하나당 유지비를 계산하지 않는 안티패턴

패키지를 추가할 때 보통 설치 순간의 편리함만 본다.

하지만 실제 비용은 다음과 같다.

```text
업데이트
보안 경고
Breaking Change
번들 크기
빌드 시간
Node 호환성
설정 파일
타입 충돌
```

예를 들어 20줄로 해결 가능한 기능에 50KB 라이브러리를 넣을 수 있다.

무조건 직접 구현하라는 뜻은 아니다.

판단 기준은:

```text
직접 구현의 복잡도
vs
외부 의존성의 장기 운영 비용
```

이다.
