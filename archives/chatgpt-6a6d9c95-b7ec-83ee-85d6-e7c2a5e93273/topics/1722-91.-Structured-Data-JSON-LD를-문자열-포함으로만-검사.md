# 91. Structured Data JSON-LD를 문자열 포함으로만 검사

JSON-LD를 Parse해 Schema의 필수 필드와 실제 표시 값의 일치를 검사한다.

```text
headline = H1
datePublished = metadata
canonical = mainEntityOfPage
```

검색엔진 Rich Result를 보장하지는 않지만 명백한 불일치는 막을 수 있다.
