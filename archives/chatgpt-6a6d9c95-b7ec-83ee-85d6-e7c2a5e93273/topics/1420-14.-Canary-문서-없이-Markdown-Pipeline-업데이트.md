# 14. Canary 문서 없이 Markdown Pipeline 업데이트

Remark·Rehype·Shiki·Astro를 업데이트했을 때 다음 페이지가 동시에 영향을 받는다.

```text
표
Footnote
Code Fence
Raw HTML
Callout
Heading Anchor
수식
이미지
```

대표 Canary 문서 세트를 둔다.

```text
긴 코드 문서
복잡한 표 문서
Raw HTML Legacy 문서
한글 Heading 문서
다이어그램 문서
Historical 문서
```

업데이트 전후 Build와 Screenshot을 비교한다.
