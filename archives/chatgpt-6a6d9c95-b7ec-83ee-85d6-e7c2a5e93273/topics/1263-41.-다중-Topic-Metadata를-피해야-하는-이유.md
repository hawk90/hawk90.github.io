# 41. 다중 Topic Metadata를 피해야 하는 이유

```yaml
topics:
  - firmware
  - pcie
  - linux
  - fpga
```

를 허용하면 거의 모든 글이 여러 Topic에 들어가면서 Hub가 중복 목록이 된다.

초기에는:

```yaml
topic: firmware-bootloader
```

하나를 사용하고, Tags·Relations·Learning Path로 교차 연결한다.
