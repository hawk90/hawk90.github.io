# 6. 검색 가중치

권장 상대 우선순위는 다음과 같다.

```text
Title
>
Exact Alias
>
Symbol
>
Topic
>
Heading
>
Description
>
Keyword
>
Excerpt
>
Error Message
```

오류 메시지는 일반 검색에서는 낮지만 정확히 일치하면 높은 점수를 줄 수 있다.

---

## 예시

```ts
export const SEARCH_FIELD_WEIGHTS = {
  title: 12,
  aliases: 10,
  symbols: 10,
  topic: 7,
  headings: 6,
  description: 5,
  keywords: 4,
  excerpt: 2,
  errorMessages: 2,
} as const;
```

숫자 자체보다 상대 관계가 중요하다.
