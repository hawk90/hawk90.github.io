# 48. 내부 도구의 제품화

로컬 스크립트가 점점 다음 기능을 갖출 수 있다.

```text
TUI
Web Dashboard
DB
상태 저장
필터
그래프
인증
```

블로그 콘텐츠를 개선하기보다 도구 자체를 만드는 데 시간이 사용된다.

개인적으로 호크가 특히 조심해야 할 부분이다.

정리와 시스템 설계 능력이 강해서 **콘텐츠 개선보다 콘텐츠 관리 플랫폼을 더 정교하게 만드는 방향**으로 빠질 가능성이 있다.

내부 도구의 종료 기준을 정한다.

```text
한 번 실행
명확한 Report
파일 직접 수정은 Dry-run 후
```

이 정도면 충분하다.
