# 37. HTML 장기 캐시 가정

정적 자산은 Hash 파일명으로 장기 캐시할 수 있지만 HTML은 새 배포를 가리키므로 오래 캐시되면 안 된다.

GitHub Pages·CDN 정책을 임의로 가정하지 말고 실제 응답 Header를 확인한다.

Custom CDN을 사용한다면:

```text
HTML
→ 짧은 Cache 또는 Revalidate

Hashed Asset
→ 장기 Immutable
```

원칙을 적용한다.
