# B-24. Hub와 태그 페이지 관계

기존 태그 페이지를 모두 제거할 필요는 없다.

## Topic Hub

```text
편집된 구조
설명
학습 순서
대표 글
```

## Tag page

```text
해당 태그를 가진 글의 전체 목록
```

중요한 주제는 Topic Hub가 canonical 탐색 페이지가 되고, 태그 페이지는 보조 목록으로 남긴다.

SEO 관점에서 둘이 거의 같은 내용이라면 태그 페이지 색인 필요성을 검토한다.
