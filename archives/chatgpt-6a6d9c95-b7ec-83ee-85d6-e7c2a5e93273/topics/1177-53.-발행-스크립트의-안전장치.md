# 53. 발행 스크립트의 안전장치

자동 수정 전에 dry-run을 제공한다.

```bash
npm run content:publish -- \
  pcie-bar-sizing \
  --status current \
  --dry-run
```

출력:

```text
Planned changes

draft: true → false
status: needs-review → current
published: undefined → 2026-08-01
updated: undefined → 2026-08-01
```
