# 17. Markdown 요소별 Margin이 누적

예:

```css
h2 { margin-bottom: 1rem; }
p { margin-block: 1rem; }
ul { margin-block: 1rem; }
```

인접 Margin과 Layout 방식에 따라 예상보다 큰 공백이 생긴다.

`prose`에서 일관된 vertical rhythm을 설계한다.

예:

```text
Block 간 기본 간격
Section 전환 간격
List 내부 간격
Code와 설명 간격
Figure와 Caption 간격
```

을 구분한다.
