# 실제로 반복된 항목

## 대표 문서 우선

다음 태스크에서 반복됐다.

```text
Topic Hub
검색 Ranking
내부 링크
Article Page
작성 Workflow
Migration
AdSense
```

결론은 모두 같다.

```text
대표 문서를 선정하고
홈·Hub·검색·링크에서 우선 노출한다.
```

한 번의 통합 규칙으로 끝낼 수 있다.

---

## Historical·Superseded

다음에서 반복됐다.

```text
Publication Policy
검색
내부 관계
Article Header
Migration
AdSense·Sitemap
```

이것도 정책표 하나면 충분하다.

---

## 기존 글 500개 정리

다음 내용이 여러 번 나왔다.

```text
Inventory
대표 글 선정
작은 Batch
Metadata 적용
구판 분류
중복 통합
URL 유지
```

추가 설명은 이제 거의 필요 없다.

---

## 검색·내부 링크·Learning Path

각각 다른 기능이지만 계속 다음 결론으로 모였다.

```text
사용자를 대표 문서로 보내고
다음 문서로 이동시킨다.
```

이후에는 세부 구현을 실제 저장소에서 검토하지 않는 이상 일반론만 반복될 가능성이 높다.

---

## AdSense와 콘텐츠 품질

앞서 말한:

```text
대표 문서
얕은 글 통합
빈 목록 제거
Topic Hub 강화
Historical 분리
```

가 그대로 다시 등장했다.

AdSense만의 신규 내용은 사실 다음 정도였다.

```text
검색·Tag·Pagination 광고 제외
얕은 URL noindex
Sitemap 표면 축소
광고 대상 페이지 제한
```

나머지는 기존 콘텐츠 아키텍처와 겹친다.
