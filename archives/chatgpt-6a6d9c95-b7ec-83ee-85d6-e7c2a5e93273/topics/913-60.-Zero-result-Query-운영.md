# 60. Zero-result Query 운영

검색 분석을 수집한다면 결과 없음 Query를 주기적으로 검토한다.

결과 없음의 원인은 세 가지다.

```text
콘텐츠가 없음
Alias가 없음
검색 알고리즘이 못 찾음
```

각각 대응이 다르다.

예:

```text
“코히어런시”
→ Cache Coherence 글은 있음
→ Alias 추가

“CXL.cache snoop filter”
→ 관련 글 없음
→ 신규 콘텐츠 후보

“pci_scan_child_bus”
→ 글에 함수명이 있으나 index에 없음
→ Symbol 추출 보완
```
