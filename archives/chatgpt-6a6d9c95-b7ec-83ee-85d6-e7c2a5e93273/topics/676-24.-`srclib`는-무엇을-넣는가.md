# 24. `src/lib`는 무엇을 넣는가

`lib`는 잡동사니 폴더가 되기 쉽다.

다음처럼 범위를 제한한다.

```text
src/lib/
├── dates/
├── urls/
├── collections/
└── browser/
```

예:

```text
날짜 표시
URL join
배열 정렬
DOM focus utility
```

콘텐츠 정책은 `lib`에 넣지 않는다.

나쁜 예:

```text
src/lib/utils.ts
```

안에 다음이 모두 들어가는 구조:

```text
날짜
태그
검색
Featured
광고
URL
Markdown
```

가능하면 `utils.ts` 자체를 만들지 않는다.
