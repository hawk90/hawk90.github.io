# 46. 테스트가 Production Analytics를 호출

브라우저 테스트가 실제 GA, Giscus, 광고를 로드하면:

```text
데이터 오염
외부 장애
느린 실행
개인정보 요청
```

이 생긴다.

테스트 환경에서는 외부 Integration을 비활성화하거나 Mock한다.

중요한 것은 Integration이 없어도 Layout이 정상인지다.
