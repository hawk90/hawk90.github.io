# 92. Article 품질 검사

자동화 가능한 항목:

```text
H1 중복
Description 누락
Status와 Notice 불일치
Canonical 누락
Heading Anchor 중복
깨진 내부 링크
이미지 Alt 누락
표 Header 누락 후보
코드 언어 오타
```

사람이 검토해야 하는 항목:

```text
결론이 근거를 초과하는가
가설이 사실처럼 표현됐는가
범위가 명확한가
그림이 실제 이해에 도움이 되는가
```
