# 12. 검색 정규화

```ts
export function normalizeSearchText(
  value: string,
): string {
  return value
    .normalize("NFKC")
    .toLocaleLowerCase("ko-KR")
    .replace(/\s+/g, " ")
    .trim();
}
```

하지만 모든 기호를 제거하면 안 된다.
