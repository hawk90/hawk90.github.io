# 5. Content Status 모델

```ts
export const CONTENT_STATUSES = [
  "current",
  "needs-review",
  "historical",
  "superseded",
  "archived",
] as const;

export type ContentStatus =
  (typeof CONTENT_STATUSES)[number];
```

## 상태의 의미

### `current`

현재도 대표 경로에서 적극적으로 노출할 수 있다.

### `needs-review`

내용 일부가 오래됐거나 검증이 필요하다.

### `historical`

과거 버전·환경을 설명하는 기록으로 유효하다.

### `superseded`

더 좋은 신판이나 통합 문서가 존재한다.

### `archived`

보존하지만 일반 탐색에서는 제외한다.
