# 지금 시점의 추천

범용 안티패턴 작업은 **90~95% 완료**로 보는 것이 적절하다.

계속 같은 방식으로 `다음`을 진행하면:

```text
상태
대표 문서
검색
링크
색인
Migration
```

이 이름만 바뀌어 다시 나올 가능성이 높다.

따라서 남은 범용 영역은 다음 세 개로 종료하는 것이 좋다.

```text
1. 보안·공급망
2. 저작권·라이선스
3. 백업·보존
```

그 뒤에는 전체 목록을 다음처럼 정리해야 한다.

```text
필수
권장
현재 불필요
과설계 위험
실제 저장소 확인 필요
```

즉, 이제부터 중요한 것은 **안티패턴을 더 늘리는 것보다 중복을 제거하고 실행 가능한 최종 백로그로 압축하는 것**이다.
