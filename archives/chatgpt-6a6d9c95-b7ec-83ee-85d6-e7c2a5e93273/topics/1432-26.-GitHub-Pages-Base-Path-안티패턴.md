# 26. GitHub Pages Base Path 안티패턴

사용자 사이트:

```text
https://hawk90.github.io/
```

와 프로젝트 사이트:

```text
https://hawk90.github.io/project-name/
```

는 Base Path 처리가 다르다.

개발 환경에서는 `/`에서 잘 동작하지만 프로젝트 경로 배포에서 다음이 깨질 수 있다.

```text
CSS
JavaScript
이미지
Search Index
RSS
Sitemap
Font
```

현재 사이트 유형과 Custom Domain 사용 여부를 기준으로 Astro `site`와 `base`를 명확히 설정한다.
