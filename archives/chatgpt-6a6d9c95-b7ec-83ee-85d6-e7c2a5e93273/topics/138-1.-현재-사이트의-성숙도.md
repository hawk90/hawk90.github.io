# 1. 현재 사이트의 성숙도

현재 블로그를 일반적인 성숙도 단계로 나누면 다음과 같다.

## 1단계: 개인 기록

```text
글을 작성한다
날짜순으로 보여준다
```

## 2단계: 전문 기술 블로그

```text
주제가 일관된다
검색 유입이 발생한다
전문성을 보여준다
```

## 3단계: 기술 지식베이스

```text
주제별 체계가 있다
대표 문서가 있다
글 간 연결이 있다
학습 순서가 있다
```

## 4단계: 퍼블리싱 플랫폼

```text
테마
검색
콘텐츠 감사
OG 생성
관리 도구
다이어그램 빌드
자동화
```

현재 `hawk90.github.io`는 이상하게도:

```text
콘텐츠 측면에서는 2~3단계
플랫폼 측면에서는 4단계
```

에 가깝다.

즉 **사이트 기반시설은 상당히 발전했는데, 콘텐츠를 지식 체계로 보여주는 층은 상대적으로 덜 발전했다.**

이 불균형이 현재 가장 중요한 진단이다.
