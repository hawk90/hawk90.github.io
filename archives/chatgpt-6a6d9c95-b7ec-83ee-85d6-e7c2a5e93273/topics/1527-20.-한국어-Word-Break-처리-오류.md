# 20. 한국어 Word Break 처리 오류

다음 CSS가 사이트 전체에 적용될 수 있다.

```css
word-break: break-all;
```

영문 식별자와 URL이 아무 위치에서나 잘리고, 한국어도 읽기 흐름이 나빠질 수 있다.

반대로 `white-space: nowrap`이 Metadata나 Badge에 남으면 모바일 폭을 깨뜨린다.

권장 요소별 정책:

```text
일반 한국어 본문
→ 자연스러운 줄바꿈

긴 URL·Identifier
→ overflow-wrap

코드 블록
→ 가로 스크롤

Badge
→ 필요한 경우 줄바꿈 또는 축약
```
