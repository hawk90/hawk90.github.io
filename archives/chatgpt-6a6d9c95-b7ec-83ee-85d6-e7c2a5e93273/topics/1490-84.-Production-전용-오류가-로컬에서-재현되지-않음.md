# 84. Production 전용 오류가 로컬에서 재현되지 않음

예:

```text
Base Path
Minification
Environment Variable
Case-sensitive Path
CSP
GitHub Pages 404
```

때문이다.

로컬에서 `astro dev`만 사용하지 말고 Production Build 후 Static Server로 `dist`를 확인한다.

```bash
npm run build
npm run preview:dist
```
