# 7. 동시 배포 경쟁

짧은 시간에 여러 Commit을 Push하면 이전 Workflow가 늦게 끝나 최신 배포를 덮어쓸 수 있다.

예:

```text
Commit A Build 시작
Commit B Build 시작
Commit B 먼저 배포
Commit A 나중에 배포
→ 운영 사이트가 A로 되돌아감
```

GitHub Actions의 `concurrency`를 사용한다.

```yaml
concurrency:
  group: pages
  cancel-in-progress: true
```

단, 취소된 Build의 Artifact가 Deploy Job에 남지 않는지 확인한다.
