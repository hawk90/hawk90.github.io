# 5. 모든 실제 문서를 Unit Test Fixture로 사용

실제 콘텐츠 500개를 매 Unit Test에서 로드하면 테스트가 느리고 서로 영향을 준다.

```text
Publication Policy Test
→ 실제 Markdown 전체 로드

Relation Function Test
→ 실제 사이트 Manifest 생성
```

이 구조에서는 작은 함수 테스트도 전체 사이트 상태에 의존한다.

권장:

```text
작은 인공 Fixture
→ 함수와 규칙 테스트

실제 전체 콘텐츠
→ 별도의 Content Integration Test
```
