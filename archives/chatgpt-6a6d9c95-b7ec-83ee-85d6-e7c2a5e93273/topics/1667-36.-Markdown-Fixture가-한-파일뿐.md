# 36. Markdown Fixture가 한 파일뿐

하나의 거대한 Fixture에 다음을 모두 넣으면 실패 원인을 찾기 어렵다.

```text
표
코드
Callout
Footnote
Raw HTML
이미지
Anchor
```

권장:

```text
markdown/code-block.md
markdown/table.md
markdown/headings.md
markdown/callout.md
markdown/legacy-html.md
```

작은 기능 Fixture와 복합 Canary Fixture를 함께 둔다.
