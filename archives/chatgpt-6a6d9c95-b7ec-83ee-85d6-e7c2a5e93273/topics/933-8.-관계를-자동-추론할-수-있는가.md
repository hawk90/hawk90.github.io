# 8. 관계를 자동 추론할 수 있는가

일부 후보는 자동 생성할 수 있다.

```text
본문 링크
같은 Topic
같은 Series
제목 유사도
같은 Symbol
```

하지만 최종 관계를 자동 확정하는 것은 위험하다.

예:

```text
PCIe BAR
```

와:

```text
BAR에서 맥주 주문하기
```

가 같은 문자열을 공유하는 극단적 문제도 있지만, 기술 문서 안에서도 더 현실적인 문제가 있다.

```text
DMA API
GPU DMA
PCIe DMA Engine
```

관련은 있지만 선행 관계는 아니다.

따라서:

```text
자동화
→ 관계 후보 생성

사람
→ 관계 의미 확정
```

구조가 적합하다.
