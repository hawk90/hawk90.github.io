# 104. 모든 예외를 CSS로 수용

콘텐츠가 비정상적으로 긴 경우 CSS로 무조건 숨기거나 축소하기보다 콘텐츠 규칙으로 잡아야 할 수 있다.

예:

```text
제목 180자
Tag 30개
Prerequisite 10개
```

는 Layout 문제이기도 하지만 Editorial Validation 문제다.

```text
CSS
→ 정상 범위의 다양성 처리

Validation
→ 비정상 범위 방지
```

로 책임을 나눈다.
