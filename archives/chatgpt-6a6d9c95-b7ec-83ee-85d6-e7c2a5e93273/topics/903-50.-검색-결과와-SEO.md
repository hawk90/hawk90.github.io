# 50. 검색 결과와 SEO

내부 검색 결과 페이지는 일반적으로 색인하지 않는다.

```html
<meta
  name="robots"
  content="noindex,follow"
/>
```

Sitemap에서 제외한다.

URL query별 검색 결과를 정적 페이지로 생성하지 않는다.

```text
/search?q=pcie
```

가 무수한 색인 페이지로 만들어지지 않게 한다.
