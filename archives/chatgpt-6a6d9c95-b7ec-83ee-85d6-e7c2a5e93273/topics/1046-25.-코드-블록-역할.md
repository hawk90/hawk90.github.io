# 25. 코드 블록 역할

모든 fenced block을 같은 코드로 보지 않는다.

```text
Source Code
Command
Output
Log
Error
Register Dump
Plain Text
```

예:

````markdown
```bash role="command"
lspci -vv -s 01:00.0
```

```text role="output"
01:00.0 Processing accelerators: ...
```
````

명령과 결과가 구분되면 독자가 복사해야 할 부분을 명확히 안다.
