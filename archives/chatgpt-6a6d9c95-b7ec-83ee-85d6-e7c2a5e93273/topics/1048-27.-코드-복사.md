# 27. 코드 복사

복사 결과에는 다음이 포함되면 안 된다.

```text
Line Number
Diff Marker
Highlight Wrapper
Prompt Symbol
```

예:

화면:

```text
$ cmake --build build
```

복사 결과:

```text
cmake --build build
```

터미널 Prompt를 복사할지 여부는 명령 Role 정책에 따라 결정한다.
