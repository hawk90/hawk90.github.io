# 34. Sitemap에 모든 생성 URL 포함

자동 Sitemap Plugin이 다음을 모두 넣을 수 있다.

```text
Article
Tag
Category
Archive
Pagination
Search
404
Admin
Draft Preview
```

Sitemap은 사이트가 중요하다고 생각하는 URL을 알리는 수단이다. 모든 생성 Route를 무조건 제출하는 목록으로 사용하지 않는다. citeturn517910search38turn517910search5

## Sitemap 포함 후보

```text
Current Article
가치 있는 Historical Article
고유 Topic Hub
About
필요한 Policy Page
```

## 제외 후보

```text
Search
빈 Tag
Pagination
Draft
Superseded
Archive된 글
Admin
404
```
