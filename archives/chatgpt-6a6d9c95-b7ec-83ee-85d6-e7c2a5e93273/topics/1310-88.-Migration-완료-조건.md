# 88. Migration 완료 조건

문서 하나의 Migration 완료는 Tier에 따라 다르다.

## Representative

```text
Metadata
기술 검증
Article UX
관계
검색
Hub
모바일
```

## Valuable

```text
ID
Topic
Type
Status
Description
상위 연결
```

## Legacy

```text
URL 안정성
Draft 유출 없음
민감 정보 없음
기본 렌더 정상
```

## Remove or Merge

```text
최종 대상
내부 링크
Redirect 또는 상태
검색·Sitemap 제거
```
