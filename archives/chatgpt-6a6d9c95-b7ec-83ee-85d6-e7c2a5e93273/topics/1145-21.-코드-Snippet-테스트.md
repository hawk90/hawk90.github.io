# 21. 코드 Snippet 테스트

가능하다면 문서 코드 블록을 추출해 테스트할 수 있다.

예:

````markdown
```cpp test="compile"
#include <cstddef>

constexpr std::size_t alignUp(
    std::size_t value,
    std::size_t alignment)
{
    return (value + alignment - 1)
        & ~(alignment - 1);
}
```
````

빌드 시:

```text
role/source
+
test=compile
```

인 코드만 임시 파일로 추출해 컴파일한다.
