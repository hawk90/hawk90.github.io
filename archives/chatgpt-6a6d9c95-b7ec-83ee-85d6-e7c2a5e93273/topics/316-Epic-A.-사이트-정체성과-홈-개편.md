# Epic A. 사이트 정체성과 홈 개편

## 목표

현재 홈이 전달하는 메시지를:

```text
C++를 좋아하고 글을 쓰는 개발자의 최신 글 블로그
```

에서 다음으로 바꾼다.

```text
C++, 시스템 소프트웨어, 펌웨어, CUDA,
PCIe와 CXL을 다루는 기술 지식베이스
```

홈의 목적도 최신 글 나열에서 다음으로 바꾼다.

```text
사이트 정체성 전달
→ 핵심 주제 탐색
→ 대표 문서 진입
→ 최근 활동 확인
```
