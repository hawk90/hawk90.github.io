# 18. 배열 정규화

alias와 relation에 중복이 들어갈 수 있다.

```ts
export function normalizeStringList(
  values: readonly string[] | undefined,
): string[] {
  if (!values) {
    return [];
  }

  return [
    ...new Set(
      values
        .map((value) => value.trim())
        .filter(Boolean),
    ),
  ];
}
```

대소문자 정규화는 필드별로 다르게 해야 한다.

문서 ID:

```text
lowercase 권장
```

Symbol:

```text
대소문자 보존
```

Alias:

```text
화면 원문은 보존
검색용 정규화는 별도
```
