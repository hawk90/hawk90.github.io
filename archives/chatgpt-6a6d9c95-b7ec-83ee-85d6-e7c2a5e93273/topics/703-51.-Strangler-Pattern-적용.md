# 51. Strangler Pattern 적용

기존 구조를 유지하면서 새 경로를 조금씩 확장한다.

```text
기존 Post 데이터
     │
     ├── 기존 페이지
     │
     └── normalize()
           ↓
       새 Domain Model
           ↓
       새 Hub와 Search
```

처음부터 모든 기존 컴포넌트를 교체하지 않는다.

새 Home과 Hub부터 새 Domain을 사용하고, 기존 Article Page는 이후 전환할 수 있다.
