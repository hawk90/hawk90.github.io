# 51. GitHub README를 그대로 페이지로 복제

Repository README와 블로그 글이 거의 같은 내용인데 둘 다 검색되는 경우가 있다.

완전히 같은 콘텐츠를 여러 URL에서 유지하기보다 역할을 나눈다.

```text
README
→ 설치·사용법

Blog Article
→ 설계 이유·실험·트레이드오프
```

같은 본문을 복사하지 않는다.
