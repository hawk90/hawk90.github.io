# 6주 계획: 사용자에게 보이는 구조 완성

6주차까지의 목표는 다음이다.

> 사용자가 홈에 들어와 사이트의 전문 분야를 이해하고, Topic Hub를 통해 대표 글로 이동할 수 있다.

---

## Sprint 3 — 3주차: Topic Hub 2개

### 목표

두 개의 강한 Topic Hub를 공개한다.

```text
PCIe & CXL
Firmware & Bootloader
```

### 작업

관련 항목:

```text
B-03
B-05
B-11
B-13
B-17
B-25
```

각 Hub 구성:

```text
Topic 소개
Start Here 3개 이하
Core Concepts
Featured Guides 4개 전후
Debug & Experiments
Related Topics
```

### 수동 큐레이션

```text
Start Here
Featured
Core Concepts
```

### 자동 생성 가능

```text
Recently Updated
All Articles
Debug Notes
Experiments
```

### 완료 조건

```text
[ ] Hub 2개 production 공개
[ ] 각각 고유 description
[ ] 각각 Start Here 3개 이하
[ ] 각각 Featured 3~5개
[ ] 모든 Featured current
[ ] 홈에서 접근 가능
[ ] JS 없이 탐색 가능
```

## Sprint 4 — 4주차: 홈 개편

### 목표

홈을 시간순 피드에서 지식베이스 진입점으로 바꾼다.

### 구조

```text
Hero
Core Topics
Featured Guides
Latest Posts
Trust/Author summary
```

### 관련 작업

```text
A-02
A-03
A-04
A-05
A-06
A-07
A-08
```

### Hero 권장 방향

```text
코드에서 하드웨어까지 연결하는 시스템 기술 문서
```

설명:

```text
C++, Linux 시스템 프로그래밍, 펌웨어, CUDA,
PCIe와 CXL의 내부 동작과 디버깅을 정리합니다.
```

### 홈 Featured

초기 4~6개.

조건:

```text
status=current
대표 Topic 존재
description 존재
Hub 연결
```

### 완료 조건

```text
[ ] 최신 글이 첫 핵심 영역이 아님
[ ] Core Topics 5개
[ ] Featured 4~6개
[ ] Latest 6개 이하
[ ] 모바일 첫 화면에서 사이트 정체성 확인 가능
[ ] hydration 추가 없이 정적 HTML
```

## Sprint 5 — 5주차: 검색과 내부 관계

### 목표

검색이 긴 글의 단어 빈도가 아니라 대표 문서를 우선하도록 바꾼다.

### 관련 작업

```text
D-01
D-02
D-03
D-04
D-07
D-15
D-16
```

### 우선 구현

```text
SearchDocument schema
전체 코드·로그 제외
title/alias/topic/heading 가중치
상태 기반 ranking
핵심 alias 30개
Golden query 20개
```

### 관계

대표 문서 20개에만 우선 적용:

```yaml
parent:
prerequisites:
next:
related:
```

### 고아 문서

전체 정리 대신 상위 20개 후보를 리포트한다.

### 완료 조건

```text
[ ] Golden query 20개 테스트
[ ] 대표 문서가 넓은 검색에서 우선
[ ] C++, MSI-X, container_of 검색 가능
[ ] superseded 기본 상위 노출 없음
[ ] 대표 문서가 dead end가 아님
[ ] 검색 인덱스 현재 대비 급증 없음
```

## Sprint 6 — 6주차: 색인과 신뢰 페이지

### 목표

검색엔진과 방문자에게 어떤 페이지가 핵심인지 명확히 한다.

### 관련 작업

```text
F-01
F-02
F-03
F-04
F-05
F-07
F-12
F-13
F-15
F-18
```

### 작업

```text
URL 유형 전수 조사
Indexability Matrix
Sitemap 정리
canonical 검증
얕은 Tag 정책
빈 페이지 제거
About
Privacy
Editorial Policy
제목·description 감사
```

### 최소 페이지

```text
About
Privacy Policy
Editorial Policy
Contact 또는 오류 제보 경로
```

### 태그 처리

먼저 다음만 한다.

```text
빈 태그 생성 중단
1~2개 문서 태그 noindex 검토
동의어 통합
핵심 태그를 Topic Hub로 연결
```

전 태그 시스템을 한 번에 재작성하지 않는다.

### 6주차 완료 조건

```text
[ ] URL 유형별 색인 정책
[ ] Sitemap에 canonical URL만 존재
[ ] Search/Admin/Draft/404 제외
[ ] 빈 Tag·Series 없음
[ ] About·Privacy·Editorial Policy 공개
[ ] 대표 20개 제목·description 감사
[ ] 내부 링크로 핵심 페이지 발견 가능
```
