# 81. 콘텐츠 건강 상태를 Page View로만 판단

조회 수가 낮다고 가치 없는 글은 아니다.

예:

```text
특정 U250 XRT 문제
희귀 Linux 3.10 장애
AV1 Hardware Encoder 분석
```

은 독자가 적어도 독창성이 높다.

평가 축:

```text
검색 수요
독창성
전문성
다른 글의 기반
보완 비용
```

을 함께 본다.
