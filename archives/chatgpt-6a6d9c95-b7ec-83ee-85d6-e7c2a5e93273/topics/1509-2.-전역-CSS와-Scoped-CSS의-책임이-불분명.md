# 2. 전역 CSS와 Scoped CSS의 책임이 불분명

Astro에서는 다음이 쉽게 섞인다.

```text
global.css
Layout scoped style
Component scoped style
Utility class
Inline style
Markdown-generated class
```

동일한 요소가 여러 층에서 제어될 수 있다.

예:

```css
/* global.css */
article h2 {
  margin-top: 3rem;
}
```

```css
/* ArticleLayout.astro */
.prose h2 {
  margin-top: 2.5rem;
}
```

```css
/* 특정 문서 Component */
h2 {
  margin-top: 2rem;
}
```

어떤 규칙이 적용되는지 추적하기 어려워진다.

### 권장 책임 분리

```text
Global
→ Reset, Token, 기본 Document 설정

Layout
→ Page width, Grid, major regions

Component
→ 컴포넌트 내부 표현

Prose
→ Markdown 본문 요소

Utility
→ 소수의 반복적인 단일 목적
```

Markdown 본문 Typography를 일반 Component CSS와 섞지 않는다.
