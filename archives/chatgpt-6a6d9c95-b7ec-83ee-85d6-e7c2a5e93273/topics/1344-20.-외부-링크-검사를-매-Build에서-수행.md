# 20. 외부 링크 검사를 매 Build에서 수행

외부 링크는 네트워크 상태와 상대 서버 정책에 따라 불안정하다.

```text
403
429
Timeout
Bot 차단
지역 제한
```

따라서 PR마다 모든 외부 링크를 검사하면 Flaky CI가 된다.

권장:

```text
내부 링크
→ 모든 Build에서 Error

외부 링크
→ 정기 Audit에서 Warning
```
