# 1. 전체 문서 생명주기

권장 흐름은 다음과 같다.

```text
Idea
→ Draft
→ Technical Review
→ Editorial Review
→ Ready
→ Published
→ Maintained
→ Historical / Superseded / Archived
```

하지만 이 상태를 모두 front matter enum으로 만들 필요는 없다.

문서에 필요한 축은 크게 두 개다.

```text
발행 상태
+
콘텐츠 유효 상태
```
