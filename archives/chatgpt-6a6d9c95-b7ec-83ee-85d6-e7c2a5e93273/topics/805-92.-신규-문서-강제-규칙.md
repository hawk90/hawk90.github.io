# 92. 신규 문서 강제 규칙

기존 글은 Legacy 허용, 신규 글은 strict를 적용하려면 기준이 필요하다.

가능한 방법:

```text
특정 날짜 이후 작성
특정 디렉터리
Git diff 신규 파일
```

가장 안정적인 것은 Git diff 기반 CI다.

```text
새로 추가된 Markdown
→ strict schema 적용
```

기존 글 수정 시에는 대표 문서 여부에 따라 적용한다.
