# 4. Breadcrumb

예:

```text
Home
→ PCIe & CXL
→ PCIe BAR 크기는 어떻게 탐색되는가
```

## 역할

```text
현재 위치 표시
상위 Topic으로 돌아가기
검색엔진과 접근성에 계층 제공
```

## 피해야 할 것

파일 시스템 구조를 그대로 표시하는 것.

```text
Home
→ Posts
→ 2024
→ Hardware
→ PCIe
→ BAR
```

독자는 저장소 경로가 아니라 지식 구조를 이해해야 한다.
