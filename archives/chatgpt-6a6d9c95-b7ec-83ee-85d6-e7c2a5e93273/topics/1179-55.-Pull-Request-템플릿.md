# 55. Pull Request 템플릿

문서 변경 전용 체크리스트를 둘 수 있다.

```markdown
## Content change

- [ ] 신규 문서
- [ ] 기술 내용 수정
- [ ] 상태 변경
- [ ] URL 변경
- [ ] 관계 변경

## Verification

- [ ] Environment documented
- [ ] Claims verified
- [ ] Internal links checked
- [ ] Sensitive data removed
- [ ] Mobile article reviewed
```

혼자 작업하더라도 검수 기록이 남는다.
