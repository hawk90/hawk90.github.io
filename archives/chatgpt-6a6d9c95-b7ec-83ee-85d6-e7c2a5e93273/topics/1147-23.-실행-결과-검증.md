# 23. 실행 결과 검증

작은 예제는 예상 출력을 함께 지정할 수 있다.

```yaml
example:
  command: ./build/vector_add
  expectedExitCode: 0
```

하지만 복잡한 CUDA·FPGA·Kernel 예제를 일반 CI에서 실행하려고 하지 않는다.

환경별 검증 수준을 구분한다.

```text
Syntax checked
Compiled
Executed
Hardware verified
```
