# 98. `requireDocuments`

```ts
export function requireDocuments(
  ids: readonly string[],
  manifest: ContentManifest,
): ContentDocument[] {
  return ids.map((id) => {
    const document =
      manifest.byId.get(id);

    if (!document) {
      throw new Error(
        `Required content document ` +
        `"${id}" was not found.`,
      );
    }

    return document;
  });
}
```

Manifest validation이 먼저 실행됐다면 여기서 실패할 가능성은 낮다.

그래도 조용히 무시하지 않는다.
