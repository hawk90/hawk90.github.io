# 27. 분리 유지 기준

```text
문서 타입이 다름
검색 의도가 다름
버전 문맥이 다름
독립 실험이 있음
소스 분석과 개념 설명이 구분됨
초보·고급 대상이 명확히 다름
```

예:

```text
Concept:
PCIe BAR의 동작 원리

Source Walkthrough:
Linux가 PCI Resource를 등록하는 코드 흐름

Debug Note:
U250에서 BAR 접근이 실패한 사례
```

세 문서는 서로 연결하되 통합하지 않는다.
