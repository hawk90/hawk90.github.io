# 8. 테스트 데이터가 Production 모델을 그대로 복제

테스트 폴더에 별도 인터페이스를 만들어 Production 모델과 거의 동일한 구조를 유지할 수 있다.

```ts
interface TestContentDocument {
  ...
}
```

그러면 모델 변경 시 Production과 Test 모델이 따로 drift한다.

테스트는 실제 타입을 사용하고, 생성 Helper만 제공하는 편이 낫다.
