# 61. 사이트의 콘텐츠 품질을 한 번에 고치려 함

AdSense 재신청 전:

```text
500개 전부 수정
```

은 비현실적이다.

더 효과적인 접근은 **색인 표면 축소와 대표 콘텐츠 강화**다.

## 1단계

```text
빈·얕은 목록 noindex
검색·Pagination 광고 제외
Draft·Placeholder 제거
```

## 2단계

```text
대표 기술 문서 10~20개 강화
핵심 Topic Hub 3~5개 작성
About·Privacy 정리
```

## 3단계

```text
중복·구판 정리
내부 링크를 대표 글 중심으로 변경
Sitemap 정리
```

## 4단계

```text
Search Console에서 색인 상태 확인
운영 사이트 직접 검토
재신청
```
