# D-16. 관련 글 추천 재설계

기존 태그 기반 추천이 있다면 제거부터 하지 말고 우선순위를 바꾼다.

## 추천 신호 순서

```text
명시적 관계
동일 Series
동일 세부 Topic
본문 링크
동일 콘텐츠 타입
공통 Tag
```

## 추천 슬롯

```text
다음에 읽을 글
필요한 선행 개념
같은 문제의 실전 사례
```

각 슬롯 하나씩이면 충분하다.

## fallback

명시적 관계가 없으면:

```text
상위 Topic Hub
```

하나만 보여줘도 된다.

억지 관련 글 6개보다 낫다.
