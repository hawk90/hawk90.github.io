# 89. `package.json` Script가 실제로 동작하는지 미검증

문서에는:

```text
npm run content:check
```

가 있지만 Script 이름이 바뀌거나 깨질 수 있다.

CI에서 공개된 핵심 명령을 직접 실행한다.

README 예제까지 전부 자동 실행할 필요는 없지만 사용자-facing 명령은 보호한다.
