# 13. 테스트가 코드 중복을 허용하지 않음

Production과 Test에 일부 유사 코드가 있다고 무조건 Helper로 추출하면 테스트 읽기가 어려워질 수 있다.

예:

```ts
const current =
  createDocumentFixture({
    id: "current",
    status: "current",
  });
```

정도는 반복돼도 테스트 의도가 명확하다.

테스트 코드는 완벽한 DRY보다 가독성이 우선일 수 있다.
