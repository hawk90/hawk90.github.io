# 6. 빈 배열을 기본값으로 사용

다음처럼 optional 배열을 많이 사용하면 Query마다 분기가 생긴다.

```ts
prerequisites?: string[];
next?: string[];
related?: string[];
```

권장:

```ts
relations: {
  prerequisites: [],
  next: [],
  related: [],
}
```

정규화 단계에서 빈 배열로 만든다.
