# 13. 제목만 있고 설명이 없는 글 목록

카드:

```text
PCIe BAR
2023-05-21
```

이 정보만으로 사용자는 다음을 알 수 없다.

```text
개념 설명인가?
디버깅 기록인가?
Linux 코드 분석인가?
현재도 유효한가?
```

목록 페이지의 카드가 너무 얇으면 목록 전체도 가치가 낮아 보일 수 있다.

## 카드 최소 정보

```text
명확한 제목
한두 문장의 고유 Description
Topic 또는 문서 타입
필요하면 Historical 상태
```

태그 10개와 읽기 시간보다 설명이 중요하다.
