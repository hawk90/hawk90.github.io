# 93. 최소 구현 범위

1차 구현은 다음이면 충분하다.

```text
문서 타입별 생성기
draft 기본값
변경 문서 validation
대표 문서 validation
content:review 명령
content:publish dry-run
Freshness report
문서 발행 체크리스트
```

후속:

```text
Code Snippet compile
중복 문서 후보
AI-assisted relation suggestions
Editorial Dashboard
예약 발행
```
