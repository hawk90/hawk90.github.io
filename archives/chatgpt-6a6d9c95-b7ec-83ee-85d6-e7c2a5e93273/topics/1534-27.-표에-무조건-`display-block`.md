# 27. 표에 무조건 `display: block`

모바일 Overflow를 해결하려고 모든 `table`에:

```css
display: block;
overflow-x: auto;
```

를 적용하면 Table Layout이나 접근성에 예기치 않은 영향을 줄 수 있다.

Wrapper를 사용하는 편이 명확하다.

```html
<div class="table-scroll">
  <table>...</table>
</div>
```

Markdown Pipeline에서 자동 Wrapper를 생성할 수 있다.
