# 86. Symbol 추출

자동 추출은 후보만 만든다.

```text
snake_case
camelCase
namespace::symbol
UPPER_CASE_MACRO
```

너무 일반적인 symbol은 제외한다.

```text
main
size
data
value
```

대표 문서에는 front matter에서 명시적으로 보완할 수 있다.

```yaml
symbols:
  - pci_scan_child_bus
  - pci_bus_add_devices
```
