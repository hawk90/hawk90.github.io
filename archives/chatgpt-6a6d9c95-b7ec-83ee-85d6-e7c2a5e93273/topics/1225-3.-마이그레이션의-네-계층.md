# 3. 마이그레이션의 네 계층

기존 콘텐츠를 네 단계로 나눈다.

```text
Tier 1: Representative
Tier 2: Valuable
Tier 3: Legacy
Tier 4: Remove or Merge
```

---

## Tier 1. Representative

사이트의 전문성을 대표할 문서.

초기 목표:

```text
20개 선정
10개 완성
```

조건:

```text
직접 경험·실험·소스 분석이 있음
현재도 검색 가치가 높음
Topic Hub의 진입점이 될 수 있음
다른 글의 선행 개념임
보완 비용 대비 가치가 높음
```

처리:

```text
type/topic/status 명시
Description 재작성
기술 재검증
환경·범위 추가
관계 설정
모바일 검토
Featured·Start Here 후보
```

---

## Tier 2. Valuable

대표 문서까지는 아니지만 독립적인 가치가 있는 글.

예:

```text
특정 오류 해결 기록
함수 하나의 코드 분석
짧은 실험 결과
명령·레지스터 Reference
과거 환경의 희귀한 해결법
```

처리:

```text
최소 Metadata
상위 Topic 연결
상태 명시
필요하면 Historical
대표 문서에서 관련 사례로 연결
```

모든 Tier 2 문서를 대규모로 다시 쓰지는 않는다.

---

## Tier 3. Legacy

현재 품질 기준은 부족하지만 즉시 삭제할 이유도 없는 글.

예:

```text
짧은 학습 메모
일반적인 공식 문서 요약
맥락이 부족한 코드 조각
오래된 설치 기록
검증 상태를 알 수 없는 글
```

처리:

```text
기본 노출 유지
대표 경로에서는 제외
필요하면 needs-review
Sitemap·검색 정책 선별
향후 검토 Queue
```

Legacy 문서 때문에 전체 마이그레이션이 막히지 않게 한다.

---

## Tier 4. Remove or Merge

독립 페이지로 유지할 가치가 낮은 글.

예:

```text
내용이 거의 없는 Placeholder
동일 검색 의도의 중복 글
신판에 완전히 흡수된 글
링크 모음만 있는 페이지
제목과 한두 문장뿐인 메모
테스트용 게시물
```

처리:

```text
통합
Redirect
Superseded
Archive
삭제
```
