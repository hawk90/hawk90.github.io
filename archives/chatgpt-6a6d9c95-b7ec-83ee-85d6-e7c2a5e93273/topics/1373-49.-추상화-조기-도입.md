# 49. 추상화 조기 도입

Topic Hub가 두 개뿐인데 모든 가능한 Hub Variant를 지원하는 Framework를 먼저 만들 수 있다.

```text
Section Plugin
Dynamic Renderer
Schema-driven UI
Block Registry
```

실제 Hub 두 개를 먼저 구현하고 중복이 확인된 부분만 추출한다.

```text
첫 번째 구현
→ 두 번째 구현
→ 실제 공통점 확인
→ 추상화
```

순서가 맞다.
