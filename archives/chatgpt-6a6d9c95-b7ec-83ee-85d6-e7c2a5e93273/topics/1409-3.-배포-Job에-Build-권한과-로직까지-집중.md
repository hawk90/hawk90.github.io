# 3. 배포 Job에 Build 권한과 로직까지 집중

다음처럼 하나의 Job이 모든 것을 수행할 수 있다.

```text
Checkout
Install
Build
Test
Secret 접근
Pages 배포
Release 작성
```

문제는 배포 권한이 필요한 Job에서 임의 코드와 의존성 설치까지 실행된다는 점이다.

더 안전한 경계:

```text
Build Job
- Repository read
- Secret 최소화
- dist Artifact 생성

Deploy Job
- Artifact 다운로드
- Pages 배포만 수행
- 필요한 배포 권한만 부여
```

Deploy Job에서 `npm install`이나 콘텐츠 Script를 다시 실행하지 않는다.
