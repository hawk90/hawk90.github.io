# 52. 삭제 대상 후보

새 구조가 안정되면 다음을 찾는다.

```text
중복 Markdown parser
태그별 front matter loader
검색 전용 content loader
Sitemap 전용 loader
컴포넌트 내부 status 조건
Home 전용 featured flag
거대한 utils.ts
사용하지 않는 admin route
중복 date formatter
```

삭제는 새 구조가 동일 기능을 제공하는 것이 확인된 뒤 한다.
