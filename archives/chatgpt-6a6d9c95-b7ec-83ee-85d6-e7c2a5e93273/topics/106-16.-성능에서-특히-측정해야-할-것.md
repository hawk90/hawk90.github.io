# 16. 성능에서 특히 측정해야 할 것

내가 현재 공개 페이지와 저장소 구조만 보고 확정할 수 없는 부분이 있다.

실제 다음 수치는 Lighthouse, PageSpeed Insights, Chrome DevTools, Search Console로 측정해야 한다.

```text
초기 HTML 크기
CSS 크기
초기 JavaScript 크기
검색 인덱스 크기
폰트 다운로드 크기
LCP 자원
CLS 원인
INP 병목
페이지별 이미지 크기
Giscus 로딩 비용
AdSense 삽입 후 변화
```

따라서 이번 리뷰에서 “느리다”고 단정하는 것은 부정확하다.

대신 구조상 반드시 측정해야 하는 후보를 정할 수 있다.

## 페이지 유형별 측정

### 홈

- Hero 이미지
- 최신 글 카드
- 폰트
- ClientRouter

### 일반 글

- 코드 블록 0개
- 코드 블록 10개
- 코드 블록 100개 이상
- 수식 포함
- 다이어그램 포함

### 검색

- 검색 버튼 클릭부터 입력 가능 시점
- 인덱스 다운로드 크기
- JSON parse 시간
- 첫 결과 표시 시간

### 댓글 포함 글

- Giscus 로딩 전후
- CLS
- 네트워크 요청 증가
