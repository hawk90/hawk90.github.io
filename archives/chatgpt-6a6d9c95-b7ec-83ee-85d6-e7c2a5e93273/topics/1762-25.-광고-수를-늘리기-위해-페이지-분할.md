# 25. 광고 수를 늘리기 위해 페이지 분할

하나의 글을:

```text
PCIe BAR 1편
PCIe BAR 2편
PCIe BAR 3편
PCIe BAR 4편
```

으로 불필요하게 나누면 각 페이지가 얕아질 수 있다.

## 분할이 적합한 경우

```text
검색 의도가 다름
각 편이 독립된 결론을 가짐
문서 타입이 다름
코드·실험 범위가 분리됨
```

## 분할이 부적합한 경우

```text
단순히 글이 김
광고 노출 증가
페이지뷰 증가
```
