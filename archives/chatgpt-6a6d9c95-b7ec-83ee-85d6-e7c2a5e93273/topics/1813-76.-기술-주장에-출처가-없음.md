# 76. 기술 주장에 출처가 없음

특히 다음 주장은 출처 또는 범위가 필요하다.

```text
사양 요구사항
API 지원 여부
성능 수치
버전별 변경
하드웨어 동작
```

출처가 없으면 독자가 사실과 개인 추론을 구분하기 어렵다.

Google의 사람 중심 콘텐츠 안내도 명확한 출처와 전문성의 근거를 신뢰 신호로 점검하도록 한다. citeturn517910search3

## 출처 유형

```text
공식 사양
공식 문서
소스코드 Tag·Commit
직접 실험
논문
```

검색 결과 상위 블로그를 다시 인용하는 것보다 원자료가 낫다.
