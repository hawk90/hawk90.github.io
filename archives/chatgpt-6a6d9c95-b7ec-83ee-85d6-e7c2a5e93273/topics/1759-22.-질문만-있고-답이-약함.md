# 22. 질문만 있고 답이 약함

제목:

```text
왜 shared memory는 빠른가?
```

본문:

```text
Shared memory는 on-chip memory이므로 global memory보다 빠르다.
```

맞는 말이지만 사용자의 실제 질문은 더 깊을 수 있다.

```text
Latency인가 Bandwidth인가?
Bank는 어떻게 구성되는가?
Register와 비교하면?
동기화 비용은?
어떤 경우 느려지는가?
```

독립 페이지라면 제목이 약속한 질문의 실질적인 범위를 해결해야 한다.
