# 주간 작업량이 부족할 때 축소 순서

시간이 부족하면 다음 순서로 범위를 줄인다.

## 반드시 유지

```text
대표 문서
Topic Hub
홈 구조
색인 정리
About·Privacy
```

## 그다음 유지

```text
검색 baseline
canonical
Sitemap
내부 링크 검사
```

## 나중으로 이동

```text
Content Manifest 고도화
증분 빌드
Visual regression
CSP
OG 자동화
```

즉, 콘텐츠와 정보 구조를 플랫폼 최적화보다 먼저 유지한다.
