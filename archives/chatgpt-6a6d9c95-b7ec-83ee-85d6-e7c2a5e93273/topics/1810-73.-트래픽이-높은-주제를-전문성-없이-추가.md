# 73. 트래픽이 높은 주제를 전문성 없이 추가

예:

```text
ChatGPT 사용법
AI 부업
추천 노트북
```

같은 주제를 검색량만 보고 추가하면 다른 사이트와 차별성이 없다.

새 주제가 들어올 조건:

```text
기존 경험과 연결
직접 실험 가능
현재 독자와 연결
사이트 중심을 강화
```

예를 들어 AI를 다룬다면:

```text
AI 코딩 도구의 C++ 코드 분석 차이
CUDA 코드 생성 검증
펌웨어에서 AI 도구를 안전하게 쓰는 방법
```

처럼 호크의 전문 영역과 연결하는 편이 낫다.
