# Task 3-1. 실제 개선 백로그 설계

이제부터는 안티패턴 카탈로그를 더 늘리지 않고, 실제 `hawk90.github.io` 개선 작업으로 바꾼다.

이번 단계의 목표는 다음이다.

```text
문제
→ 작업
→ 수정 위치
→ 완료 조건
→ 기대 효과
```

우선 전체 백로그를 다섯 묶음으로 나눈다.

```text
A. 사이트 정체성과 홈
B. Topic Hub와 대표 글
C. 콘텐츠 신뢰성과 상태
D. 검색·빌드·운영
E. AdSense 재신청 준비
```

이번에는 가장 우선순위가 높은 **Epic A: 사이트 정체성과 홈 개편**부터 시작한다.
