# C-19. 대표 글의 하단 관계 추가

대표 글 20개에만 우선 적용한다.

```yaml
prerequisites:
  - pcie-configuration-space
next:
  - pcie-msix
related:
  - linux-pci-enumeration
```

## 노출 우선순위

```text
상위 Topic
필수 선행 1~2개
다음 단계 1개
실전 사례 1개
```

너무 많은 링크를 넣지 않는다.

## 완료 조건

- 대표 글에 dead end가 없음
- 같은 글이 여러 슬롯에 반복되지 않음
- `superseded` 글이 추천되지 않음
- 링크 이유가 UI에 표시됨
