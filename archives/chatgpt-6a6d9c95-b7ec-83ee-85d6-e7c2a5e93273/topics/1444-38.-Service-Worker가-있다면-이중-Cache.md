# 38. Service Worker가 있다면 이중 Cache

브라우저 HTTP Cache와 Service Worker Cache가 동시에 존재하면 장애 분석이 어려워진다.

```text
CDN은 최신
브라우저 Cache는 최신
Service Worker는 과거
```

같은 상황이 생긴다.

PWA가 핵심 요구가 아니라면 제거가 가장 단순한 해결책이다.

유지한다면 Cache Version과 정리 정책을 테스트한다.
