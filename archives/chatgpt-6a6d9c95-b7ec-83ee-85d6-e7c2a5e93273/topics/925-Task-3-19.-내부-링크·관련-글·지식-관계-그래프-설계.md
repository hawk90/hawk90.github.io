# Task 3-19. 내부 링크·관련 글·지식 관계 그래프 설계

앞에서는 검색을 통해 **원하는 글을 찾는 구조**를 만들었다.

이번 태스크는 사용자가 글 하나를 읽은 뒤:

```text
어디에서 왔는지
무엇을 먼저 알아야 하는지
다음에는 무엇을 읽어야 하는지
같은 문제의 실전 사례가 무엇인지
```

를 알 수 있게 만드는 단계다.

핵심은 단순한 `관련 글 6개`가 아니다.

> 문서 사이의 관계에 의미를 부여해, 개별 글을 하나의 학습 구조로 연결하는 것이다.
