# 28. 404와 오류 화면에 광고

404는 게시자가 작성한 일반 콘텐츠 페이지가 아니다.

```text
페이지를 찾을 수 없습니다
광고
```

구조는 피한다.

광고 제외 대상:

```text
404
검색
빈 목록
Login·Admin
오류 페이지
Redirect 페이지
```

광고 대상은 독립 콘텐츠가 있는 실제 Article과 충분히 작성된 Hub 중심으로 제한한다.
