# 43. Astro Island 경계

Hydration이 필요한 컴포넌트만 Island로 만든다.

## Hydration 필요 가능

```text
검색 modal
테마 전환
댓글 로드 버튼
이미지 확대
```

## Hydration 불필요

```text
Topic Card
Featured Guide
Status Notice
Article Relations
Learning Path
Metadata
```

나쁜 예:

```astro
<FeaturedGuides client:load />
```

정적 목록인데도 client runtime을 추가한다.
