# 22. 코드 블록의 이중 스크롤

다음 구조에서 발생할 수 있다.

```text
Article Container Scroll
→ Code Wrapper Scroll
→ Inner pre Scroll
```

사용자가 두 스크롤 영역을 만나게 된다.

가로 스크롤은 한 요소에서만 담당한다.

```text
Code Frame
→ Header 고정
→ pre가 overflow-x 담당
```

또는 Wrapper 하나가 전체를 담당한다.
