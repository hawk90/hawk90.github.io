# Task 3-7. 보안·개인정보·GitHub Actions 정비 백로그

이번 단계의 목표는 정적 블로그에 필요한 수준까지만 보안을 강화하는 것이다.

```text
공개 사이트는 단순하게
관리 기능은 별도 경계로
외부 스크립트는 최소화
CI 권한은 필요한 만큼만
민감 정보는 배포 전에 차단
```

핵심 원칙은 다음이다.

> 정적 사이트의 가장 좋은 보안 설계는 복잡한 방어 시스템이 아니라, 쓰기 권한과 비밀 정보가 공개 빌드 경로에 들어오지 않게 만드는 것이다.
