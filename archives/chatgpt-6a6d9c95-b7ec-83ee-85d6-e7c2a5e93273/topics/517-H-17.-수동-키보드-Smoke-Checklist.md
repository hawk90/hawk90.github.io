# H-17. 수동 키보드 Smoke Checklist

자동화가 놓치는 핵심 흐름만 짧게 확인한다.

```text
[ ] Skip link로 본문 이동
[ ] Header 메뉴 접근
[ ] 검색 열기·닫기
[ ] 검색 결과 선택
[ ] Topic Hub Start Here 순서 탐색
[ ] 코드 복사 버튼 접근
[ ] Heading permalink 접근
[ ] 댓글 열기 기능 접근
```

## 완료 조건

- 마우스 없이 핵심 탐색 가능
- focus indicator가 모든 인터랙션에서 보임
- modal 뒤쪽으로 focus가 빠지지 않음
- 카드가 실제 `<a>` 또는 `<button>`으로 구현됨
