# 36. 빌드 산출물 디렉터리

```text
.generated/
├── manifest/
├── search/
├── og/
├── diagrams/
└── reports/
```

또는 `.cache/`와 `public/generated/`를 구분한다.

## `.cache/`

재생성 가능한 중간 결과.

```text
문서별 검색 레코드
Shiki 캐시
hash metadata
```

## `public/generated/`

배포되는 생성 결과.

```text
OG 이미지
SVG
검색 JSON
```

## `reports/`

사람이 검토할 감사 결과.

```text
고아 문서
중복 후보
대형 코드 블록
깨진 외부 링크
```
