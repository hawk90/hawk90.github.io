# 30. Sticky Header가 Anchor를 가림

TOC나 외부 링크로 Heading Anchor에 이동했는데 고정 Header 뒤에 제목이 숨을 수 있다.

다음 속성을 고려한다.

```css
scroll-margin-top: ...;
```

대상:

```text
H2
H3
Footnote
Named Anchor
```

Header 높이를 여러 CSS 파일에서 각각 하드코딩하지 않는다.
