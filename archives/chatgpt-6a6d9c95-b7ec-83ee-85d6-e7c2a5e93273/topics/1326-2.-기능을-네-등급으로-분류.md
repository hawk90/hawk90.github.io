# 2. 기능을 네 등급으로 분류

모든 기존 기능을 다음 네 가지로 분류한다.

## A. Core

사이트가 존재하는 이유와 직접 연결된다.

```text
Article rendering
Topic navigation
내부 링크
검색
코드 표시
SEO 기본 Metadata
Sitemap
RSS
```

## B. Supporting

핵심 경험을 보조하지만 실패해도 글은 읽혀야 한다.

```text
댓글
Analytics
AdSense
OG 이미지
테마 전환
이미지 확대
```

## C. Editorial

작성자에게만 필요한 기능이다.

```text
콘텐츠 검증
링크 검사
Migration script
품질 Report
문서 생성기
```

## D. Questionable

실제 사용 가치가 불명확한 기능이다.

```text
관리자 웹 UI
브라우저 내 Markdown 편집
공개 Dashboard
과도한 검색 필터
PWA
오프라인 전체 글 Cache
실시간 통계
```

핵심 문제는 C와 D가 공개 사이트 번들에 섞이는 것이다.
