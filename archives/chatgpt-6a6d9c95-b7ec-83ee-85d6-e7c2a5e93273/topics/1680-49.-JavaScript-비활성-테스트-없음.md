# 49. JavaScript 비활성 테스트 없음

Astro 정적 사이트의 핵심 장점은 JavaScript 없이도 콘텐츠를 읽고 탐색할 수 있다는 것이다.

최소 Smoke Test:

```text
JavaScript 비활성
→ 홈 콘텐츠 표시
→ Topic 링크 이동
→ Article 본문 표시
→ Breadcrumb 이동
```

검색 Dialog·댓글 등만 사용할 수 없어도 된다.
