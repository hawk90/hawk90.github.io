# 23. PWA 안티패턴

PWA는 매력적으로 보이지만 기술 블로그에 반드시 필요한 것은 아니다.

추가되는 복잡도:

```text
Service Worker
Cache version
오래된 HTML
오래된 Search Index
Offline fallback
배포 후 Cache invalidation
```

특히 문서를 수정했는데 사용자가 오래된 Service Worker Cache를 계속 보는 문제가 생긴다.

실제 오프라인 요구가 확인되지 않았다면 제거 후보가 될 수 있다.
