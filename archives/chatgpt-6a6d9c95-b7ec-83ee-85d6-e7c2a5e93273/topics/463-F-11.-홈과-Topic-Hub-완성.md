# F-11. 홈과 Topic Hub 완성

AdSense 재신청 전에 최소한 다음 구조가 실제로 배포돼 있어야 한다.

```text
홈
├── 사이트 목적
├── Core Topics
├── Featured Guides
└── Latest Posts

Topic Hub
├── 주제 설명
├── Start Here
├── Core Concepts
├── Featured Guides
└── Debug & Experiments
```

### 최소 완료 범위

```text
PCIe & CXL Hub
Firmware & Bootloader Hub
대표 글 8개 이상 연결
```

### 완료 조건

- 홈이 최신 글 목록으로만 구성되지 않음
- 핵심 주제와 대표 문서가 첫 방문에서 확인됨
- Hub가 단순 카드 자동 목록이 아님
- 모든 Featured 문서가 `current`

### 우선순위

```text
P0
```
