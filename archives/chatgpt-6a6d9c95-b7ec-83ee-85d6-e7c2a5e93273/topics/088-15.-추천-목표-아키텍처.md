# 15. 추천 목표 아키텍처

```text
Markdown Content
        │
        ▼
Astro Content Collections
        │
        ├── Article rendering
        ├── Topic/Series graph
        ├── Search documents
        ├── RSS/Sitemap
        └── OG metadata
        │
        ▼
Static HTML
        │
        ├── Minimal navigation JS
        ├── Search loaded on demand
        ├── Giscus loaded on demand
        └── Optional view transitions
```

핵심 원칙은 다음과 같다.

```text
HTML이 제품
JavaScript는 보조 기능
Markdown이 원본
생성물은 재현 가능
검색은 지연 로드
테마보다 콘텐츠가 우선
```
