# 81. 문서 생성부터 발행까지 명령 예

```bash
npm run content:new -- \
  --type concept \
  --topic pcie-cxl \
  --title "PCIe BAR 크기는 어떻게 탐색되는가"
```

작성 후:

```bash
npm run content:review -- pcie-bar-size-probing
```

발행 Dry Run:

```bash
npm run content:publish -- \
  pcie-bar-size-probing \
  --status current \
  --dry-run
```

최종 발행:

```bash
npm run content:publish -- \
  pcie-bar-size-probing \
  --status current
```
