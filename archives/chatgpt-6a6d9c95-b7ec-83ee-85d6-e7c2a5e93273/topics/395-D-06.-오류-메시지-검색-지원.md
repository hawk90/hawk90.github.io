# D-06. 오류 메시지 검색 지원

Debug Note의 강점은 정확한 오류 문자열 검색이다.

예:

```text
device not found
failed to load xclbin
no space for BAR
unknown code model
```

## 권장 방법

본문에서 명시적으로 표시된 오류 블록만 추출한다.

```md
```text title="Error"
failed to load xclbin
```
```

또는 front matter:

```yaml
errorMessages:
  - failed to load xclbin
```

## 피해야 할 것

모든 로그 줄을 인덱싱하는 것.

## 완료 조건

- 대표 오류 메시지로 해당 Debug Note 검색 가능
- 일반 단어 검색에서 로그 문서가 과도하게 상위 노출되지 않음
