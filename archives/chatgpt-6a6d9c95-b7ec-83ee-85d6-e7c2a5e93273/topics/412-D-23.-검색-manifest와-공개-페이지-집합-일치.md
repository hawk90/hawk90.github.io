# D-23. 검색 manifest와 공개 페이지 집합 일치

다음 집합은 공통 publication policy에서 생성해야 한다.

```text
공개 페이지
검색 인덱스
Sitemap
RSS
Topic Hub 자동 목록
```

## 불변조건

```text
draft → 어디에도 없음
archived → 일반 검색 기본 제외
superseded → Sitemap 정책에 따라 제한
공개하지 않은 페이지 → 검색 레코드 없음
```

이 규칙이 각 generator에 따로 구현되면 드리프트가 발생한다.
