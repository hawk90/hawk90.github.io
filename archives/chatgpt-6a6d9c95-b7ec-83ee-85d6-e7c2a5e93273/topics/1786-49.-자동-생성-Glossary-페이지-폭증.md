# 49. 자동 생성 Glossary 페이지 폭증

기술 용어마다:

```text
/terms/bar/
/terms/dma/
/terms/irq/
/terms/msi/
```

를 생성할 수 있다.

정의 한두 줄뿐이면 얕은 페이지가 대량으로 생긴다.

## 대안

```text
Topic별 Glossary 한 페이지
Article 내부 Definition
검색 Alias Registry
Reference 문서에 통합
```

독립 Glossary URL은 충분한 설명과 관계가 있을 때만 만든다.
