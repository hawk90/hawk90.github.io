# H-20. 코드 블록 회귀 검사

기술 블로그의 핵심 UI다.

## 시나리오

```text
짧은 코드
긴 코드
긴 한 줄
한글 주석
로그
명령과 출력
line highlight
파일명 표시
복사
```

## 검사

```text
강제 wrap 여부
가로 스크롤
복사 결과 원문 일치
복사 버튼 겹침
line number alignment
다크모드 대비
```

## 복사 결과

UI용 line number나 강조 markup이 clipboard에 들어가면 안 된다.

```text
화면:
1 int main() {

복사:
int main() {
```

## 완료 조건

- 코드 원문이 정확히 복사됨
- 모바일에서 첫 줄이 버튼에 가리지 않음
- 로그·출력이 불필요한 syntax grammar를 사용하지 않음
- 장문 코드 페이지 DOM 회귀 추적
