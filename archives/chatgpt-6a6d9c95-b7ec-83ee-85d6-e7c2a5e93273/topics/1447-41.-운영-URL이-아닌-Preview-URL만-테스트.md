# 41. 운영 URL이 아닌 Preview URL만 테스트

로컬 Preview는 GitHub Pages의 Base Path·Header·404 동작을 완전히 재현하지 못할 수 있다.

다음 계층을 구분한다.

```text
Local Dist Server
→ HTML·자산 기본 검증

Preview Deployment
→ Base·Routing 검증

Production Smoke
→ 실제 Domain·HTTPS·CDN 검증
```

모든 Commit마다 Production을 상세 테스트할 필요는 없지만 배포 직후 핵심 Smoke는 가치가 있다.
