# 6. Metadata 우선순위

모든 metadata를 같은 크기의 Badge로 나열하지 않는다.

## 높은 우선순위

```text
문서 타입
Topic
상태
검증 시점
```

## 중간 우선순위

```text
작성일
수정일
환경
난이도
```

## 낮은 우선순위

```text
읽기 시간
태그
문서 ID
단어 수
```

읽기 시간을 보여주더라도 기술 문서는 코드와 실험 때문에 일반적인 분당 단어 계산이 부정확할 수 있다.

필수 정보는 아니다.
