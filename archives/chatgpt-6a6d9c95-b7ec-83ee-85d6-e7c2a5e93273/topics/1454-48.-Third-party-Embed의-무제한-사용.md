# 48. Third-party Embed의 무제한 사용

YouTube, CodePen, GitHub Gist, Slideshare 등의 Embed가 많으면 각 서비스 장애와 개인정보 요청에 영향을 받는다.

권장:

```text
정적 Preview
→ 사용자가 클릭
→ 실제 Embed 로드
```

또는 핵심 코드·이미지는 로컬 콘텐츠로 제공하고 외부 자료는 보조 링크로 둔다.
