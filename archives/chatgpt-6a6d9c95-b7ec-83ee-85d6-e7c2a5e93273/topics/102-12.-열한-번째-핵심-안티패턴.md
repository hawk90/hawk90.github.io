# 12. 열한 번째 핵심 안티패턴

## Tag Vocabulary Drift  
### 태그 이름이 시간이 지나면서 분열됨

기술 블로그에서 흔한 사례다.

```text
cpp
c++
modern-c++
cplusplus
cxx
```

또는:

```text
embedded
firmware
bsp
bootloader
u-boot
uefi
```

이들은 모두 필요할 수도 있지만 분류 원칙이 없으면 태그가 계속 증가한다.

### 태그 역할을 제한해야 함

태그는 계층 구조가 아니다.

태그는 다음처럼 **횡단 속성**에 적합하다.

```text
performance
debugging
postmortem
tutorial
benchmark
linux
hardware
```

반면 핵심 주제는 Topic이나 Category로 관리하는 편이 좋다.

```text
C++
CUDA
PCIe
CXL
Firmware
Linux Kernel
```

### 추천 규칙

```text
Topic:
글이 속한 핵심 지식 분야

Type:
글의 콘텐츠 역할

Tag:
여러 분야를 가로지르는 보조 특성
```

예:

```yaml
topics:
  - pcie
  - firmware

type: source-walkthrough

tags:
  - debugging
  - u-boot
```
