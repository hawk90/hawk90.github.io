# 65. 중앙 Migration Registry

```ts
export interface MigrationRecord {
  documentId: string;
  tier: MigrationTier;
  action: MigrationAction;
  reviewed: boolean;
  notes?: readonly string[];
}
```

장점:

```text
마이그레이션 진행률 확인
문서 Front Matter 오염 방지
작업 우선순위 관리
```

Migration이 끝나면 Registry를 줄이거나 삭제할 수 있다.
