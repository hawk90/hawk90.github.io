# 60. 회사 내부 경험을 그대로 공개하거나 전부 제거

두 극단 모두 문제다.

## 그대로 공개

```text
기밀
내부 Host
고객 정보
비공개 설계
```

위험.

## 전부 제거

실제 경험이 사라지고 일반론만 남음.

## 적절한 방식

```text
민감 식별자는 일반화
기술적 조건은 유지
직접 관찰과 판단은 보존
```

예:

```text
사내 bm09 서버
```

대신:

```text
CentOS 7.9 기반 FPGA Build Host
```

로 표현한다.
