# 20. 코드만 있고 설명이 없음

페이지:

```cpp
template <typename T>
void foo(T value) {
    ...
}
```

그 아래 설명이 거의 없다.

코드는 게시자 콘텐츠이지만, 검색 사용자가 다음을 이해할 수 있어야 한다.

```text
무슨 문제를 해결하는가
왜 이 구조인가
어떤 제약이 있는가
어떻게 실행하는가
결과는 무엇인가
```

GitHub 저장소 Raw Code와 블로그 문서의 차이는 설명과 판단이다.
