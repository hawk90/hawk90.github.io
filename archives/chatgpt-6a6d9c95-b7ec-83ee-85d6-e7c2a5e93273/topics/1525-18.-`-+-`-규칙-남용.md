# 18. `* + *` 규칙 남용

```css
.prose > * + * {
  margin-top: 1.5rem;
}
```

는 단순하지만 다음 조합에서 세밀한 제어가 어렵다.

```text
Heading 다음 문단
Figure 다음 Caption
List 다음 List
Code 다음 설명
Callout 다음 Heading
```

기본 Rhythm에는 사용할 수 있지만 의미 있는 인접 조합을 Override해야 한다.
