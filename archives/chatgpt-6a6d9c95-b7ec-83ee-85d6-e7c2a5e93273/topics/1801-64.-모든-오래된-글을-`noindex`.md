# 64. 모든 오래된 글을 `noindex`

오래됐다는 사실만으로 가치가 낮은 것은 아니다.

다음은 오래돼도 안정적일 수 있다.

```text
container_of 원리
PCIe BAR 기본 구조
C++ Template 명시적 인스턴스화
Shared Memory Bank 기본
```

반면 최근 글도 얕을 수 있다.

판단 기준:

```text
현재 유효성
고유성
검색 질문 해결
환경 명확성
대체 문서 존재
```
