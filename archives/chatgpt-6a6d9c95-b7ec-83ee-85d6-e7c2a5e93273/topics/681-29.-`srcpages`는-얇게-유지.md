# 29. `src/pages`는 얇게 유지

권장:

```text
src/pages/
├── index.astro
├── articles/
│   └── [...slug].astro
├── topics/
│   └── [topic].astro
├── search.astro
├── about.astro
├── privacy.astro
└── 404.astro
```

페이지 역할:

```text
데이터 query 호출
View Model 생성
Layout 선택
Component 조합
```

페이지에서 하지 않을 것:

```text
전체 문서 relation 계산
검색 인덱스 생성
Publication Policy 구현
Topic registry 정의
복잡한 metadata validation
```
