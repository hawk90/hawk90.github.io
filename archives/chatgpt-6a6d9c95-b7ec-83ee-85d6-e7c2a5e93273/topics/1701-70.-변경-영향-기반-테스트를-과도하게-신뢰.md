# 70. 변경 영향 기반 테스트를 과도하게 신뢰

Markdown 하나만 바뀌었다고 해당 페이지 테스트만 실행하면 다음 영향을 놓칠 수 있다.

```text
Home Featured
Topic Hub
Search Index
RSS
Sitemap
Related Graph
```

변경 파일 기반 최적화를 하더라도 전체 Manifest 불변조건과 주요 파생 Artifact는 검사해야 한다.
