# 42. 상태 전역 Store를 만들지 않기

Astro 정적 사이트에서는 다음 상태가 대부분 빌드 타임 데이터다.

```text
Topic
Featured
Content Status
Relations
Search Metadata
```

이를 Nanostores, Redux, Zustand 같은 client store에 넣을 이유가 없다.

Client state가 필요한 것은 제한적이다.

```text
검색 modal open
테마 선택
코드 복사 상태
모바일 메뉴
```

Content Domain은 정적 HTML로 렌더링한다.
