# 70. Validation Profile

```ts
export type ValidationProfile =
  | "legacy"
  | "representative"
  | "strict";
```

## Legacy

기존 콘텐츠 호환.

```text
필수 구조 오류만 차단
```

## Representative

대표 문서·Featured 기준.

```text
type/topic/status/description 필수
```

## Strict

신규 콘텐츠 기준.

```text
모든 metadata와 관계 정책 강제
```

문서별 profile을 metadata에 넣기보다 큐레이션 집합과 경로에 따라 적용한다.
