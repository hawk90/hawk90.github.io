# 23. 관련 실전 사례

Concept 문서에는 Debug Note를 연결하는 것이 강력하다.

예:

```text
Concept
PCIe BAR Size Probing

관련 실전 사례
BAR mapping은 성공했지만 유효한 값이 나오지 않은 사례
```

반대로 Debug Note에는 Concept를 prerequisite로 연결한다.

```text
Debug Note
U250 BAR mmap 실패

먼저 읽을 글
PCIe BAR와 MMIO
```

이 구조가 이론과 경험을 연결한다.
