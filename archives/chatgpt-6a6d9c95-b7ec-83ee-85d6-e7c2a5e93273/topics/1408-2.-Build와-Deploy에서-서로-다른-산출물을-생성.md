# 2. Build와 Deploy에서 서로 다른 산출물을 생성

위험한 구조:

```text
Job A
→ Build
→ Test

Job B
→ 다시 Checkout
→ 다시 Install
→ 다시 Build
→ Deploy
```

테스트한 산출물과 실제 배포한 산출물이 다르다.

두 번째 Build에서 다음이 달라질 수 있다.

```text
Dependency Resolution
환경변수
현재 시간
외부 API 응답
생성 파일 순서
캐시 상태
```

권장:

```text
Build once
→ dist Artifact 저장
→ 같은 Artifact 검증
→ 같은 Artifact 배포
```

---

## 불변조건

```text
검증한 bytes
=
배포한 bytes
```

가 되어야 한다.
