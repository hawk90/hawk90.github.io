# 37. Generated 파일을 Git에 넣을지

항목마다 다르다.

## Git에 넣기 좋은 것

```text
Hub curation
Topic registry
redirect manifest
editorial report 중 사람이 관리하는 감사표
```

## 빌드 시 생성하는 것

```text
검색 인덱스
Sitemap
RSS
relation graph
build metrics
```

## 상황에 따라 저장

```text
OG 이미지
다이어그램 SVG
```

재현 비용이 높거나 외부 도구가 필요하면 결과물도 Git에 둘 수 있다.

다만 source와 generated를 명확히 구분한다.
