# 5. 다섯 번째 핵심 안티패턴

## Multi-Language Tooling Tax  
### 운영 도구 언어가 늘어남

현재 빌드와 감사 체계에는 최소한 다음 언어가 사용된다.

```text
JavaScript / MJS
Python
Bash
TypeScript
Astro
```

각 언어를 쓴 이유는 이해된다.

- Astro와 OG: JavaScript
- 콘텐츠 분석: Python
- 다이어그램: Bash
- 타입과 UI: TypeScript

문제는 규모가 커지면 실행 환경이 복잡해진다는 것이다.

### 발생 가능한 문제

- Node만 설치하면 빌드가 안 됨
- Python 버전 차이
- Bash가 Windows에서 동작하지 않음
- Python package dependency가 숨겨짐
- 스크립트별 인코딩 처리 차이
- YAML parser 동작 차이
- 날짜 파싱 차이
- glob 규칙 차이

### 반드시 통일할 필요는 없음

모든 스크립트를 TypeScript로 다시 쓰는 것도 비용이다.

대신 다음을 명확히 해야 한다.

```text
지원 운영체제
필수 런타임 버전
외부 명령
설치 방법
입력과 출력
실패 코드
```

예:

```text
Node 22.12+
Python 3.12+
Bash 5+
LaTeX/TikZ optional
```
