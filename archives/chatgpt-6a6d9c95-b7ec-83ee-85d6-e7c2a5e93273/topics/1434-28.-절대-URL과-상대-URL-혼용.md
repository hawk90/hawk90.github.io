# 28. 절대 URL과 상대 URL 혼용

페이지 내부 자산은 상대·Base-aware URL이 적합할 수 있고, 다음은 절대 URL이 필요하다.

```text
Canonical
Open Graph URL
Sitemap
RSS
Structured Data
```

용도별 URL 생성기를 분리한다.

```ts
buildInternalPath()
buildAbsoluteUrl()
```

모든 위치에서 `SITE.origin + path`를 반복하지 않는다.
