# 47. 광고 Script 실패 시 본문 렌더 차단

광고 Script를 `<head>`의 Blocking 형태로 넣거나, 초기 JavaScript가 광고 초기화를 기다리면 읽기 경험이 외부 광고 서비스에 종속된다.

광고는 다음 특성을 가져야 한다.

```text
비동기
본문 독립
실패 허용
Layout Shift 제한
```

승인 전에는 광고 Script 자체가 없어도 사이트가 완전해야 한다.
