# 8. Confidence를 결과가 아니라 후보 근거로 사용

예:

```json
{
  "value": "pcie-cxl",
  "confidence": "high",
  "reasons": [
    "Existing category is PCIe",
    "Title contains BAR",
    "Body contains lspci and pci_resource"
  ]
}
```

이렇게 하면 사용자가 왜 해당 Topic이 제안됐는지 판단할 수 있다.

단순히:

```text
Topic: PCIe
Confidence: 92%
```

만 보여주는 것보다 낫다.
