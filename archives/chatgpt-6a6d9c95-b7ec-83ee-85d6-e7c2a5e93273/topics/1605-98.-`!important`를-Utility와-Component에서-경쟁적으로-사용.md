# 98. `!important`를 Utility와 Component에서 경쟁적으로 사용

Tailwind의 `!` Modifier, Inline Style, Global `!important`가 섞이면 Theme와 Responsive Override가 어려워진다.

`!important`는 Accessibility Override나 외부 Embed 격리처럼 제한적인 목적에 사용한다.
