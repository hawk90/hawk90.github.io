# 3. 작성 흐름을 너무 세분화하지 않기

다음처럼 상태를 지나치게 늘리지 않는다.

```text
idea
outline
writing
editing
technical-review
copy-review
seo-review
approved
scheduled
published
monitoring
```

개인 블로그에서 이 정도 워크플로는 운영되지 않을 가능성이 높다.

실제 필요한 체크포인트는 다음 네 단계다.

```text
1. 초안
2. 기술 검증
3. 편집 검수
4. 발행
```
