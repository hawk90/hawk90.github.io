# 13. Node·Astro 업데이트와 콘텐츠 변경을 함께 배포

예:

```text
Astro Major Update
Markdown Plugin 변경
대표 문서 30개 수정
홈 개편
```

을 한 번에 배포하면 문제가 생겼을 때 원인을 찾기 어렵다.

권장 분리:

```text
Platform Upgrade
→ Canary Build
→ Deploy 확인

Content Change
→ 별도 Commit
```

특히 Markdown Renderer 업데이트는 수백 개 글의 HTML을 바꿀 수 있다.
