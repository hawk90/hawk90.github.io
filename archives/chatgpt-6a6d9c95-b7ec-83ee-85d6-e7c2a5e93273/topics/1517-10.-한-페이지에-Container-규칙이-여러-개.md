# 10. 한 페이지에 Container 규칙이 여러 개

예:

```css
.header-inner {
  max-width: 1200px;
}

.main {
  max-width: 1100px;
}

.footer-inner {
  max-width: 1280px;
}

.article {
  max-width: 760px;
}
```

각각 이유가 있을 수 있지만 시각적 축이 맞지 않으면 페이지가 좌우로 흔들려 보인다.

권장 Container 역할:

```text
Site Container
→ Header, Footer, Hub

Reading Column
→ 일반 문단

Wide Content
→ 표, 코드, 다이어그램
```

이 세 가지 정도로 명확히 구분한다.
