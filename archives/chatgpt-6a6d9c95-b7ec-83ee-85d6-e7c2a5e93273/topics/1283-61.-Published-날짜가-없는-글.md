# 61. Published 날짜가 없는 글

가능한 근거:

```text
기존 Front Matter
파일명 날짜
Git 최초 Commit
기존 URL
```

우선순위:

```text
기존 명시값
→ 파일명
→ Git 최초 추가 시점
→ 수동 확인
```

Git history가 대량 이동·Import를 거쳤다면 실제 발행일과 다를 수 있다.

불확실한 경우 날짜를 만들어내지 않고 Migration Note에 기록한다.
