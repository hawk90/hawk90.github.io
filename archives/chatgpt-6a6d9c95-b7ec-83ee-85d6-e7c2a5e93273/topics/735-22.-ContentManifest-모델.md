# 22. ContentManifest 모델

```ts
export interface ContentManifest {
  documents: readonly ContentDocument[];

  byId: ReadonlyMap<
    string,
    ContentDocument
  >;

  byUrl: ReadonlyMap<
    string,
    ContentDocument
  >;

  byTopic: ReadonlyMap<
    string,
    readonly ContentDocument[]
  >;
}
```

추가 index가 필요하면 만들 수 있다.

```text
byStatus
byType
```

하지만 처음부터 모든 조합을 Map으로 만들 필요는 없다.

문서가 수백 개 수준이라면 배열 filter도 충분히 빠르다.
