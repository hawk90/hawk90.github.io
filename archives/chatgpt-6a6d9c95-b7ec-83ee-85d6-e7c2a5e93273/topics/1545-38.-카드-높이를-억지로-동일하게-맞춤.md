# 38. 카드 높이를 억지로 동일하게 맞춤

Grid를 정돈하려고 다음을 사용할 수 있다.

```text
Description 2줄 제한
Title 2줄 제한
고정 높이
```

하지만 긴 한국어 제목이나 기술 식별자가 잘리면서 의미가 손실될 수 있다.

Featured 카드에서는 제목과 설명을 충분히 보여주는 것이 우선이다.

일반 Archive 목록에서는 짧은 Description Clamp가 가능하다.

카드 역할마다 정책이 달라야 한다.
