# 41. 의존성 규칙 예시

```text
src/domain
- src/components import 금지
- src/layouts import 금지
- browser API 사용 금지

src/components
- scripts import 금지
- content file 직접 glob 금지

src/pages
- raw Markdown 직접 parse 금지

scripts
- components import 금지
```

이 규칙은 ESLint boundary plugin 없이도 초기에는 리뷰 원칙으로 운영할 수 있다.

문제가 반복되면 자동 lint를 추가한다.
