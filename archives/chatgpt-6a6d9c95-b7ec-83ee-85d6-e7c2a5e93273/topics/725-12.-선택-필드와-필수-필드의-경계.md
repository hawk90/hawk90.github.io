# 12. 선택 필드와 필수 필드의 경계

## 대표 문서 필수

```text
id
title
description
type
status
topicId
publishedAt
```

## 기존 글 호환을 위해 선택 가능

```text
lastVerifiedAt
testedWith
aliases
symbols
errorMessages
relations
```

## 관계 배열은 `undefined`보다 빈 배열 권장

```ts
relations: {
  prerequisites: [],
  next: [],
  related: [],
}
```

이렇게 하면 모든 Query가 null check를 반복하지 않는다.
