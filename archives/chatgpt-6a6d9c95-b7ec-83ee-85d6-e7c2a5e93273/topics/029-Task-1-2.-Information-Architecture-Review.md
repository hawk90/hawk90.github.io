# Task 1-2. Information Architecture Review

> "좋은 글"과
>
> "좋은 지식 사이트"는 다르다.

대부분 기술 블로그는

```
좋은 글
+
좋은 글
+
좋은 글
```

이다.

하지만 Wikipedia나 cppreference는

```
지식 구조

↓

문서

↓

세부 문서

↓

관련 문서
```

이다.

이 차이가 엄청 크다.
