# 38. Fixture가 Production 콘텐츠와 자동 동기화

실제 글 하나를 Fixture로 직접 참조하면 글을 편집할 때 테스트 의미도 바뀐다.

Canary 문서가 필요하다면:

```text
Production 글을 읽는 Smoke Test
```

와:

```text
고정 테스트 Fixture
```

를 구분한다.

고정 Fixture는 특정 문제를 재현하는 최소 입력으로 유지한다.
