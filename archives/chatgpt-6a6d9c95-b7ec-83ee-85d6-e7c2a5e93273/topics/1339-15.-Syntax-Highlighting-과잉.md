# 15. Syntax Highlighting 과잉

기술 블로그에서 Shiki 같은 빌드 타임 Highlight는 유용하다.

하지만 다음 기능이 모두 필요한지는 별개다.

```text
두 가지 테마 Token 동시 생성
Line Number
Diff
Focus Line
Word Highlight
파일명
복사
언어 Badge
```

각 기능이 HTML 노드 수와 CSS를 늘린다.

대표 문서에서 실제로 사용하는 기능만 유지한다.
