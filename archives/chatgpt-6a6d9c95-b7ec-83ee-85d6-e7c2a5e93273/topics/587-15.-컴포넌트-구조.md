# 15. 컴포넌트 구조

권장 구조:

```text
TopicHubLayout
├── TopicHero
├── StartHereList
├── SystemFlow
├── ConceptGrid
├── FeaturedGuideList
├── LearningPathList
├── DebugSection
├── RelatedTopicList
└── ArticleArchive
```

## 피해야 할 것

```text
PCIeHubCard
CXLHubCard
BARHubCard
MSIXHubCard
```

각 Topic 전용 컴포넌트를 계속 추가하지 않는다.

## 카드 유형

3개 정도면 충분하다.

```text
StartHereCard
ContentCard
ConceptEntry
```

Learning Path는 카드보다 순서 있는 목록이 더 적합하다.
