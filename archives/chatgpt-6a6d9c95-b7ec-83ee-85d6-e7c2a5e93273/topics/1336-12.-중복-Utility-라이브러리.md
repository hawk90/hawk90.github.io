# 12. 중복 Utility 라이브러리

대표 사례:

```text
date-fns + dayjs
lodash + 자체 collection helper
Fuse.js + MiniSearch
Prism + Shiki
marked + remark
```

각 라이브러리가 실제로 다른 역할을 하는지 확인한다.

예를 들어 Astro가 이미 Markdown pipeline을 제공하는데 별도 parser가 검색·감사용으로 또 존재하면 콘텐츠를 여러 번 처리하게 된다.
