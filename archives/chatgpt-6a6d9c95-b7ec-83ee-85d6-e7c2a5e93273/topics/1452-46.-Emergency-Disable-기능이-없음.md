# 46. Emergency Disable 기능이 없음

외부 Integration이 문제를 일으킬 때 전체 코드를 수정하지 않고 끌 수 있으면 유용하다.

예:

```text
AdSense
Comments
Analytics
Broken Embed
```

하지만 Feature Flag를 무한히 유지하지 않는다.

통합 설정 한 곳에서:

```ts
export const INTEGRATIONS = {
  ads: false,
  comments: true,
  analytics: true,
};
```

정도로 관리한다.

콘텐츠·Home V1/V2 같은 장기 Feature Flag와는 다르다.
