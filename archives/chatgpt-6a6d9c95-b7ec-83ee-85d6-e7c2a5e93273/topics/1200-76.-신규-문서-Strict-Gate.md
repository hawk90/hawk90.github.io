# 76. 신규 문서 Strict Gate

신규 문서는 처음부터 높은 기준을 적용한다.

필수:

```text
id
title
description
type
topic
status
draft
published
```

발행 시:

```text
내부 링크
환경·범위 검토
관계
Secret Scan
모바일
```

기존 Legacy 문서 때문에 신규 문서 기준까지 낮추지 않는다.
