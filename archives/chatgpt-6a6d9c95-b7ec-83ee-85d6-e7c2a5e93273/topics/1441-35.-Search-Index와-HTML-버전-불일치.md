# 35. Search Index와 HTML 버전 불일치

새 HTML은 배포됐지만 CDN·Service Worker가 과거 Search Index를 제공할 수 있다.

그 결과:

```text
검색 결과에 삭제된 URL
신규 글 검색 불가
SearchDocument Schema 오류
```

해결:

```text
Content-hashed Search Index 파일
HTML이 정확한 Hash URL 참조
Schema Version 검사
```

예:

```text
/search/index.4e91ac.json
```
