## 내가 생각하는 가장 큰 문제

사실 애드센스보다 더 큰 문제가 하나 보여.

**네 글은 좋은데 "도서관"이 아니다.**

예를 들어

```
UEFI

PCIe

CXL

Bootloader

Compiler
```

글이 각각 존재하는 것과

```
System Programming

├── Computer Architecture

├── Firmware

├── Linux

├── C++

├── Compiler

├── CXL

├── PCIe

└── Bootloader
```

처럼 연결되는 것은 완전히 다른 사이트야.

후자가 되면 방문자는 한 글만 읽고 나가는 것이 아니라 자연스럽게 여러 글을 탐색하게 된다.
