# 51. 내부 링크가 Redirect를 거치지 않게 한다

기존 글 URL을 변경했을 때 내부 링크가 구주소를 계속 가리킬 수 있다.

외부 사용자는 Redirect로 이동해도 되지만, 내부 링크는 최종 canonical을 직접 가리켜야 한다.

감사:

```text
internal URL
→ redirect registry 확인
→ 최종 target로 수정 제안
```
