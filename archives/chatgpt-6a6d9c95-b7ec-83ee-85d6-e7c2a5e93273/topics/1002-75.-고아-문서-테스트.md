# 75. 고아 문서 테스트

```ts
it("reports public documents with no semantic inbound path", () => {
  const report =
    findOrphanDocuments(
      manifest,
      relationGraph,
      topicCuration,
    );

  expect(
    report.map(
      (item) => item.documentId,
    ),
  ).toContain("isolated-document");
});
```
