# 44. 검색 Island

검색은 별도 경계로 격리한다.

```text
SearchButton.astro
SearchDialog.ts
SearchIndexLoader.ts
SearchEngine.ts
```

흐름:

```text
검색 버튼 클릭
→ Dialog module 로드
→ Search index fetch
→ Search engine 초기화
```

초기 페이지 로드에서는 검색 인덱스를 받지 않는다.
