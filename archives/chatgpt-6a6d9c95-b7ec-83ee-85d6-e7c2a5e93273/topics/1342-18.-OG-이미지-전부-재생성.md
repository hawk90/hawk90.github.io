# 18. OG 이미지 전부 재생성

모든 Build에서 500개 글의 OG 이미지를 다시 만들면 비용이 크다.

안티패턴:

```text
본문 한 문장 수정
→ OG 500장 재생성
```

권장 Cache Key:

```text
title
description
topic
template version
font version
```

이 값이 바뀐 문서만 생성한다.

OG 생성 실패가 모든 문서의 본문 Build를 막아야 하는지도 따로 판단한다.
