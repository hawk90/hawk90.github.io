# 46. Git 변경 기반 검수

매번 500개 문서를 모두 수동 검토할 필요는 없다.

```bash
npm run content:review:changed
```

Git diff에서 변경된 Markdown을 찾고:

```text
schema
internal links
type별 구조
secret
redaction 후보
```

를 검사한다.

전체 Manifest 무결성은 별도로 항상 확인한다.
