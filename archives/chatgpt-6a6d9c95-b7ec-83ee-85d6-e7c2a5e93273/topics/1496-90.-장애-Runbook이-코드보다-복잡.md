# 90. 장애 Runbook이 코드보다 복잡

개인 사이트 Runbook은 짧아야 한다.

예:

```text
1. GitHub Deployment에서 현재 Commit 확인
2. Home·대표 Article·Search Index 확인
3. 직전 정상 Commit 식별
4. Revert 또는 정상 Artifact 재배포
5. Custom Domain·Pages 상태 확인
6. 원인 수정은 복구 후 진행
```

별도 운영 플랫폼을 만들 필요는 없다.
