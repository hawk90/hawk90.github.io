# 34. Web Font 과잉

다음 구성이 흔하다.

```text
본문 Font
Heading Font
Code Font
한글 Font
영문 Font
Variable Font
여러 Weight
```

한글 Web Font는 파일이 커질 수 있다.

검토:

```text
실제로 사용하는 Weight
System Font 대체 가능성
Subset
font-display
Code Font 필요성
```

폰트가 차단돼도 Layout과 가독성이 유지돼야 한다.
