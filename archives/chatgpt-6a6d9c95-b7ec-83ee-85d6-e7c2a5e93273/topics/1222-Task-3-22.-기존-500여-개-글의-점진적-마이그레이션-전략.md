# Task 3-22. 기존 500여 개 글의 점진적 마이그레이션 전략

앞에서는 앞으로 작성할 문서의 작성·검수·발행 흐름을 설계했다.

하지만 `hawk90.github.io`의 현실적인 핵심 문제는 신규 글보다 **이미 쌓여 있는 수백 개의 기존 글**이다.

> 기존 콘텐츠를 전면 재작성하지 않고, 사이트를 계속 운영하면서 가치 있는 글부터 새로운 지식베이스 구조로 옮긴다.
