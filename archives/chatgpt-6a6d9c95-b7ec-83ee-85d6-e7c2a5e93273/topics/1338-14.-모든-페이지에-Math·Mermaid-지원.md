# 14. 모든 페이지에 Math·Mermaid 지원

수식이나 Mermaid를 사용하는 글이 극소수인데 전역 Pipeline과 자산을 추가하면 낭비다.

권장:

```text
해당 문법이 있는 문서만 감지
→ 필요한 변환 실행
```

또는 작성 시 SVG로 생성해 정적 자산으로 저장한다.

특히 Mermaid Client Runtime을 모든 Article에 넣지 않는다.
