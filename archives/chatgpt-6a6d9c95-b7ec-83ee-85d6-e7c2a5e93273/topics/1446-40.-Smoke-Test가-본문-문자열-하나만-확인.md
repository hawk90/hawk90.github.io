# 40. Smoke Test가 본문 문자열 하나만 확인

예:

```text
Home contains "Hawk"
```

만 검사하면 CSS가 깨져도 통과한다.

권장 검사:

```text
HTTP Status
Content-Type
필수 Title
Canonical
Main element
대표 자산 Link
Draft 문자열 부재
```

브라우저 테스트에서는 대표 페이지의 Console Error도 확인한다.
