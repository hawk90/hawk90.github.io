# 7. Tested Environment 모델

모든 분야를 하나의 거대한 고정 구조로 만들지 않는다.

```ts
export interface TestedEnvironment {
  os?: string;
  kernel?: string;
  architecture?: string;

  compiler?: string;
  toolchain?: string;

  hardware?: string;
  sdk?: string;
  runtime?: string;

  notes?: readonly string[];
}
```

예:

```yaml
testedWith:
  os: CentOS 7.9
  kernel: 3.10.0-1160
  architecture: x86_64
  hardware: AMD Alveo U250
  sdk: XRT 2.13.466
  toolchain: Vivado 2021.2
```

CUDA 글:

```yaml
testedWith:
  os: Windows 11
  architecture: x86_64
  hardware: NVIDIA GTX 1070
  sdk: CUDA 11.8
  compiler: MSVC 2019
```

## 피해야 할 구조

```ts
interface TestedEnvironment {
  cudaVersion?: string;
  xrtVersion?: string;
  vivadoVersion?: string;
  linuxVersion?: string;
  rustVersion?: string;
  nodeVersion?: string;
  ...
}
```

새 기술이 추가될 때마다 Domain 모델이 비대해진다.
