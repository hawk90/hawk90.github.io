# 67. 모든 ‘Crawled, currently not indexed’를 오류로 봄

검색엔진이 모든 URL을 색인할 의무는 없다.

Sitemap도 색인을 보장하지 않는다. citeturn517910search38

해당 URL을 보고 판단한다.

```text
색인될 가치가 충분한가?
다른 문서와 중복되는가?
내용이 너무 짧은가?
대표 URL이 따로 있는가?
내부 링크가 있는가?
```

색인되지 않은 모든 페이지를 억지로 늘리지 않는다.
