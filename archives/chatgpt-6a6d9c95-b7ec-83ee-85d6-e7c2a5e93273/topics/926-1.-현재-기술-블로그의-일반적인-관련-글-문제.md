# 1. 현재 기술 블로그의 일반적인 관련 글 문제

대부분 관련 글은 다음 방식으로 생성된다.

```text
같은 태그
+
같은 카테고리
+
최신 글
```

예를 들어 `PCIe BAR` 문서 아래에 다음이 나올 수 있다.

```text
PCIe 6.0 동향
CXL 3.0 소개
U250 설치 방법
Rust PCIe 라이브러리
```

모두 PCIe 태그를 공유하지만, 독자가 BAR 글을 읽은 뒤 실제로 필요한 문서는 아닐 수 있다.
