# 74. Type별 Layout Variant

완전히 별도 Layout을 여섯 개 만들 필요는 없다.

공통 Article Layout 안에서 타입별 선택 섹션을 사용한다.

예:

```text
Experiment
→ Environment와 Results 강조

Debug Note
→ Symptom·Cause·Resolution Navigation 강조

Reference
→ TOC와 빠른 조회표 강조
```

구조가 크게 다를 때만 별도 템플릿을 고려한다.
