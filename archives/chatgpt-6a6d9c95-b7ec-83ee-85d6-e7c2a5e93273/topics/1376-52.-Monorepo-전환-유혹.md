# 52. Monorepo 전환 유혹

사이트, 콘텐츠 도구, 공통 UI를 분리한다며:

```text
apps/site
packages/content
packages/ui
packages/search
packages/config
```

로 만들 수 있다.

재사용 대상이 실제로 하나뿐이라면 Monorepo는 다음을 추가한다.

```text
Workspace 설정
Package build
Version 경계
Import 경계
Task runner
```

현재는 단일 Astro 프로젝트 안의 디렉터리 경계로 충분하다.
