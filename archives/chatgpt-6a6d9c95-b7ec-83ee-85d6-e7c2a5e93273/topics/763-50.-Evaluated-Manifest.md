# 50. Evaluated Manifest

```ts
export interface EvaluatedManifest {
  entries: readonly EvaluatedDocument[];

  byId: ReadonlyMap<
    string,
    EvaluatedDocument
  >;
}
```

하지만 `ContentManifest`와 `EvaluatedManifest`를 모두 전역으로 관리하면 복잡해질 수 있다.

초기에는 build context에서 한 번 만들어 전달하면 충분하다.
