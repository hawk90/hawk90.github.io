# 28. View Model을 무조건 만들 필요는 없다

다음처럼 단순한 컴포넌트에는 Domain Model을 직접 전달해도 된다.

```text
StatusNotice
TestedEnvironment
```

View Model은 다음 상황에서 사용한다.

```text
여러 Domain 객체 결합
날짜·라벨 포맷 필요
노출 조건 복잡
컴포넌트가 Domain 세부사항을 알아서는 안 됨
```

모든 컴포넌트마다 별도 View Model을 만들면 보일러플레이트가 늘어난다.
