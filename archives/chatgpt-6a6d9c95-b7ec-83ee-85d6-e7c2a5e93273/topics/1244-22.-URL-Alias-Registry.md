# 22. URL Alias Registry

```ts
export interface LegacyUrlEntry {
  from: string;
  documentId: string;
  action:
    | "preserve"
    | "redirect"
    | "gone";
}
```

예:

```ts
export const LEGACY_URLS = [
  {
    from: "/posts/pcie-bar/",
    documentId: "pcie-bar-sizing",
    action: "preserve",
  },
] as const;
```

URL 마이그레이션을 문서 관계와 분리해 관리한다.
