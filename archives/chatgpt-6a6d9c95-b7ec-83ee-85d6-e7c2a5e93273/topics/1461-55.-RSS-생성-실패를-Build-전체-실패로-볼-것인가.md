# 55. RSS 생성 실패를 Build 전체 실패로 볼 것인가

RSS가 사이트 핵심 기능이라면 실패를 차단하는 것이 맞다.

하지만 Legacy 문서 하나의 잘못된 날짜 때문에 전체 사이트를 배포하지 못하는 상황도 고려해야 한다.

정책:

```text
RSS 대상 Current 문서 오류
→ Error

RSS에서 제외되는 Legacy 문서 오류
→ Warning 또는 해당 문서 제외
```

단, 조용히 콘텐츠를 누락시키지 말고 Report에 남긴다.
