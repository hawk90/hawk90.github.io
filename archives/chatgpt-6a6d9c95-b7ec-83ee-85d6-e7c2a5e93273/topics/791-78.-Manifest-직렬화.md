# 78. Manifest 직렬화

빌드 디버깅과 다른 script에서 사용할 수 있도록 JSON으로 저장할 수 있다.

```ts
export interface SerializedContentDocument {
  id: string;
  url: string;
  title: string;
  type: ContentType;
  status: ContentStatus;
  topicId: string;
  contentHash: string;
}
```

전체 내부 정보를 모두 공개 artifact에 넣지 않는다.

## 내부 Manifest

```text
sourcePath
전체 links
relation
```
