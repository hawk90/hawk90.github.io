# 99. CSS Cascade Layer를 도입하고 순서를 이해하지 못함

`@layer`는 유용하지만:

```text
reset
base
components
utilities
overrides
```

순서를 명확히 하지 않으면 Scoped CSS와 Utility 간 우선순위가 예상과 다를 수 있다.

도입한다면 CSS Architecture 문서에 Layer 책임을 짧게 기록한다.
