# B-17. Hub 큐레이션과 자동 목록 분리

Hub의 모든 콘텐츠를 수동으로 적으면 최신 글 반영이 어렵다.

반대로 전부 자동 생성하면 태그 페이지와 같아진다.

따라서 두 영역을 분리한다.

## 수동 큐레이션

```text
Start Here
Featured Guides
Core Concepts
```

## 자동 생성 가능

```text
Recently Updated
All Articles
Debug Notes
Experiments
```

이 방식이 균형이 좋다.
