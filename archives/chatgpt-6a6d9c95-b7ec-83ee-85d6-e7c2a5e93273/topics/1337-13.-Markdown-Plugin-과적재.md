# 13. Markdown Plugin 과적재

Remark·Rehype Plugin은 편리하지만 문서마다 실행된다.

다음 Plugin이 연쇄적으로 붙을 수 있다.

```text
GFM
Heading slug
Autolink
TOC
Footnote
Math
Mermaid
Callout
Code title
Code line number
External link
Image optimization
Reading time
```

글 하나에는 가벼워 보여도 500개 문서에서는 누적 비용이 커진다.

### 검토 질문

```text
모든 문서에 필요한가?
특정 문서에서만 쓰는가?
Plugin끼리 AST를 반복 순회하는가?
같은 기능을 두 Plugin이 처리하는가?
```
