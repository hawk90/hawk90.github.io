# 20. 경고 개수만 비교

Warning 1개가 사라지고 다른 위험한 Warning 1개가 생겨도 총 개수는 같다.

가능하면 Rule ID와 Document ID 기준으로 Baseline을 관리한다.

```text
content/missing-description: old-post-1
content/unclassified-topic: old-post-2
```

새로운 조합이 추가되면 감지한다.
