# 추천 최소 관계 모델

처음부터 복잡하게 만들 필요는 없다.

```yaml
parent:
prerequisites:
next:
related:
supersedes:
```

이 정도면 충분하다.

예:

```yaml
parent: pcie
prerequisites:
  - pcie-configuration-space
next:
  - pcie-msi-x
related:
  - linux-pci-enumeration
supersedes: null
```

자동 추천은 이 명시 관계를 대체하지 않고 보조해야 한다.
