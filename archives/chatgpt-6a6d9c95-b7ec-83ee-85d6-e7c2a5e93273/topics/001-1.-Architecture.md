# 1. Architecture

## 1. Static Site인데 SPA처럼 만듦

- React가 대부분 차지
- Hydration 과다
- Client Component 남발
- 페이지보다 App이 됨

---

## 2. Layer가 너무 많음

예)

```
Markdown
↓

MDX
↓

Remark

↓

Rehype

↓

Astro

↓

Vite

↓

Rollup

↓

GitHub Pages
```

중간 Plugin이 계속 늘어남.

---

## 3. Plugin Hell

```
remark-x
remark-y
remark-z
rehype-a
rehype-b
rehype-c
```

하나 버전 올리면 전부 깨짐.

---

## 4. Theme가 Core보다 큼

테마 수정하려고

```
100줄 수정
```

했는데

```
1000줄 override
```

되는 상황.

---

## 5. Framework Lock-in

Astro 전용 문법

```
<Component />
Astro.props
```

이 너무 많으면

다른 SSG로 못 감.

---

## 6. Content와 Rendering이 분리 안됨

Markdown 안에

```
<Component />

<ClientOnly>

<script>
```

가득.

Markdown이 Markdown이 아님.

---

## 7. Routing과 Category가 결합

```
/cpp/basic
/cpp/advanced
```

나중에

```
compiler
```

카테고리 추가하면 URL 전부 수정.
