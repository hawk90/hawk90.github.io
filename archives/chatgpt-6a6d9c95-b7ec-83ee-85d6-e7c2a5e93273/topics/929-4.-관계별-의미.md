# 4. 관계별 의미

## `parentTopic`

이 글이 속한 대표 Topic Hub.

예:

```yaml
topic: pcie-cxl
```

UI:

```text
상위 주제
PCIe & CXL
```

---

## `prerequisites`

현재 글을 이해하기 전에 알아야 하는 문서.

예:

```yaml
prerequisites:
  - pcie-configuration-space
  - memory-mapped-io
```

UI:

```text
먼저 읽으면 좋은 글
1. PCIe Configuration Space
2. Memory-Mapped I/O
```

---

## `next`

현재 글을 읽은 뒤 이어지는 학습 단계.

예:

```yaml
next:
  - linux-pci-resource
  - pcie-msix
```

UI:

```text
다음 단계
1. Linux는 PCIe Resource를 어떻게 등록하는가
2. MSI-X는 어떻게 설정되는가
```

---

## `related`

직접적인 선행·후행 관계는 아니지만 주제 이해에 도움이 되는 문서.

예:

```yaml
related:
  - u250-bar-mmap-debug
  - vfio-pcie-passthrough
```

UI:

```text
관련 실전 사례
```

단순 `관련 글`보다 관계 이유를 설명하는 편이 낫다.

---

## `supersededBy`

현재 글을 대체하는 신판.

```yaml
status: superseded
supersededBy: modern-pcie-bar-guide
```

UI:

```text
이 문서는 새 글로 대체되었습니다.

현재 문서:
PCIe BAR 크기 탐색과 주소 할당
```
