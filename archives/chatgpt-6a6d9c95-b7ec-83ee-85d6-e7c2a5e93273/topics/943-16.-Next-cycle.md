# 16. Next cycle

다음 관계도 문제가 될 수 있다.

```text
A.next = B
B.next = C
C.next = A
```

하지만 `next`가 하나의 고정된 강의 순서가 아니라 여러 추천 경로라면 cycle이 반드시 오류는 아니다.

권장 정책:

```text
Learning Path 내부 next cycle
→ Error

일반 문서 next cycle
→ Warning
```
