# 14. 하나의 테스트에서 모든 상태를 검증

나쁜 예:

```ts
it("handles publication states", () => {
  // current
  // historical
  // superseded
  // archived
  // draft
  // future document
});
```

중간 Assertion이 실패하면 어떤 계약이 깨졌는지 파악하기 어렵다.

상태 Matrix를 사용하더라도 각 Case가 독립적인 테스트 이름으로 출력되게 한다.
