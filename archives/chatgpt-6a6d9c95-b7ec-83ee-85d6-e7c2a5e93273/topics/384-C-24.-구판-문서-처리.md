# C-24. 구판 문서 처리

구판을 무조건 삭제하지 않는다.

## Historical로 둘 조건

- 과거 버전 유지 사용자에게 유용
- 기술 변화 기록 가치가 있음
- 다른 자료에서 참조함
- 당시 장애 해결 과정이 고유함

## Superseded로 둘 조건

- 같은 검색 의도의 신판이 있음
- 기존 글보다 명확하고 완전한 문서가 있음
- 두 글을 동시에 유지하면 혼동됨

## Redirect를 고려할 조건

- 기존 글의 고유 가치가 거의 없음
- 신판이 내용을 완전히 포함
- 외부 링크가 새 글로 가도 문맥이 자연스러움
