# 87. Manifest Version

Schema와 extractor가 변경되면 생성 캐시를 무효화해야 한다.

```ts
export const CONTENT_MANIFEST_VERSION =
  "1";
```

Hash 입력에 포함한다.

```ts
createContentHash({
  sourceText,
  normalizedMetadata,
  extractorVersion:
    CONTENT_MANIFEST_VERSION,
});
```
