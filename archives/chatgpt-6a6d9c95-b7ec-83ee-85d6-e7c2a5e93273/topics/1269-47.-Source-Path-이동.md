# 47. Source Path 이동

폴더 구조를 정리하고 싶어도 URL과 본문 Migration과 동시에 하지 않는다.

권장:

```text
1. Metadata와 Domain 도입
2. Manifest 안정화
3. Source Path 정리
```

Source Path 이동은 Git history 추적을 어렵게 할 수 있다.

본문 수정과 같은 Commit에 섞지 않는다.
