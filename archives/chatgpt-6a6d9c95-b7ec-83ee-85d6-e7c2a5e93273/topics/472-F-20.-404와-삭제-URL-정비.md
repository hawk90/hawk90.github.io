# F-20. 404와 삭제 URL 정비

### 좋은 404 페이지

```text
페이지를 찾을 수 없다는 명확한 안내
검색
Core Topics
홈
대표 Guide
```

### 피해야 할 것

```text
200 상태로 “페이지 없음” 표시
광고 삽입
수십 개 추천 카드
자동으로 홈 redirect
```

### 삭제 글 처리

```text
대체 문서 있음
→ 가장 가까운 문서로 redirect

대체 문서 없음
→ 정상적인 404 또는 적절한 제거 응답

외부 참조가 많은 중요 문서
→ 짧은 대체 안내 페이지 검토
```

### 완료 조건

- 존재하지 않는 URL이 200으로 응답하지 않음
- 404에 광고 없음
- 삭제 URL을 무조건 홈으로 redirect하지 않음
- redirect chain 없음
