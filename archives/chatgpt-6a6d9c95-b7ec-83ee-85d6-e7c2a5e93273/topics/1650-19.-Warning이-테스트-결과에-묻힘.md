# 19. Warning이 테스트 결과에 묻힘

CI는 통과하지만 Warning 300개가 로그 중간에 묻힐 수 있다.

결국 Warning은 무시된다.

권장:

```text
Error
→ Test 실패

Warning
→ 요약 Report
→ 신규 Warning 증가 시 검사
```

기존 부채가 많다면 전체 Warning 수를 0으로 만들기 전까지 Baseline을 둘 수 있다.

```text
현재 137개
→ 138개가 되면 실패
→ 136개는 통과
```

하지만 이 Baseline이 영구 면죄부가 되지 않게 감소 계획을 둔다.
