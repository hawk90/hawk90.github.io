# 11. 중앙 Alias와 문서 Alias 경계

## 중앙 Alias

기술 용어 자체의 동의어다.

```text
MSI-X ↔ MSIX
C++ ↔ cpp ↔ cxx
IOMMU ↔ Input Output Memory Management Unit
```

## 문서 Alias

특정 글을 찾기 위한 제목 변형이다.

```yaml
aliases:
  - PCIe BAR Size Calculation
  - BAR 크기 계산
```

중앙 Registry는 여러 문서에 공유된다.

문서 Alias는 해당 문서에만 적용한다.
