# H-10. 최종 `dist` 구조 검사

원본이 아니라 배포물을 검사한다.

## 기본 검사

```text
HTML 파일 수
예상하지 못한 확장자
숨김 파일
.env
backup 파일
source map
admin bundle
secret pattern
```

## 파일 크기 검사

```text
대형 HTML
대형 JS
대형 CSS
대형 이미지
검색 인덱스
```

예:

```text
WARNING:
`/posts/cuda-complete-guide/index.html` is 3.8 MB.
Largest contributors: code blocks, line-number markup.
```

## 완료 조건

- 민감 파일이 artifact에 없음
- 관리자 자산이 없음
- 예상 밖의 대형 파일이 보고됨
- 배포 파일 목록을 artifact로 보존 가능
