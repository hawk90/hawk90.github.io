# 3. 소스 코드만 테스트하고 최종 HTML을 확인하지 않음

다음 코드가 정상이어도:

```ts
buildCanonicalUrl(document)
```

Astro Layout에서 잘못된 값을 전달하면 실제 HTML은 틀릴 수 있다.

따라서 중요한 페이지 계약은 최종 생성 HTML에서 확인해야 한다.

예:

```text
H1 정확히 하나
canonical 정확히 하나
robots metadata
Article main 영역
Heading anchor
내부 자산 경로
```

이는 브라우저 없이 HTML Parser로 빠르게 검사할 수 있다.
