# 93. 부분 장애 격리

예:

```text
Search Index 생성 실패
```

일 때 선택지는 두 가지다.

## 검색이 배포 필수라면

Build 실패.

## 검색 없는 사이트도 탐색 가능하다면

이전 정상 Search Index 유지 또는 검색 기능 비활성화 후 콘텐츠 배포.

하지만 이전 인덱스와 신규 HTML 불일치가 생길 수 있다.

초기에는 Search Index 생성 실패를 Build Error로 두는 편이 단순하고 안전하다.

외부 댓글·Analytics는 실패 허용이 맞다.
