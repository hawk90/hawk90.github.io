# 24. 본문보다 광고가 먼저 보임

첫 화면에:

```text
제목
광고
광고
본문 시작
```

이 나타나면 콘텐츠보다 수익화가 우선인 인상을 줄 수 있다.

AdSense 승인 이전에는 특히:

```text
광고 없는 상태에서도
페이지가 완성된 기술 문서로 보여야 함
```

이 중요하다.

## 권장

```text
제목
Description
핵심 내용 또는 TL;DR
본문
논리 단위 종료 후 광고 후보
```

광고를 넣기 위해 내용을 인위적으로 쪼개지 않는다.
