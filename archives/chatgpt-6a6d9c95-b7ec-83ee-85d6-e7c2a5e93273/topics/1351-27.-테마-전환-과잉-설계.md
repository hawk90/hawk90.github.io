# 27. 테마 전환 과잉 설계

Dark Mode 하나를 위해 다음이 들어갈 수 있다.

```text
전역 Store
초기 Hydration
Cookie
Local Storage
System Sync
Cross-tab Sync
Transition
Server Hint
```

정적 사이트에서는 작은 Inline Script로 Flash를 막고 Local Storage 또는 System Preference를 읽는 정도면 충분할 수 있다.

테마를 애플리케이션 상태처럼 관리하지 않는다.
