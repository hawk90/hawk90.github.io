# 15. Dist 폴더를 검증하지 않음

Source Code만 검사하고 최종 산출물을 보지 않으면 다음을 놓친다.

```text
관리자 JS 포함
Source Map 포함
Draft HTML 생성
잘못된 canonical
내부 경로 노출
깨진 자산 URL
Secret 문자열
```

`dist` 전용 검사를 둔다.

---

## Dist Validation 항목

```text
필수 파일 존재
대표 URL HTML 존재
Draft URL 없음
관리자 파일 없음
Secret 후보 없음
절대 로컬 경로 없음
Search Index JSON 유효
Sitemap URL 유효
404 페이지 존재
```
