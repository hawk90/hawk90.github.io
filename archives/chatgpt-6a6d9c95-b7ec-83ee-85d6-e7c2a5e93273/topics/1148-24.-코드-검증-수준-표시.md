# 24. 코드 검증 수준 표시

문서 내부 또는 metadata에 선택적으로 기록할 수 있다.

```yaml
codeVerification:
  level: compiled
  environment: Ubuntu 24.04, GCC 13
```

가능한 값:

```text
illustrative
syntax-checked
compiled
executed
hardware-verified
```

다만 모든 글에 새 metadata를 계속 추가하기보다, 중요한 예제에만 사용한다.
