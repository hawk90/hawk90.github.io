# 23. 코드 블록이 모바일 Viewport보다 넓어짐

`min-width`, Line Number, Copy Button, 파일명이 합쳐져 Code Frame이 화면 밖으로 나갈 수 있다.

검사:

```text
320px
360px
긴 파일명
긴 첫 줄
Line Number 활성
Copy 버튼
```

Copy Button은 코드 텍스트 위를 가리지 않게 한다.
