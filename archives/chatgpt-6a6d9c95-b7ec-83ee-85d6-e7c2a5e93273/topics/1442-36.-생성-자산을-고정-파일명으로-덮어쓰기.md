# 36. 생성 자산을 고정 파일명으로 덮어쓰기

```text
search-index.json
main.js
og/default.png
```

를 장기 캐시하면서 같은 URL로 덮어쓰면 오래된 파일이 남을 수 있다.

변경되는 자산은 Content Hash 파일명을 사용한다.

고정 URL이 필요한 파일:

```text
robots.txt
sitemap-index.xml
rss.xml
```

은 적절히 짧은 캐시나 재검증 정책이 필요하다.

GitHub Pages의 세밀한 Cache-Control 제어에는 한계가 있을 수 있으므로 파일명 Versioning이 더 안정적이다.
