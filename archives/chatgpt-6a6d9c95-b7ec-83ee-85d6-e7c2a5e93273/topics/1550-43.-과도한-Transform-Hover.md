# 43. 과도한 Transform Hover

모든 Card가 위로 떠오르고 그림자가 커지면 기술 문서보다 상업적 Landing Page처럼 보일 수 있다.

```css
transform: translateY(-6px);
```

가 많으면 화면이 산만하다.

클릭 가능성은 다음으로도 충분히 전달할 수 있다.

```text
명확한 링크
Border 변화
배경 변화
제목 색상
```
