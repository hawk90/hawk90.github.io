# 29. Vanity Metric 수집

다음 지표는 흥미롭지만 실제 콘텐츠 개선으로 연결되지 않을 수 있다.

```text
실시간 방문자
지역별 색상 지도
초 단위 체류 시간
스크롤 10% 단위
마우스 이동
```

콘텐츠 개선에 필요한 신호는 더 단순할 수 있다.

```text
어떤 문서가 유입되는가
어떤 검색어에서 노출되는가
어떤 Hub에서 다음 글로 이동하는가
```
