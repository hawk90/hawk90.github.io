# 29. Custom Domain 설정 Drift

Custom Domain을 사용한다면 다음이 일치해야 한다.

```text
Astro site
CNAME
GitHub Pages 설정
Canonical
Sitemap
RSS
Open Graph
```

Custom Domain을 바꾸고 `CNAME`만 수정하면 이전 `github.io` 주소가 canonical로 남을 수 있다.
