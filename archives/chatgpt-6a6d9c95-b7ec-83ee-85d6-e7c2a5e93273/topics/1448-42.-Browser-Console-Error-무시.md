# 42. Browser Console Error 무시

화면이 보인다고 정상은 아니다.

다음 오류가 숨을 수 있다.

```text
Search Index Parse
Analytics Block
Giscus Origin
Missing Source Map
Hydration Mismatch
Image 404
```

Canary 페이지에서 브라우저 Console의 예상하지 않은 Error를 실패로 처리한다.

광고 차단기 등 환경 의존 오류는 Allowlist를 신중히 관리한다.
