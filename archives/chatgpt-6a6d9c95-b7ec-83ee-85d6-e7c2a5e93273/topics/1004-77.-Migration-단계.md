# 77. Migration 단계

## 1단계

기존 관련 글 데이터를 읽되 UI는 유지한다.

## 2단계

대표 문서 20개에 새 relation metadata 적용.

## 3단계

새 `ArticleRelations` UI를 대표 글에 적용.

## 4단계

기존 태그 기반 관련 글은 fallback으로 이동.

## 5단계

새 관계 품질이 충분하면 기존 관련 글 컴포넌트 제거.
