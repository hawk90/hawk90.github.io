# 47. Policy Override 순서

권장 순서:

```text
Draft
→ 미래 발행
→ 법적·강제 비공개
→ Content Status
→ 페이지별 추가 판단
```

예:

```ts
export function getPublicationDecision(
  document: ContentDocument,
  context: PublicationContext,
): PublicationDecision {
  if (document.draft) {
    return getDraftDecision(
      context.environment,
    );
  }

  if (
    isFutureDocument(
      document,
      context.now,
    )
  ) {
    return hiddenDecision();
  }

  return getStatusDecision(
    document.status,
  );
}
```
