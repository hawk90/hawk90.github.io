# 33. Prerequisite Cycle

Prerequisite cycle은 무조건 오류일 수도 있고, 기술 개념상 상호 이해가 필요한 경우도 있다.

그러나 “필수 선행” 관계라면 cycle은 학습 경로를 막는다.

```text
A를 이해하려면 B 필요
B를 이해하려면 A 필요
```

따라서 cycle을 error 또는 warning으로 둔다.

초기에는 warning이 현실적이다.

```ts
severity: "warning"
```

대표 Guide의 Start Here 경로에서는 error로 강화할 수 있다.
