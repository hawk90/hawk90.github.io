# 32. 외부 서비스 장애가 Layout을 밀어냄

댓글·광고·Embed가 로드 실패했을 때 다음 문제가 생길 수 있다.

```text
빈 거대한 영역
무한 Spinner
Layout Shift
본문 뒤 영역 접근 불가
JavaScript 오류로 다른 기능 중단
```

각 Integration을 독립된 경계로 둔다.

```text
본문
→ 완료

댓글 Loader
→ 실패해도 짧은 오류 표시

광고
→ 실패하면 슬롯 축소
```
