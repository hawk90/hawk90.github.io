# 70. 광고 승인 후 약한 페이지에 자동 광고 전면 적용

승인 후 Auto Ads를 켜면 다음에도 광고가 삽입될 수 있다.

```text
짧은 Reference
Tag
Search
Historical 안내
404와 유사한 화면
```

페이지 유형별 광고 적격성을 다시 판단해야 한다.

## 광고 허용 후보

```text
충분한 독립 Article
고유 설명이 풍부한 Topic Hub
```

## 광고 제외 후보

```text
검색
Tag 목록
Archive
짧은 Redirect 안내
404
Admin
Draft
빈 결과
```

승인은 모든 URL이 광고에 적합하다는 뜻이 아니다.
