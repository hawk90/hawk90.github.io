# 5. 범용 테마 기능 유지 안티패턴

프로젝트가 개인 사이트인데도 범용 테마처럼 다음 옵션을 계속 유지할 수 있다.

```text
작성자 여러 명
다국어
레이아웃 Variant 여러 개
카드 Style 여러 개
배포 대상 여러 개
CMS Adapter 여러 개
댓글 Provider 여러 개
Analytics Provider 여러 개
```

실제로 사용하는 조합이 하나라면 옵션은 유연성이 아니라 유지보수 부채다.

예:

```ts
type CommentProvider =
  | "giscus"
  | "disqus"
  | "utterances"
  | "none";
```

실제로 Giscus만 사용한다면:

```ts
const COMMENTS_ENABLED = true;
```

혹은 Giscus 컴포넌트 하나면 충분하다.
