# 6. 자동 후보로만 사용할 정보

다음은 자동으로 후보를 만들 수 있지만 최종 결정은 사람이 한다.

```text
Primary Topic 후보
Content Type 후보
중복 문서 후보
Historical 후보
Representative 후보
Archive 후보
```

---

## Topic 후보

예:

```text
기존 카테고리: CUDA
→ gpu-cuda 확률 높음

기존 카테고리: Linux
→ linux-systems 또는 firmware-bootloader

기존 태그: PCIe, XRT, FPGA
→ pcie-cxl 또는 firmware-bootloader
```

하나의 글이 여러 영역에 걸칠 수 있으므로 단순 키워드 개수만으로 확정하지 않는다.

---

## Type 후보

예:

```text
제목에 “오류”, “실패”, “해결”
+
로그 블록 많음
→ debug-note 후보

Benchmark 표와 숫자 존재
→ experiment 후보

특정 함수·파일·Repository 링크
→ source-walkthrough 후보

명령과 표 중심
→ reference 후보
```

최종 타입은 글의 핵심 목적을 보고 결정한다.
