# 58. 배포 환경의 Locale에 따른 정렬 변화

문서 제목 정렬에 `localeCompare()`를 기본 환경 그대로 사용하면 로컬 macOS와 CI Linux에서 결과가 달라질 수 있다.

예:

```ts
a.title.localeCompare(b.title, "ko-KR");
```

처럼 Locale을 명시하고, 동일 날짜의 Tie-breaker도 고정한다.

```text
updated desc
→ title ko-KR asc
→ id asc
```
