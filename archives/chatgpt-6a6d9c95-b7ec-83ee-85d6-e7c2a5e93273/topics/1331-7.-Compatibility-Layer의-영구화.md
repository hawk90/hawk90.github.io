# 7. Compatibility Layer의 영구화

Migration 중에는 Legacy Adapter가 필요할 수 있다.

문제는 이것이 영원히 남는 경우다.

```text
Legacy Post
→ Adapter A
→ Adapter B
→ New Content Model
→ View Model
```

세대가 추가될 때마다 변환 계층이 늘어난다.

### 위험 신호

```text
legacyTitle
legacySlug
oldCategory
newCategory
normalizedCategory
```

가 동시에 존재한다.

### 해결

변환 경계는 하나만 유지한다.

```text
Legacy Raw Entry
→ Current Domain Model
```

내부 Domain에 Legacy 필드를 전파하지 않는다.
