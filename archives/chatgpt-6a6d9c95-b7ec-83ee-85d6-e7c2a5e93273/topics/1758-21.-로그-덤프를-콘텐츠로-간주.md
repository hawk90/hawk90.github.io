# 21. 로그 덤프를 콘텐츠로 간주

```text
dmesg 전체 2,000줄
lspci 전체 출력
빌드 로그 전체
```

가 본문의 대부분을 차지할 수 있다.

검색어는 많이 포함되지만 사람이 해결책을 찾기 어렵다.

## 좋은 Debug Note

```text
증상
정상 기대값
핵심 로그 3~10줄
각 줄의 의미
가설
검증
원인
해결
한계
```

전체 로그는 별도 첨부나 접힌 영역으로 제공한다.
