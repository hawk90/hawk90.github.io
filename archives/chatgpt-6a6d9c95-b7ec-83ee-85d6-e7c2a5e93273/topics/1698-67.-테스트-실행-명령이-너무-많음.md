# 67. 테스트 실행 명령이 너무 많음

```text
test
test:unit
test:domain
test:content
test:integration
test:html
test:browser
test:visual
test:full
test:ci
```

가 생기면 어떤 명령을 실행해야 하는지 모른다.

권장 사용자 명령은 적게 둔다.

```text
npm run check
npm run test
npm run test:browser
npm run test:full
```

내부적으로 여러 Test Project를 호출할 수 있다.
