# 10. Build 시간에 현재 시각을 콘텐츠 의미로 사용

다음 값은 Build마다 바뀐다.

```text
new Date()
```

이를 다음에 사용하면 모든 페이지가 매 Build마다 달라질 수 있다.

```text
updated 날짜
Copyright 문구
Freshness 상태
검색 정렬
Sitemap lastmod
```

특히 Sitemap `lastmod`를 Build 시각으로 설정하면 실제로 수정되지 않은 500개 URL이 매 배포마다 갱신된 것처럼 보인다.

권장:

```text
문서 lastmod
= updated
  또는 published

Build timestamp
= 운영 진단용 별도 값
```
