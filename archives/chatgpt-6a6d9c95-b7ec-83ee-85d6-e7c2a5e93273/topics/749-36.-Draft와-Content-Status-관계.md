# 36. Draft와 Content Status 관계

Draft는 상태 모델에 넣지 않는 편이 낫다.

이유:

```text
draft는 발행 흐름 상태
current/historical은 공개 후 의미 상태
```

서로 축이 다르다.

따라서:

```ts
export interface ContentDocument {
  draft: boolean;
  status: ContentStatus;
}
```

예:

```yaml
draft: true
status: needs-review
```

Production에서 렌더되지 않는다.

검토가 끝난 뒤:

```yaml
draft: false
status: current
```
