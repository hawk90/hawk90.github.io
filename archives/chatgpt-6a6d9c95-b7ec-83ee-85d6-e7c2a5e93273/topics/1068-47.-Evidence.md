# 47. Evidence

근거를 단순 참고 링크 목록으로만 두지 않는다.

권장 분류:

```text
Specification
Source Code
Direct Experiment
Benchmark
Paper
```

예:

```text
근거

· PCI Express Base Specification Revision 5.0
· Linux v6.12 drivers/pci/probe.c
· AMD Alveo U250, XRT 2.13.466 직접 실험
```
