# C-18. 대표 글 결론 재작성

좋은 결론은 본문 소제목을 반복하지 않는다.

다음 세 질문에 답한다.

```text
무엇이 핵심인가
실무에서는 무엇부터 확인해야 하는가
어떤 조건에서는 결론이 달라지는가
```

## 예시

```text
BAR 문제를 볼 때는 드라이버 코드보다 먼저 장치가 보고한 BAR 크기,
firmware의 주소 할당, 운영체제 resource 등록을 순서대로 확인해야 한다.

장치가 정상적으로 열거됐더라도 내부 메모리 컨트롤러 초기화가 끝나지 않았다면
BAR 접근 결과는 여전히 유효하지 않을 수 있다.
```
