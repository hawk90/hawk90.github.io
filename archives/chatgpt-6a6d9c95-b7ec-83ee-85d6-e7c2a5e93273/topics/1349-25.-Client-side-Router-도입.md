# 25. Client-side Router 도입

정적 Article 사이트에 SPA Router를 넣으면 다음 문제가 생길 수 있다.

```text
스크롤 복원
Anchor 이동
브라우저 뒤로 가기
외부 Script 재실행
페이지별 Metadata
접근성 Focus
```

Astro의 페이지 전환 기능을 사용하더라도 댓글·광고·코드 복사·Analytics와의 상호작용을 검증해야 한다.

단순 전체 페이지 탐색이 안정적이라면 SPA화가 반드시 개선은 아니다.
