# E-14. OG 이미지 증분 생성

모든 글의 OG 이미지를 매번 다시 만들 필요는 없다.

## 입력 hash

```text
문서 제목
부제목
Topic
작성자
템플릿 버전
폰트 버전
생성기 버전
```

이미지 파일의 존재만으로 재사용하지 말고 입력 hash를 비교한다.

## Manifest 예시

```json
{
  "pcie-bar-sizing": {
    "inputHash": "abc123",
    "output": "pcie-bar-sizing.png",
    "generatorVersion": "2"
  }
}
```

## 필수와 선택 구분

### 필수 OG

```text
홈
Topic Hub
Featured Guide
```

### 선택 OG

일반 글은 생성 실패 시 기본 공유 이미지를 사용할 수 있다.

## 완료 조건

- 변경된 문서만 OG 재생성
- 제목 변경이 반드시 자산 갱신으로 이어짐
- 삭제 글의 전용 OG가 정리됨
- 생성 실패가 조용히 무시되지 않음

## 우선순위

```text
P1
```
