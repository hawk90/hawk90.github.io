# B-16. Topic registry 생성

Topic 이름을 글마다 자유 문자열로 넣으면 표기 드리프트가 발생한다.

따라서 작은 registry를 둔다.

```ts
export const TOPICS = {
  pcieCxl: {
    id: "pcie-cxl",
    title: "PCIe & CXL",
    href: "/topics/pcie-cxl/",
  },
  firmwareBootloader: {
    id: "firmware-bootloader",
    title: "Firmware & Bootloader",
    href: "/topics/firmware-bootloader/",
  },
} as const;
```

또는 YAML:

```yaml
topics:
  - id: pcie-cxl
    title: PCIe & CXL
    description: ...
  - id: firmware-bootloader
    title: Firmware & Bootloader
    description: ...
```

## 완료 조건

- Topic ID는 영문 slug
- 화면 표시명은 별도
- alias와 title이 분리
- URL이 registry 한 곳에만 정의
- 글에서는 Topic ID만 사용
