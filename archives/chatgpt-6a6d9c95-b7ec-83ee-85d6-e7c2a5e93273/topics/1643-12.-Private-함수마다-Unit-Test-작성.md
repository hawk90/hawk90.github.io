# 12. Private 함수마다 Unit Test 작성

작은 Helper 하나하나를 직접 테스트하면 리팩터링 비용이 커진다.

```text
normalizeTokenInternal()
sortAliasInternal()
createTemporaryMap()
```

이 함수들은 공개 동작 테스트를 통해 간접적으로 검증할 수 있다.

직접 테스트할 가치가 있는 것은:

```text
복잡한 알고리즘
경계 조건이 많은 순수 함수
독립적인 공개 계약
```

이다.
