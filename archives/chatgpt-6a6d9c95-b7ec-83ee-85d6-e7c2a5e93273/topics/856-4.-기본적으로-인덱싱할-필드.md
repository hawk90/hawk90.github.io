# 4. 기본적으로 인덱싱할 필드

## 제목

가장 높은 가중치다.

```text
PCIe BAR 크기는 어떻게 탐색되는가
```

사용자 의도와 직접 연결된다.

---

## 별칭

예:

```yaml
aliases:
  - PCI BAR
  - Base Address Register
  - 베이스 주소 레지스터
```

제목에 없는 표현으로도 찾을 수 있다.

---

## Symbol

예:

```yaml
symbols:
  - pci_scan_child_bus
  - pci_bus_add_devices
  - pci_iomap
```

소스코드 분석 글을 함수명으로 찾게 한다.

---

## Topic

예:

```text
PCIe & CXL
Firmware & Bootloader
```

상위 주제 검색에서 대표 글을 찾는 데 사용한다.

---

## Heading

본문 전체보다 의미 밀도가 높다.

```text
BAR Size Probing
64-bit BAR
Linux Resource Allocation
```

---

## Description

문서 범위와 목적을 나타낸다.

---

## Keyword

작성자가 검색 연결을 위해 명시한 제한된 키워드다.

기존 태그 전체를 무조건 검색 키워드로 사용하지 않는다.

---

## Error Message

Debug Note에서 명시적으로 등록된 오류 문자열만 사용한다.

```yaml
errorMessages:
  - failed to load xclbin
  - no space for BAR
```
