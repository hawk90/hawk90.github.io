# Task 3-5. 빌드 성능·콘텐츠 파이프라인 개선 백로그

이번 단계에서는 Astro 자체를 교체하지 않고, **현재 콘텐츠 규모에서 반복되는 전체 재처리와 메모리 사용을 줄이는 방향**으로 정리한다.

핵심 목표는 다음이다.

```text
현재 상태 측정
→ 병목 단계 분리
→ 콘텐츠를 한 번만 해석
→ 파생 작업 증분화
→ 로컬·CI 실행 경로 분리
```
