# 10. 홈이 콘텐츠보다 인터페이스 중심

홈에 다음만 강하게 보일 수 있다.

```text
큰 Hero
검색창
버튼
애니메이션
GitHub 링크
태그 Cloud
광고
```

실제 기술 콘텐츠는 아래쪽에 작게 위치한다.

이 경우 홈이 게시자 콘텐츠보다 탐색·브랜딩 UI 중심 화면으로 보일 수 있다.

## 홈 첫 화면에서 보여야 할 것

```text
사이트가 다루는 전문 영역
대표 Guide
실제 기술 경험
주요 Topic
작성자의 전문성 근거
```

예:

```text
FPGA·PCIe·CUDA·Linux 시스템 개발 기록

대표 분석
- PCIe BAR와 Linux Resource 할당
- CUDA Memory 성능 실험
- U250 XRT 장애 분석
```

단순히 “안녕하세요, 호크입니다”로 끝내지 않는다.
