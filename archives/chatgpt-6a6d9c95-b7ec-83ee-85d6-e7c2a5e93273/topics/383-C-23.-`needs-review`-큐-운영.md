# C-23. `needs-review` 큐 운영

상태만 붙이고 방치하면 안 된다.

## 우선순위 계산

```text
대표 글 여부
검색 유입
기술 변화 가능성
오류 위험
상위 Hub 의존도
```

## 처리 상태

```text
queued
reviewing
verified
historical
superseded
```

별도 시스템이 아니라 간단한 Markdown 표나 GitHub Issue로 충분하다.

## 완료 조건

- `needs-review` 문서에 다음 행동이 있음
- 대표 문서는 기한 없이 방치하지 않음
- 검토 후 반드시 다른 상태로 전환됨
