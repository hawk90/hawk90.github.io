# 60. Footer를 링크 창고로 사용

Footer에 다음을 모두 넣을 수 있다.

```text
모든 Topic
모든 Tag
최근 글
인기 글
GitHub
RSS
법적 문서
프로필
도구
```

페이지 끝이 다시 거대한 Sitemap이 된다.

Footer는 다음 정도면 충분하다.

```text
사이트 설명
핵심 Topic 일부
About·Privacy
GitHub·RSS
```

전체 탐색은 Topic Hub와 Archive가 맡는다.
