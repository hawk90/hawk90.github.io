# 30. Historical 판정

다음 조건이면 Historical이 적합하다.

```text
특정 버전·제품·시점에 의미가 있음
현재와 다른 동작 자체가 가치 있음
과거 장애 해결 기록으로 희귀함
신판으로 단순 대체하기 어려움
```

예:

```text
CentOS 7.9 + XRT 2.13.466 + U250
Linux 3.10 Kernel Driver
CUDA 11.8 + GTX 1070
```
