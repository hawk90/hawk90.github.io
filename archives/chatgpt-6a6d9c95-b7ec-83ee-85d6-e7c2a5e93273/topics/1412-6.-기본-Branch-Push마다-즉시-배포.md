# 6. 기본 Branch Push마다 즉시 배포

모든 작은 Commit이 바로 Production에 배포되면 다음 문제가 생긴다.

```text
중간 Migration 상태 공개
콘텐츠와 코드 순서 불일치
깨진 Hub Config 노출
대량 자동 수정 즉시 반영
```

개인 블로그라면 무거운 승인 절차는 필요 없지만, 최소한 다음 Gate는 거친다.

```text
Check
Build
Dist Validation
Smoke Test
→ Deploy
```

대규모 변경은 Pull Request Preview 또는 별도 Branch Build에서 먼저 확인한다.
