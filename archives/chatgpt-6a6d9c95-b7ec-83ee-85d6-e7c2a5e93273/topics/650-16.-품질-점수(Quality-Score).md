# 16. 품질 점수(Quality Score)

이건 내부용이다.

예를 들어

| 항목 | 점수 |
|------|------:|
| Description | 5 |
| Diagram | 10 |
| Example | 10 |
| Environment | 10 |
| Evidence | 10 |
| FAQ | 5 |
| Next Reading | 5 |
| Metadata | 10 |
| Links | 10 |
| Mobile | 5 |
| 최신성 | 10 |
| 총점 | 100 |

---

```text
92점

↓

Featured 가능
```

```text
73점

↓

Needs Review
```

```text
48점

↓

Hidden
```
