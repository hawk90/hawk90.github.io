# 53. 범용 Query의 한계

이 함수만 사용하면 중요한 의미가 호출부에 흩어진다.

```ts
queryDocuments(manifest, context, {
  topicIds: ["pcie-cxl"],
  statuses: ["current"],
  types: ["guide", "concept"],
  limit: 3,
});
```

이것이 Start Here인지 일반 목록인지 알기 어렵다.

따라서 큐레이션은 전용 함수가 적합하다.

```ts
getTopicStartHere(
  "pcie-cxl",
  manifest,
  curation,
)
```

범용 Query는 자동 목록에 사용한다.

```text
최근 글
Topic 전체 글
Debug Note 목록
Historical 목록
```
