# 70. 끝 슬래시 정책 불일치

```text
/articles/pcie-bar
/articles/pcie-bar/
```

가 혼재하면 Canonical·내부 링크·Analytics가 분리될 수 있다.

Astro의 `trailingSlash` 정책을 결정하고 다음에 일관되게 적용한다.

```text
내부 링크
Canonical
Sitemap
Redirect
Smoke Test
```
