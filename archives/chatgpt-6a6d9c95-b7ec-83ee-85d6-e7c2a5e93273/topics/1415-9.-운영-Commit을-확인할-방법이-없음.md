# 9. 운영 Commit을 확인할 방법이 없음

사이트가 이상할 때 가장 먼저 알아야 하는 것은:

```text
지금 어떤 Commit이 배포돼 있는가?
```

이다.

방법:

```text
Build metadata JSON
HTML meta
Footer의 숨김 가능한 Version 정보
Deployment 기록
```

예:

```json
{
  "commit": "abc1234",
  "builtAt": "2026-08-01T06:00:00Z",
  "manifestVersion": "3",
  "searchIndexVersion": "2"
}
```

이를 공개 UI에 크게 표시할 필요는 없지만 장애 분석에 사용할 수 있어야 한다.
