# 83. Production과 Preview 환경 분기를 본문에서 처리

각 Page가:

```ts
if (isPreview) ...
```

를 반복하지 않는다.

Build Environment와 Publication Context를 중앙에서 만들어 전달한다.

```text
Production
Preview
Development
```

환경별 계약을 명시한다.
