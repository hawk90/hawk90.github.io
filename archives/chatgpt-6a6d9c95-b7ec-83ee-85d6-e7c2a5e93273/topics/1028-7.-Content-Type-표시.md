# 7. Content Type 표시

문서 타입은 독자가 기대할 읽기 방식을 결정한다.

```text
GUIDE
전체 흐름과 실행 순서를 설명

CONCEPT
원리와 메커니즘을 설명

DEBUG NOTE
실제 증상과 원인 추적 기록

EXPERIMENT
가설·방법·결과 중심

SOURCE WALKTHROUGH
특정 소스코드 흐름 분석

REFERENCE
빠르게 다시 찾기 위한 자료
```

현재 모든 글이 같은 `POST`로 보이는 것보다 문서 역할이 명확해진다.
