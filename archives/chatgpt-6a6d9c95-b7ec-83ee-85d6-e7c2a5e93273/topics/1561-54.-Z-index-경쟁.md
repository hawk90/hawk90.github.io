# 54. Z-index 경쟁

다음 숫자가 계속 증가한다.

```text
Header 10
TOC 20
Dropdown 100
Search 1000
Tooltip 9999
```

새 UI가 생길 때마다 더 큰 숫자를 사용한다.

권장 Layer 역할:

```text
Base
Sticky
Dropdown
Modal
Toast
```

정도로 제한한다.

CSS Stacking Context가 Transform·Opacity로 새로 생기는 문제도 확인한다.
