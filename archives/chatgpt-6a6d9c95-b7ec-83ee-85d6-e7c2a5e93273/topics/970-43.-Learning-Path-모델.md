# 43. Learning Path 모델

```ts
export interface LearningPathDefinition {
  id: string;
  title: string;
  description: string;

  topicId: string;

  levels: readonly LearningPathLevel[];
}
```

```ts
export interface LearningPathLevel {
  id: string;
  title: string;
  documentIds: readonly string[];
}
```
