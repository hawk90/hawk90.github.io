# 75. 작성자의 독창적 자산이 숨겨짐

다음은 강한 콘텐츠 자산이다.

```text
직접 만든 Diagram
Benchmark 데이터
재현 코드
실패 로그
소스코드 호출 흐름
환경 Matrix
```

그런데 현재 글이 텍스트만 있고 이 자산이 GitHub 저장소나 개인 메모에만 있을 수 있다.

대표 문서에는 적어도 하나의 독창적 증거를 드러낸다.

```text
측정
코드
Diagram
관찰
소스 분석
```

모든 글에 억지로 넣는 것은 아니지만, 대표 글은 분명한 차별점이 있어야 한다.
