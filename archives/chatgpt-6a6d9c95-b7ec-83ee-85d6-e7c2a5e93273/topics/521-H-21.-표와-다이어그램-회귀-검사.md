# H-21. 표와 다이어그램 회귀 검사

## 표

```text
wide table
긴 identifier
많은 열
모바일
인쇄
```

검사:

```text
페이지 viewport 확장 없음
가로 스크롤 영역 명확
header cell 존재
caption 존재 여부
```

## 다이어그램

```text
SVG 렌더링
viewBox
text clipping
모바일 축소
alt·본문 설명
```

## 완료 조건

- 대표 표와 SVG를 canary로 지정
- 생성 성공뿐 아니라 실제 렌더링 확인
- 텍스트가 잘리지 않음
- 색만으로 관계를 구분하지 않음
