# 18. 검색 인덱스 지연 로딩

페이지를 방문한 모든 사용자에게 검색 인덱스를 내려주지 않는다.

```text
초기 페이지
→ 검색 버튼만 렌더

사용자 클릭
→ 검색 모듈 로드

검색 Dialog 열림
→ Search Index Fetch

Fetch 완료
→ 입력 및 결과
```

---

## Astro 경계

```text
SearchButton.astro
SearchDialog.ts
SearchIndexLoader.ts
SearchEngine.ts
```

`SearchButton`은 가벼운 정적 HTML이다.

Dialog와 검색 엔진은 사용자 행동 후 로드한다.
