# 60. Print Style

기술 문서는 인쇄·PDF 저장 수요가 있을 수 있다.

최소 Print CSS:

```text
Header·Footer Navigation 숨김
검색 버튼 숨김
댓글·광고 숨김
링크 URL 선택적으로 표시
본문 폭 전체 활용
코드 잘림 방지
배경색 단순화
```

다만 전체 PDF 생성 기능을 별도로 만들 필요는 없다.

브라우저 Print가 정상 동작하면 충분할 수 있다.
