# 40. 의존성 방향

가장 중요한 규칙이다.

```text
Components
    ↓
View Models
    ↓
Domain Queries
    ↓
Domain Models
```

그리고:

```text
Scripts
    ↓
Domain
```

금지 방향:

```text
Domain
→ Astro Component

Domain
→ Browser DOM

Content Model
→ Layout

Publication Policy
→ Search UI
```

Domain은 UI를 몰라야 한다.
