# 38. 모든 Tag 페이지 Canonical을 홈으로 설정

이 방식은:

```text
/tag/cpp/
→ canonical /
```

처럼 쓸 수 있다.

하지만 홈과 Tag 페이지는 같은 콘텐츠가 아니다.

더 적절한 선택은:

```text
Tag 페이지 자기 Canonical + noindex
또는 Route 제거
```

이다.

Canonical과 `noindex`의 목적을 구분한다.
