# Task 3-12. `Firmware & Bootloader` Hub 실제 콘텐츠 설계안

이번 Hub는 개인적으로 **`hawk90.github.io`에서 가장 차별화될 가능성이 큰 영역**이다.

이유는 단순하다.

CUDA나 C++ 글은 인터넷에 많다.

하지만

```text
Boot ROM
↓

BL1
↓

BL2
↓

TF-A / U-Boot
↓

Linux Kernel
↓

Driver
↓

Application
```

까지 **하나의 흐름으로 설명하는 사이트는 생각보다 거의 없다.**
