# 17. 코드 Line Number DOM 폭증

각 코드 줄을 별도 `<span>`으로 감싸면 긴 코드 문서의 DOM이 커진다.

```text
500줄 코드
×
여러 Token span
×
Line wrapper
```

코드가 많은 문서에서 렌더링·검색·복사 비용이 증가한다.

### 대안

```text
Line Number가 정말 필요한 코드에만 활성화
CSS counter 사용 검토
짧은 코드에는 비활성화
```
