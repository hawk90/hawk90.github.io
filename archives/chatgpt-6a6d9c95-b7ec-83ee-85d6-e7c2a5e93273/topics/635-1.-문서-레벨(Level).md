# 1. 문서 레벨(Level)

이걸 반드시 넣는 걸 추천한다.

예를 들어

```yaml
level: beginner
```

또는

```yaml
level: intermediate
```

또는

```yaml
level: advanced
```

---

## Beginner

예

```text
Virtual Memory란?

PCIe BAR란?

DMA란?
```

---

## Intermediate

예

```text
PCIe Enumeration

Linux DMA API

Page Table Walk
```

---

## Advanced

예

```text
CXL HDM Decoder

RCU

Kernel Scheduler

NUMA Balancing
```

---

### 장점

검색 결과에서도

```text
Advanced
```

배지를 줄 수 있다.
