# 23. 404에서 자동 검색·자동 이동

없는 URL을 분석해 비슷한 페이지로 자동 Redirect하면 편리해 보이지만 잘못된 문서로 이동할 수 있다.

예:

```text
/pcie-bar-old
→ 문자열이 비슷한 /bar-chart-css
```

권장:

```text
요청한 경로 표시
홈
Topic Hub
검색 버튼
대표 문서
```

를 제공한다.

명확한 과거 URL만 Redirect Registry로 처리한다.
