# 2. 가장 큰 구조적 문제

## Platform Ahead of Knowledge Architecture

### 플랫폼이 지식 구조보다 앞서감

현재 사이트는 다음을 이미 갖추고 있거나 중요하게 다룬다.

- 정적 빌드
- 코드 하이라이팅
- 검색
- OG 이미지
- 시리즈
- 댓글
- 수식
- 다이어그램
- 페이지 전환
- 콘텐츠 감사
- 관리자 기능 가능성

그런데 사용자가 실제로 가장 필요로 하는 다음 구조는 상대적으로 약하다.

```text
어디서 시작해야 하는가
이 글의 상위 개념은 무엇인가
이 글 다음에 무엇을 읽어야 하는가
이 분야의 대표 문서는 무엇인가
이 글은 튜토리얼인가, 레퍼런스인가
현재도 유효한 정보인가
```

이 때문에 플랫폼은 풍부하지만 방문자 입장에서는 여전히 **많은 글이 있는 블로그**로 보일 수 있다.

### 우선순위 원칙

앞으로 한동안은 다음처럼 판단해야 한다.

```text
새로운 사이트 기능 추가
<
기존 콘텐츠의 구조화
```

예를 들어 새로운 애니메이션, 코드 테마, 관리자 기능보다 다음 작업이 우선이다.

- Topic Hub
- Start Here
- 대표 Guide
- 관련 글 연결
- 글 유형 표시
- 검증 환경 표시
- 오래된 글 상태 표시
