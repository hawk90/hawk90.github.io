# 42. 모든 요소에 `data-testid` 추가

Role과 Text로 찾을 수 있는데도 Test ID를 붙이면 테스트가 사용자 경험과 분리된다.

`data-testid`는 다음 상황에 제한한다.

```text
시각적으로 동일한 반복 요소
텍스트가 번역될 수 있음
실제 접근 가능한 이름이 없는 비표시 구조
```

접근 가능한 이름이 없는 버튼을 Test ID로 해결하지 말고 버튼 자체를 먼저 고친다.
