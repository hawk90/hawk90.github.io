# 41. Superseded 정책

두 가지 선택지가 있다.

## 선택안 A. `noindex`

```ts
function supersededDecision():
  PublicationDecision {
  return {
    render: true,

    index: false,
    follow: true,

    includeInSearch: false,
    includeInSitemap: false,
    includeInRss: false,
    includeInTopicLists: false,

    canBeFeatured: false,
    adsEligible: false,

    searchRankMultiplier: 0,
  };
}
```

장점:

```text
구판이 검색 결과에서 경쟁하지 않음
신판으로 이동 유도
```

## 선택안 B. Historical 검색 의도에 대응

과거 버전 검색 유입이 중요한 글은 index를 유지할 수 있다.

```text
CUDA 11.8 설치
XRT 2.13 U250
Linux 3.10 driver
```

이 경우 상태를 `historical`로 두는 편이 더 정확하다.

즉:

```text
완전히 대체됨 → superseded
과거 버전에 독립 가치 → historical
```
