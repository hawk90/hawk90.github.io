# F-21. 모바일 콘텐츠 경험 감사

재신청 전 실제 모바일 화면을 대표 페이지 기준으로 검사한다.

## 페이지

```text
홈
Topic Hub
일반 Guide
코드가 많은 글
표가 많은 글
검색
About
Privacy
404
```

## 검사

```text
본문 글자 크기
코드 가로 스크롤
표 overflow
광고 슬롯 예정 위치
고정 헤더
목차
다이어그램 확대
링크·버튼 터치 영역
CLS
```

### 완료 조건

- 본문을 가리는 고정 요소 없음
- 코드 복사 버튼이 코드를 덮지 않음
- 표와 코드가 viewport를 확장하지 않음
- Topic Hub 탐색이 한 열에서도 이해 가능
- 핵심 콘텐츠가 Hero 아래 너무 늦게 시작하지 않음

P0
