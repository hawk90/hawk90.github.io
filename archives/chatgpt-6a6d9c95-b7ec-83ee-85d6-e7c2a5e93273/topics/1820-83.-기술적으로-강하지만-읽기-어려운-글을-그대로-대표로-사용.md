# 83. 기술적으로 강하지만 읽기 어려운 글을 그대로 대표로 사용

독창적인 코드 분석이 있어도:

```text
서론 없음
환경 없음
로그부터 시작
결론 없음
```

이면 신규 독자가 가치를 판단하기 어렵다.

대표 문서는 새로운 내용을 더 많이 쓰기보다 기존 자료를 다음 흐름으로 편집할 필요가 있다.

```text
문제
핵심 결론
근거
범위
다음 글
```
