# B-08. `PCIe & CXL` 기존 글 배치 작업

각 기존 글에 다음만 우선 지정한다.

```yaml
topic: pcie-cxl
type: concept
status: current
```

처음부터 관계 metadata를 모두 넣지 않는다.

1차 작업에서는 다음 세 필드만 있어도 충분하다.

```text
parent topic
content type
status
```

2차 작업에서 대표 글에만 추가한다.

```yaml
prerequisites:
next:
related:
```
