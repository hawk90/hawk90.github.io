# 16. 두 테마용 중복 Token

Light·Dark Mode를 위해 코드 HTML에 양쪽 테마의 색상 정보를 모두 넣으면 HTML이 커질 수 있다.

예:

```html
<span style="--shiki-light:#...;--shiki-dark:#...">
```

코드가 많은 글에서는 반복 비용이 상당하다.

가능한 선택:

```text
CSS Variable 기반
단일 코드 테마
문서별 측정 후 현재 방식 유지
```

무조건 단일 테마로 바꿀 필요는 없지만, 생성 HTML 크기를 측정해야 한다.
