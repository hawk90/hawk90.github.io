# 13. Technical Tokenizer

일반 자연어 tokenizer는 기술 용어를 잘못 자를 수 있다.

예:

```text
std::vector
cudaMemcpyAsync
pci_scan_child_bus
CXL.mem
```

권장 token 후보:

```text
한글 단어
영문·숫자 조합
snake_case
camelCase
namespace::symbol
dot notation
hyphenated identifier
```

초기에는 정교한 형태소 분석기보다 단순 규칙 기반이 낫다.

```ts
const TECHNICAL_TOKEN_PATTERN =
  /[가-힣]+|[A-Za-z0-9_:+.#/-]+/g;
```

이후 Golden Query 결과를 보고 조정한다.
