# 26. 검색 Dialog UX

## 필수 동작

```text
검색 버튼 클릭
Dialog 열림
검색 입력에 Focus
입력
결과 갱신
키보드로 이동
Enter로 선택
Escape로 닫기
원래 버튼으로 Focus 복귀
```

---

## Dialog 초기 상태

검색 인덱스가 아직 로드되지 않았을 때:

```text
검색 준비 중…
```

로딩이 길다면 spinner만 보여주지 말고:

```text
Topic별로 둘러보기
```

fallback 링크를 제공한다.

---

## 빈 검색어

다음 중 하나를 보여줄 수 있다.

```text
Core Topics
Featured Guides
최근 검색은 저장하지 않음
```

인기 검색어 기능은 실제 데이터와 운영 필요가 없으면 추가하지 않는다.
