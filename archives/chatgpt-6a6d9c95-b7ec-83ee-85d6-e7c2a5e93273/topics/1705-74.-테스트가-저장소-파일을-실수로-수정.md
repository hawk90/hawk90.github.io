# 74. 테스트가 저장소 파일을 실수로 수정

Formatter·Migration·Publish Script 테스트는 실제 콘텐츠 파일을 대상으로 실행하면 안 된다.

Fixture를 임시 작업 디렉터리로 복사한 뒤 수행한다.

테스트 종료 후 변경된 Git 상태가 없는지도 CI에서 확인할 수 있다.

```text
git diff --exit-code
```

단, 의도적으로 생성 파일을 추적하는 Workflow와 충돌하지 않게 한다.
