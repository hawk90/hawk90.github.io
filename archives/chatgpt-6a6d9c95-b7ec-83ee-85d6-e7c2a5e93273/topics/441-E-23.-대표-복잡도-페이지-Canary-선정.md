# E-23. 대표 복잡도 페이지 Canary 선정

전체 평균만으로는 극단적으로 무거운 글 문제를 찾기 어렵다.

## Canary 후보

```text
코드 블록이 가장 많은 글
표가 가장 넓은 글
다이어그램이 가장 많은 글
수식이 많은 글
일반 대표 Guide
```

## 검사 항목

```text
HTML 크기
DOM node 수
render 시간
모바일 스크롤
코드 가로 overflow
TOC 길이
```

## 완료 조건

- 3~5개 canary 페이지 고정
- 주요 UI·빌드 변경에서 반복 검증
- 가장 깨끗한 글만 테스트하지 않음
