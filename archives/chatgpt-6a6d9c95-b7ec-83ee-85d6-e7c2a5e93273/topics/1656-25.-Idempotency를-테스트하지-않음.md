# 25. Idempotency를 테스트하지 않음

콘텐츠 변환 도구와 Migration Script는 같은 입력에 반복 실행해도 결과가 바뀌지 않아야 한다.

```text
첫 실행
→ Metadata 정규화

두 번째 실행
→ 변경 없음
```

테스트:

```ts
const once = migrate(source);
const twice = migrate(once);

expect(twice).toBe(once);
```

문자열 Formatting 차이까지 포함해 확인한다.
