# 43. 서로 무관한 글이 최근 글에서 섞임

방문자가 PCIe 글을 읽고 홈으로 돌아왔을 때:

```text
역사 이야기
개인 메모
CUDA
일상
```

이 섞여 있으면 전문 지식 흐름이 끊긴다.

## 기술 사이트 홈

```text
대표 Topic
최근 기술 글
최근 갱신된 Guide
실전 Debug Note
```

를 중심으로 구성한다.

개인 글은 별도 Archive나 Profile 영역에서 접근시킬 수 있다.
