# 18. SEO와 색인

## Hub 색인 조건

다음이 실제로 준비된 뒤 indexable로 공개한다.

```text
고유한 소개
Start Here
Featured
Core Concept 설명
실제 연결 문서
```

글 목록만 존재하는 초기 페이지라면 공개를 늦추거나 임시 `noindex`를 적용한다.

## Canonical

```text
https://hawk90.github.io/topics/pcie-cxl/
```

실제 운영 도메인에 맞춘다.

## 구조화 데이터

초기에는 `CollectionPage` 또는 일반 `WebPage`를 고려할 수 있다.

화면에 없는 강의 과정이나 교육 인증 정보를 구조화 데이터에 넣지 않는다.
