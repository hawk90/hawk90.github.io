# 17. 실패 메시지가 의미 없음

예:

```text
Expected true, received false
```

만 나오면 어떤 문서와 규칙이 문제인지 알기 어렵다.

콘텐츠 검증 테스트에서는 다음을 포함한다.

```text
문서 ID
Source Path
규칙 ID
실제 상태
기대 정책
```

단, 각 테스트에 장문의 수동 오류 메시지를 반복하기보다 Validator 자체가 좋은 Issue를 반환하도록 한다.
