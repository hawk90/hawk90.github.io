# 68. Common Mistakes

기술 문서에서 유용한 섹션이다.

예:

```text
자주 하는 오해

BAR Register 값이 장치 내부 메모리 주소다.
→ 아니다. Host에서 할당된 MMIO Base Address를 나타낸다.

BAR mmap 성공은 장치 초기화 완료를 의미한다.
→ 아니다. 내부 Controller 상태는 별도로 확인해야 한다.
```

Concept와 Debug Note를 연결하는 좋은 장치다.
