## 왜 front matter의 `featured: true`가 좋지 않은가

Featured는 문서의 영구 속성이 아니다.

```text
홈 Featured
Topic Hub Featured
특정 캠페인 Featured
```

의 기준이 다를 수 있다.

문서 안에:

```yaml
featured: true
```

만 두면 어느 화면에서 Featured인지 불명확하다.

권장:

```ts
export const HOME_FEATURED_ARTICLE_IDS = [
  "pcie-bar-sizing",
  "linux-pci-enumeration",
  "cuda-pinned-memory",
  "uboot-driver-model",
] as const;
```
