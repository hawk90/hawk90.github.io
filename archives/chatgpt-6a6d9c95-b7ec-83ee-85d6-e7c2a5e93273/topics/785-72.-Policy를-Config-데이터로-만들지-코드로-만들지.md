# 72. Policy를 Config 데이터로 만들지 코드로 만들지

다음처럼 YAML로 만들 수 있다.

```yaml
current:
  index: true
  sitemap: true
  featured: true
```

장점:

```text
설정 수정이 쉬움
정책 표가 명확함
```

단점:

```text
미래 날짜, draft 등 조건 분기 표현 어려움
잘못된 조합 방지 어려움
타입과 테스트가 약해짐
```

## 권장

기본 정책은 TypeScript 코드로 둔다.

문서화용 정책 표를 별도로 생성하거나 README에 유지한다.
