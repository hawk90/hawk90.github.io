# 38. Import Alias

상대 경로가 깊어지는 것을 막기 위해 alias를 사용한다.

```json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["src/*"],
      "@domain/*": ["src/domain/*"],
      "@components/*": ["src/components/*"],
      "@config/*": ["src/config/*"]
    }
  }
}
```

그러나 alias를 지나치게 많이 만들 필요는 없다.

```text
@content
@topic
@search
@view
@shared
@common
```

처럼 유사 alias가 폭발하면 오히려 혼란스럽다.

`@/` 하나만 사용해도 충분할 수 있다.
