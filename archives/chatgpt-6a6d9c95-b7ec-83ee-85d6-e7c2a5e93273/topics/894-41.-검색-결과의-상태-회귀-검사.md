# 41. 검색 결과의 상태 회귀 검사

```ts
it("does not show superseded documents", () => {
  const results =
    searchEngine.search(
      "PCIe BAR",
    );

  expect(
    results.some(
      (result) =>
        result.status ===
        "superseded",
    ),
  ).toBe(false);
});
```
