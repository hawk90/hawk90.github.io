# 21. GitHub API·외부 API 빌드 의존

빌드 시 다음 데이터를 API로 가져오는 구조는 재현성을 낮춘다.

```text
GitHub Star
최근 Commit
Profile 정보
Contribution
외부 RSS
```

API가 실패하거나 Rate Limit에 걸리면 배포가 막힌다.

공개 페이지에 꼭 필요하지 않은 실시간 데이터는 제거하거나 주기적으로 캐시된 파일을 생성한다.
