# 2. 발행 상태와 콘텐츠 상태 분리

## 발행 상태

```text
draft: true
draft: false
```

정도면 충분하다.

## 콘텐츠 상태

```text
current
needs-review
historical
superseded
archived
```

예를 들어:

```yaml
draft: true
status: needs-review
```

는 아직 공개하지 않은 검토 중 문서다.

```yaml
draft: false
status: current
```

는 현재 대표 경로에 노출 가능한 문서다.

```yaml
draft: false
status: historical
```

는 공개하되 과거 환경임을 명확히 표시하는 문서다.
