# 핵심 결론

기술 블로그의 CSS는 일반 마케팅 사이트보다 더 강한 콘텐츠 내구성이 필요하다.

```text
긴 텍스트
긴 코드
넓은 표
깊은 Heading
복잡한 Figure
```

가 들어와도 매번 예외를 추가하지 않고 견뎌야 한다.

따라서 좋은 시각 구조는:

```text
소수의 Container
일관된 Vertical Rhythm
제한된 Token
명확한 Prose 규칙
역할 중심 Component
콘텐츠 기반 Breakpoint
```

로 만들어진다.

디자인 시스템의 목적은 모든 화면을 똑같이 보이게 하는 것이 아니다.

> 새로운 글과 새로운 기술 형식이 추가돼도 레이아웃이 무너지지 않게 만드는 것이다.
