# 33. 광고 로직 위치

광고 조건을 `BaseLayout`에 넣으면 모든 페이지에 퍼진다.

권장 흐름:

```text
Publication Decision
→ Article Page Model
→ Article Layout
→ Ad Slot Component
```

예:

```ts
export interface ArticlePageViewModel {
  // ...
  adsEligible: boolean;
}
```

Layout:

```astro
{page.adsEligible && (
  <ArticleAdSlot position="after-section" />
)}
```

광고 삽입 위치는 본문 AST 처리와 연결될 수 있으므로 초기에는 본문 후단 정도로 제한하는 것이 안전하다.
