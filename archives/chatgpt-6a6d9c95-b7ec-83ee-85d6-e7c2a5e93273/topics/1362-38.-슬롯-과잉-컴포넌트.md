# 38. 슬롯 과잉 컴포넌트

아무 구조나 넣을 수 있는 범용 Layout 컴포넌트는 재사용성이 높아 보이지만, 페이지 일관성을 잃는다.

```text
header slot
meta slot
before slot
main slot
aside slot
after slot
footer slot
actions slot
```

필요한 구조가 명확한 Article Layout이라면 명시적인 Props와 일부 Slot만 유지한다.
