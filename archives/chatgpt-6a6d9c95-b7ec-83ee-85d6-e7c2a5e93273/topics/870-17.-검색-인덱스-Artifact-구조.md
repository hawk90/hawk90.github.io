# 17. 검색 인덱스 Artifact 구조

## 단일 파일

```text
/search-index.json
```

장점:

```text
구현 단순
요청 1회
캐시 용이
```

초기에는 단일 파일을 권장한다.

---

## 분할 파일

```text
/search/
├── metadata.json
├── pcie-cxl.json
├── linux-systems.json
└── gpu-cuda.json
```

다음 문제가 실제 발생할 때만 고려한다.

```text
압축 인덱스가 지나치게 큼
파싱으로 UI 멈춤
모바일 메모리 문제
```

처음부터 shard를 만들면 다음 문제가 생긴다.

```text
어느 Topic shard를 받을지 결정 필요
전역 검색에서 여러 요청
캐시와 버전 관리 복잡
```
