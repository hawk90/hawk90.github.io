# 39. 카테고리 Migration

기존 카테고리가 다음처럼 넓을 수 있다.

```text
Development
Programming
Linux
Hardware
Study
```

새 Topic에 일대일 대응하지 않을 수 있다.

처리:

```text
고신뢰 매핑
→ 자동

모호한 카테고리
→ Suggested Topic 후보

다중 주제
→ Primary Topic 수동 선택
```
