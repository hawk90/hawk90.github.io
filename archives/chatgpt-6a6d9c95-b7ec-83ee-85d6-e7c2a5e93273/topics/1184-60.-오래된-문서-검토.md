# 60. 오래된 문서 검토

날짜만으로 자동 `needs-review`로 바꾸지는 않는다.

기술마다 변동성이 다르다.

```text
C++ 언어 기본 원리
→ 비교적 안정적

CUDA Toolkit 설치
→ 변동 큼

Linux Kernel Source Walkthrough
→ 버전 영향 큼

PCIe BAR 기본 구조
→ 비교적 안정적

특정 XRT Runtime API
→ 변동 큼
```
