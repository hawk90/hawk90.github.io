# Task 3-8. 테스트·회귀 검증·출시 체크리스트 백로그

이번 단계의 목표는 지금까지 바꾼 구조가 다시 무너지지 않도록 **최소한의 자동 검증과 출시 절차**를 만드는 것이다.

핵심은 이것이다.

```text
모든 것을 테스트하는 것
≠
깨지면 큰 문제가 되는 계약을 보호하는 것
```

보호해야 할 핵심 계약은 다음이다.

```text
URL
콘텐츠 상태
검색 결과
Topic Hub 관계
Sitemap·canonical
최종 dist
모바일 읽기
배포 권한
```
