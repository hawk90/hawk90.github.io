# 7. 검색 결과 페이지에 광고 표시

```text
/search?q=pcie
```

페이지의 본질은 사용자의 입력에 따라 결과를 나열하는 것이다.

게시자가 작성한 독립 콘텐츠라기보다 탐색 도구에 가깝다.

따라서 공개 검색 페이지는 일반적으로:

```text
noindex,follow
Sitemap 제외
광고 제외
```

가 적합하다.

검색 결과가 없을 때:

```text
검색 결과 없음
+
광고
```

만 보이는 상황은 특히 피해야 한다.
