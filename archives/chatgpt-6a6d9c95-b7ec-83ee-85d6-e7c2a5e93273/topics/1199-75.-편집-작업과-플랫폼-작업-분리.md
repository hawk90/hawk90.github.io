# 75. 편집 작업과 플랫폼 작업 분리

다음 변경을 하나의 PR에 묶지 않는다.

```text
Schema 변경
+
Article Layout 개편
+
글 200개 metadata 수정
```

권장:

```text
1. Schema는 optional로 추가
2. 대표 문서 적용
3. UI가 새 metadata 지원
4. 대량 Migration
5. Strict 규칙 강화
```
