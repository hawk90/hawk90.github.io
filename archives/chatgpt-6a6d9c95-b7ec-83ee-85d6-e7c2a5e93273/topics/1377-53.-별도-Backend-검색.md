# 53. 별도 Backend 검색

수백 개 기술 글 검색에 Elasticsearch·Typesense·Meilisearch 같은 별도 서버를 붙이는 것은 과도할 가능성이 높다.

추가 비용:

```text
Hosting
Index 동기화
API 장애
Secret
CORS
비용
```

정적 Search Index로 품질과 크기를 먼저 측정한다.

실제 한계를 확인한 뒤에만 서버 검색을 검토한다.
