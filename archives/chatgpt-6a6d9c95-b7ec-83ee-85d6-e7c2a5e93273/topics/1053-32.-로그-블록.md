# 32. 로그 블록

로그 전체를 붙이지 않는다.

다음 구조를 권장한다.

```text
핵심 로그
→ 각 줄의 의미
→ 전후 문맥이 필요하면 접기 또는 외부 파일
```

예:

```text
pci 0000:01:00.0: BAR 0: no space for [mem size 0x10000000 64bit pref]
```

설명:

```text
운영체제가 256MB 크기의 64-bit Prefetchable MMIO Window를
배치할 수 있는 주소 공간을 찾지 못했다는 의미다.
```
