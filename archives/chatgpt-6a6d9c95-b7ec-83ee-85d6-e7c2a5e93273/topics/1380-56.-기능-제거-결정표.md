# 56. 기능 제거 결정표

각 기능에 다음을 답한다.

| 질문 | 판단 |
|---|---|
| 독자가 실제로 사용하는가 | 아니면 제거 후보 |
| 콘텐츠가 없어도 기능 자체로 가치가 있는가 | 대체로 아니어야 함 |
| 실패하면 본문이 깨지는가 | 결합 해제 필요 |
| JavaScript가 반드시 필요한가 | 아니면 정적화 |
| 외부 서비스가 필요한가 | 실패 격리 |
| 최근 3개월 수정·사용했는가 | 아니면 재검토 |
| 더 단순한 브라우저 기능이 있는가 | 있으면 대체 |
