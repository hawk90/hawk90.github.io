# 62. 내부 링크 Manifest

문서별 링크를 저장한다.

```ts
export interface DocumentLinkManifest {
  documentId: string;

  outboundDocumentIds: readonly string[];

  inboundDocumentIds: readonly string[];

  brokenLinks: readonly string[];
  redirectedLinks: readonly string[];
}
```

본문 링크와 relation metadata를 함께 분석한다.
