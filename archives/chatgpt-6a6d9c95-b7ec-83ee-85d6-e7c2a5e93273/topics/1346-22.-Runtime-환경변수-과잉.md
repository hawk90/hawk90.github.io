# 22. Runtime 환경변수 과잉

정적 사이트인데도 많은 환경변수가 필요한 경우 아키텍처가 과도해졌을 가능성이 있다.

```text
PUBLIC_API_URL
ADMIN_API_URL
CMS_TOKEN
SEARCH_API_URL
AUTH_CLIENT_ID
SESSION_SECRET
```

일반적인 GitHub Pages 기술 블로그에 이 정도 Runtime 설정은 필요하지 않다.

공개 설정과 Secret도 명확히 분리한다.
