# 21. 테스트에서 현재 날짜 직접 사용

```ts
const now = new Date();
```

를 사용하면 자정, Timezone, 시간이 흐름에 따라 테스트가 깨질 수 있다.

특히:

```text
미래 발행
Freshness
Copyright
검토 기한
```

에 영향이 크다.

시간은 명시적으로 주입한다.

```ts
const context = {
  now: new Date(
    "2026-08-01T00:00:00Z",
  ),
};
```
