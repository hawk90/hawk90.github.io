# 32. Layout 구조

```text
src/layouts/
├── BaseLayout.astro
├── ArticleLayout.astro
├── TopicHubLayout.astro
└── StaticPageLayout.astro
```

---

## BaseLayout

담당:

```text
HTML document
공통 Head
Header
Footer
전역 CSS
기본 script
```

담당하지 않을 것:

```text
광고 무조건 삽입
Article metadata 결정
Topic 데이터 수집
검색 인덱스 preload
```

---

## ArticleLayout

담당:

```text
Article Header
Status Notice
TOC
본문
Environment
Relations
오류 제보
```

---

## TopicHubLayout

담당:

```text
Topic Hero

```
