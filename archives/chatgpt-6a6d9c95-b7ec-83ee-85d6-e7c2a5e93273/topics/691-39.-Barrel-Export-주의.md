# 39. Barrel Export 주의

다음처럼 모든 것을 `index.ts`에서 재수출하면 import는 짧아진다.

```ts
export * from "./content-model";
export * from "./manifest";
export * from "./queries";
```

하지만 대규모 barrel은 다음 문제를 만든다.

```text
순환 dependency
실제 source 추적 어려움
불필요한 module load
동일 이름 충돌
```

권장:

- 작은 bounded context 내부에서만 사용
- Domain 전체를 하나의 index에서 재수출하지 않음
- 핵심 import는 원본 파일을 명시
