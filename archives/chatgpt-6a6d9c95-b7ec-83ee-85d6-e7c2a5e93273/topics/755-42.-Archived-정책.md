# 42. Archived 정책

```ts
function archivedDecision():
  PublicationDecision {
  return {
    render: true,

    index: false,
    follow: false,

    includeInSearch: false,
    includeInSitemap: false,
    includeInRss: false,
    includeInTopicLists: false,

    canBeFeatured: false,
    adsEligible: false,

    searchRankMultiplier: 0,
  };
}
```

## Render를 유지하는 이유

기존 외부 링크와 기록 보존을 위해 직접 URL 접근은 가능하게 할 수 있다.

완전히 삭제할 문서는 별도 deletion·redirect 정책으로 처리한다.
