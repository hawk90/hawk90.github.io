# 11. Prerequisites

고급 글은 본문 전에 선행 개념을 알려준다.

예:

```text
먼저 알아두면 좋은 내용

· PCIe Configuration Space
· Memory-Mapped I/O
```

## 표시 기준

```text
필수 선행 지식이 실제로 있을 때만
최대 2~3개
```

5개 이상이라면 현재 문서가 너무 많은 개념을 한 번에 요구하거나, 상위 Guide가 필요한 신호일 수 있다.
