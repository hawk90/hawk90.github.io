# 4. HTML을 정규식으로 테스트

나쁜 예:

```ts
expect(html).toMatch(
  /<meta name="description".*>/
);
```

HTML 속성 순서, 공백, 줄바꿈이 바뀌면 깨진다.

반대로 잘못된 위치의 문자열도 통과할 수 있다.

권장:

```text
HTML Parser
DOM Query
Semantic Selector
```

를 사용한다.

개념 예:

```ts
const document =
  parseHtml(generatedHtml);

const canonical =
  document.querySelector(
    'link[rel="canonical"]',
  );

expect(canonical).not.toBeNull();
```
