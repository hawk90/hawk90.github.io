# 74. 주제별 깊이가 보이지 않음

글이 많아도 한눈에 보면:

```text
각 Topic에 1~2개씩 흩어짐
```

처럼 보일 수 있다.

실제로는 CUDA·PCIe 글이 많아도 Tag와 날짜에 분산돼 있기 때문이다.

## 깊이를 보이게 하는 방법

```text
Topic Hub
대표 Guide
Concept
Source Walkthrough
Debug Note
Experiment
```

를 하나의 묶음으로 보여준다.

새 글을 더 쓰지 않아도 기존 깊이가 드러날 수 있다.
