# H-16. 접근성 자동 검사

대표 페이지에 axe 계열 자동 검사를 적용할 수 있다.

## 대상

```text
홈
Topic Hub
대표 Guide
검색 modal
404
```

## 자동으로 잘 잡는 항목

```text
accessible name 누락
색 대비 일부
heading 구조 일부
form label
ARIA 오류
중복 ID
```

## 자동 검사로 충분하지 않은 항목

```text
링크 문구 품질
문서 논리 구조
다이어그램 설명
focus 이동의 자연스러움
```

## 완료 조건

- 심각한 자동 접근성 오류 0개
- warning은 의도와 이유를 검토
- suppression은 구체적인 요소에만 적용
- 라이트·다크 테마 중 최소 대표 페이지 검사

## 우선순위

```text
P1
```
