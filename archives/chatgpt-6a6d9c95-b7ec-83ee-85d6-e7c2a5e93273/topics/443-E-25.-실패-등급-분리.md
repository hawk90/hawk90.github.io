# E-25. 실패 등급 분리

모든 감사가 release blocker가 되면 결국 검사를 끄게 된다.

## Error

```text
schema 불일치
중복 URL
없는 내부 문서
필수 asset 누락
검색 JSON 생성 실패
production build 실패
```

## Warning

```text
description 누락
대형 코드 블록
오래된 외부 링크
needs-review 장기 방치
대형 이미지
```

## Info

```text
새로운 alias 후보
중복 가능성
Hub 편입 후보
읽기 환경 보완 제안
```

## 완료 조건

- 각 rule의 severity가 명시됨
- Warning만으로 배포가 막히지 않음
- 중요한 오류가 수백 개 warning에 묻히지 않음

```text
P0
```
