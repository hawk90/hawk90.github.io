# 97. CSS Selector Specificity 경쟁

```css
.article .content .prose h2.title
```

처럼 Selector가 깊어지면 Override를 위해 더 강한 Selector가 필요하다.

권장:

```text
낮은 Specificity
명확한 Component Root
Token
Cascade Layer
```

를 검토한다.

`!important`가 늘기 시작하면 Cascade 설계를 점검한다.
