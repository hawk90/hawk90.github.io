# 11. 글의 깊이와 길이를 동일하게 보는 문제

## Length-as-Depth

긴 글이라고 깊은 글은 아니다.

다음과 같은 글은 길어도 가치가 낮을 수 있다.

- 사양 내용을 순서대로 재서술
- 일반적인 개념 설명 반복
- 코드 전체를 그대로 붙임
- 로그 전체를 붙임
- 제목과 관계없는 배경 설명 확대
- 결론 없이 여러 자료를 모음

반면 짧은 글도 다음이 있으면 가치가 높다.

- 명확한 문제
- 독창적인 관찰
- 재현 가능한 실험
- 정확한 결론
- 다른 자료에서 찾기 어려운 정보

애드센스 대응을 위해 글자 수를 늘리는 것은 위험하다.

> 콘텐츠 가치는 분량이 아니라 정보 밀도와 독창성에서 나온다.
