# 55. 미지원 Syntax Grammar

기존 글에 잘못된 언어명이 있으면 Build 실패나 평문 처리 문제가 생길 수 있다.

감사 리포트:

```text
Unknown code languages

c++: 23
console-session: 12
make: 8
verilog-system: 4
```

각 언어를:

```text
정상 Alias로 변환
Plain Text로 처리
Custom Grammar 추가
```

중 선택한다.
