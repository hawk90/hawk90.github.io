# 39. 내부 링크가 구판으로 계속 향함

신판을 만들었지만 기존 글 30개가 계속 구판 URL을 링크하면:

```text
내부 권위 분산
사용자 구판 진입
Canonical 신호 혼란
```

이 생긴다.

Google은 내부 링크에서 선호하는 Canonical URL을 일관되게 사용하도록 권장한다. citeturn517910search5

## 신판 발행 시 검사

```text
본문 내부 링크
Topic Hub
Featured
관련 글
검색 Alias
Sitemap
RSS
```

를 신판 중심으로 바꾼다.
