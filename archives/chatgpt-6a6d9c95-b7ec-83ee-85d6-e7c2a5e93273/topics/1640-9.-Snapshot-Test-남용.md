# 9. Snapshot Test 남용

다음 전체를 Snapshot으로 저장할 수 있다.

```text
Content Manifest
Search Index
전체 Article HTML
Topic Hub HTML
```

처음에는 편하지만 작은 변경마다 수천 줄 Diff가 발생한다.

개발자는 내용을 확인하지 않고 Snapshot을 갱신하게 된다.

```text
실패
→ 무슨 차이인지 안 봄
→ update snapshot
```

### Snapshot이 적합한 것

```text
작고 안정적인 구조
정렬된 Policy Matrix
짧은 Structured Data
의도적으로 검토 가능한 출력
```

### 적합하지 않은 것

```text
전체 사이트 HTML
전체 검색 Index
500개 문서 Manifest
날짜와 Hash가 포함된 출력
```
