# B-21. 대표 문서 최소 metadata

대표 문서부터 다음을 갖춘다.

```yaml
type: guide
topic: pcie-cxl
status: current
updated: 2026-08-01
```

실제로 검증했다면:

```yaml
lastVerified: 2026-08-01
```

하지만 단순 문장 수정만 했다면 `lastVerified`를 바꾸지 않는다.
