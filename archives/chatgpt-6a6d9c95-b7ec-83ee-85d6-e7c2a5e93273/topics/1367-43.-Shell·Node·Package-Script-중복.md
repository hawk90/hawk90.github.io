# 43. Shell·Node·Package Script 중복

같은 작업이 다음 세 곳에 구현될 수 있다.

```text
package.json
scripts/build.sh
scripts/build.ts
GitHub Actions YAML
```

GitHub Actions에서는 로직을 직접 길게 쓰지 않고 저장소 명령을 호출한다.

```yaml
- run: npm run check
- run: npm run build
```

로컬과 CI가 같은 경로를 사용해야 한다.
