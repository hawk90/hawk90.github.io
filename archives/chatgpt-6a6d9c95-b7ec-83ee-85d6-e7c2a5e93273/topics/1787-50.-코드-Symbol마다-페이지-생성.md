# 50. 코드 Symbol마다 페이지 생성

향후 소스 분석 시스템에서:

```text
/function/pci_scan_child_bus/
/function/pci_bus_add_devices/
```

처럼 자동 문서를 생성할 수 있다.

단순 Signature와 호출 위치만 있는 페이지가 수천 개 생기면 사이트의 콘텐츠 품질을 희석할 수 있다.

## 공개 색인 조건

```text
사람이 작성한 설명
호출 흐름
핵심 분기
관련 자료구조
버전
실제 의미
```

자동 Symbol Index는 내부 검색 기능이나 noindex Reference로 두는 편이 안전하다.
