# 6. Fixture가 현실과 지나치게 다름

반대로 Fixture가 너무 단순할 수도 있다.

```ts
{
  id: "a",
  title: "test"
}
```

만 사용하면 실제 문제를 놓친다.

실제 사이트에는 다음이 있다.

```text
한글 제목
C++
MSI-X
긴 Description
Historical 상태
빈 관계
여러 Heading
긴 Symbol
```

따라서 Fixture를 두 계층으로 나눈다.

## Minimal Fixture

특정 규칙만 확인.

## Representative Fixture

실제 기술 문서 형태를 재현.
