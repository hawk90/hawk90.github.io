# 83. Metadata Collector Plugin

공통 remark plugin을 만든다면 다음을 수집할 수 있다.

```text
heading
internal link
external link
code language
symbol 후보
error block
```

Plugin 결과를 front matter에 다시 쓰지 않고 build metadata로 전달한다.

단, plugin이 global mutable array에 데이터를 쌓는 구조는 HMR과 병렬 처리에서 위험하다.

문서별 결과를 반환하는 구조가 낫다.
