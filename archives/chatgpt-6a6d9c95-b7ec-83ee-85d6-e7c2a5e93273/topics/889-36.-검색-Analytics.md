# 36. 검색 Analytics

검색 품질 개선을 위해 필요한 최소 이벤트만 고려한다.

```text
검색 실행
결과 없음
선택한 결과 순위
재검색 여부
```

그러나 전체 원문 query를 외부 Analytics로 전송하면 주의가 필요하다.

사용자가 다음을 입력할 수 있다.

```text
회사 hostname
사내 오류 로그
고객 식별자
내부 함수명
```

권장 선택:

```text
검색어 원문 미수집
또는
로컬 집계
또는
짧은 기간·명시적 정책
```
