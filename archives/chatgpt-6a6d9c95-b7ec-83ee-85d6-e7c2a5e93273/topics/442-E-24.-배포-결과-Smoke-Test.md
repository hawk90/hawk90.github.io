# E-24. 배포 결과 Smoke Test

빌드 성공 뒤 실제 `dist`를 로컬 서버로 열어 검사한다.

## 최소 URL

```text
/
대표 Guide
PCIe & CXL Hub
Firmware & Bootloader Hub
검색 페이지
404
```

## 검사

```text
HTTP 200 또는 예상 상태
title 존재
canonical 존재
H1 하나
주요 CSS·JS 로드
검색 JSON parse
대표 이미지 존재
내부 핵심 링크 유효
```

## 완료 조건

- source가 아니라 최종 `dist` 검사
- GitHub Pages의 실제 base path 조건 반영
- 배포 전 자동 실행
- 외부 광고·댓글 실패는 본문 성공에 영향 없음

## 우선순위

```text
P0
```
