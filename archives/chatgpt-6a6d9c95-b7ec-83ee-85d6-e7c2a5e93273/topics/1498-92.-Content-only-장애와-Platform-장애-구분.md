# 92. Content-only 장애와 Platform 장애 구분

## Content 장애

```text
잘못된 기술 내용
깨진 Markdown
잘못된 링크
```

## Platform 장애

```text
CSS 없음
전체 404
Build 실패
Search Index Schema 오류
```

대응이 다르다.

Content 오류는 특정 문서 Revert로 해결할 수 있지만 Platform 오류는 전체 Deployment Rollback이 더 적합할 수 있다.
