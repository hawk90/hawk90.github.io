# Task 3-16. Content Manifest와 Publication Policy 실제 TypeScript 설계

이번 단계는 앞서 만든 아키텍처에서 가장 핵심적인 두 요소를 실제 코드 수준으로 구체화한다.

```text
Content Manifest
+
Publication Policy
```

이 둘이 안정되면 다음 기능들이 같은 기준으로 움직일 수 있다.

```text
홈
Topic Hub
검색
관련 글
RSS
Sitemap
SEO
광고
검증
```

반대로 이 둘이 불명확하면 각 기능이 콘텐츠를 제각각 해석하게 된다.
