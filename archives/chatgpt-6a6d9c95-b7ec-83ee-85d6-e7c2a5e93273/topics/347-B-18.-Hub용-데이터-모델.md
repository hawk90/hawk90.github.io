# B-18. Hub용 데이터 모델

초기 권장 모델:

```ts
interface TopicHubConfig {
  id: string;
  title: string;
  description: string;
  startHere: string[];
  featured: string[];
  sections: {
    title: string;
    description?: string;
    articles: string[];
  }[];
  relatedTopics: string[];
}
```

예:

```ts
export const PCIE_CXL_HUB = {
  id: "pcie-cxl",
  title: "PCIe & CXL",
  description: "...",
  startHere: [
    "pcie-device-initialization",
    "pcie-bar-sizing",
    "cxl-memory-address-mapping",
  ],
  featured: [
    "linux-pci-enumeration",
    "pcie-msix",
    "cxl-hdm-decoder",
  ],
};
```

복잡한 CMS는 필요 없다.
