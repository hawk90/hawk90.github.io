# 27. 문자열로 URL 조립

나쁜 예:

```ts
const href = base + "/search-index.json";
```

슬래시 중복·누락과 Subpath 문제가 생긴다.

공통 URL Helper 또는 Astro의 Base URL 처리 방식을 사용한다.

대표 URL 테스트를 다음 환경에서 수행한다.

```text
Local Root
Preview Base Path
Production Origin
```
