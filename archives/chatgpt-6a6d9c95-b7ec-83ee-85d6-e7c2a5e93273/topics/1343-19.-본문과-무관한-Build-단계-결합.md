# 19. 본문과 무관한 Build 단계 결합

다음 구조는 실패 전파 범위가 너무 넓다.

```text
Article Build
→ 외부 링크 검사
→ OG 생성
→ Analytics Report
→ Screenshot
→ 배포
```

외부 사이트 하나가 일시적으로 응답하지 않아도 글 수정 배포가 실패한다.

분리:

```text
필수 Build
선택적 Asset Build
Scheduled Audit
```
