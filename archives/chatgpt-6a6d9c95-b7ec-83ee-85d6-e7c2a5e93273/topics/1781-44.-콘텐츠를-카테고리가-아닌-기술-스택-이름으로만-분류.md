# 44. 콘텐츠를 카테고리가 아닌 기술 스택 이름으로만 분류

```text
C++
Rust
Python
Linux
```

만 있으면 사용자가 해결하려는 문제와 맞지 않을 수 있다.

예:

```text
PCIe Driver를 이해
```

하려면:

```text
C
Linux
Firmware
Hardware
```

글이 여러 카테고리에 흩어진다.

따라서 검색 가치가 높은 랜딩 페이지는 언어보다 문제 영역 중심이 좋다.

```text
PCIe & CXL
GPU & CUDA
Firmware & Boot
Linux Internals
Performance Engineering
```
