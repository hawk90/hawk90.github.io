# 88. Publication Policy Version

정책 변경 자체는 Content Hash를 바꿀 필요가 없다.

하지만 Search·Sitemap 파생 산출물은 다시 생성해야 한다.

```ts
export const PUBLICATION_POLICY_VERSION =
  "1";
```

파생 artifact hash에 포함한다.

```text
contentHash
+
publicationPolicyVersion
+
generatorVersion
```
