# 33. Sidebar가 본문 폭을 지속적으로 침식

Desktop에서 TOC와 Related Sidebar를 동시에 두면 본문이 좁아질 수 있다.

기술 문서는 Code 폭이 중요하므로:

```text
TOC
본문
Related
```

3열 구조를 무조건 유지하지 않는다.

관련 문서는 본문 하단으로 보내고, Desktop에는 TOC 하나만 두는 편이 안정적이다.
