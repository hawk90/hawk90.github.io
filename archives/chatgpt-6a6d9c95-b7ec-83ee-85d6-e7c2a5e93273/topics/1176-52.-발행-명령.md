# 52. 발행 명령

단순 workflow를 만들 수 있다.

```bash
npm run content:publish -- pcie-bar-sizing
```

수행:

```text
문서 존재 확인
draft=true 확인
필수 validation
published 비어 있으면 오늘 날짜 설정
updated 설정 여부 확인
draft=false 변경
```

하지만 자동으로 `status=current`로 바꾸지는 않는다.

사용자가 명시해야 한다.

```bash
npm run content:publish -- \
  pcie-bar-sizing \
  --status current
```
