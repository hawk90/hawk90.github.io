# 59. Markdown 링크를 ID로 직접 쓰는 안티패턴

```markdown
[PCIe BAR](content:pcie-bar-sizing)
```

같은 Custom Protocol은 편리할 수 있지만:

```text
일반 Markdown 호환성 저하
GitHub Preview에서 동작하지 않음
Editor 지원 필요
```

문제가 있다.

관계 Metadata는 ID를 사용하고 본문 링크는 일반 URL을 유지하는 절충이 좋다.
