# 69. Warning 정책

초기 migration에서 warning이 너무 많으면 아무도 보지 않는다.

따라서 Warning도 운영해야 한다.

## 초기 Warning

```text
unclassified topic
missing type
lastVerified 없음
대형 코드 블록
```

## Error

```text
중복 ID
중복 URL
없는 relation
Featured 비current
Draft Sitemap 유출
superseded target 없음
```

## 점진 강화

대표 문서에 대해서는 다음을 Error로 강화한다.

```text
type 없음
topic 없음
description 없음
상태 미명시
```

일반 Legacy 문서에는 Warning을 유지한다.
