# D-11. 고아 문서 정의

모든 내부 링크가 없는 글을 무조건 문제로 보지 않는다.

## 실질적인 고아 문서

다음을 모두 만족하는 글:

```text
공개 상태
일반 검색 대상
상위 Topic 없음
들어오는 의미 링크 없음
시리즈 소속 없음
```

태그 목록이나 아카이브 링크만 있는 경우도 구조상 고아에 가깝다.

## 예외

- 독립 Reference
- Historical 기록
- 의도적인 standalone landing page

예외도 가능하지만 이유를 기록한다.
