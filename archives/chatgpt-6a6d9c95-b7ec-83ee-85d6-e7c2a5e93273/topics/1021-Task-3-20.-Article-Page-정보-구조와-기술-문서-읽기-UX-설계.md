# Task 3-20. Article Page 정보 구조와 기술 문서 읽기 UX 설계

앞에서는 문서 사이의 관계를 설계했다.

이번 태스크는 개별 글 페이지가 다음 역할을 제대로 수행하도록 만드는 단계다.

```text
검색·Hub에서 들어온 독자에게
→ 이 글이 무엇을 설명하는지 알려주고
→ 현재도 믿을 수 있는지 보여주고
→ 긴 기술 내용을 읽기 쉽게 만들고
→ 다음 문서로 연결한다
```

핵심은 단순히 Markdown을 예쁘게 렌더링하는 것이 아니다.

> 기술 문서의 범위·근거·환경·본문 구조·코드·결론·다음 행동을 하나의 읽기 흐름으로 설계해야 한다.
