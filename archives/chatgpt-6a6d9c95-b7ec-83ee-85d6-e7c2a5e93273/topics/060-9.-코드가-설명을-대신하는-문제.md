# 9. 코드가 설명을 대신하는 문제

## Code-as-Explanation

코드 블록이 길수록 글이 깊어 보일 수 있지만, 실제로는 반대일 때가 많다.

```cpp
// 150줄 코드
```

뒤에:

```text
위 코드와 같이 구현한다.
```

라고 끝나면 독자는 중요한 설계 판단을 알아내기 위해 직접 코드를 분석해야 한다.

### 좋은 코드 설명

코드 자체보다 다음을 설명해야 한다.

- 왜 이 구조를 선택했는가
- 대안은 무엇이었는가
- 어떤 불변조건을 유지하는가
- 실패할 수 있는 경로는 무엇인가
- 성능 비용은 어디서 발생하는가
- 어떤 부분이 예시를 위한 단순화인가

### 코드 블록 역할 분리

```text
Minimal Example
Core Logic
Production Consideration
Failure Path
Complete Source
```

전체 코드는 GitHub에 두고, 본문에는 설명에 필요한 부분만 남기는 게 좋다.
