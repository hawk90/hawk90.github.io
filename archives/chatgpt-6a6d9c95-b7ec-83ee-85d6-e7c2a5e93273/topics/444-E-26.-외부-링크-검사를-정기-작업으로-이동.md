# E-26. 외부 링크 검사를 정기 작업으로 이동

외부 URL은 일시 장애와 rate limit 때문에 CI를 불안정하게 만든다.

## 매 변경마다

```text
내부 링크
내부 anchor
문서 ID
redirect target
```

## 주간 또는 월간

```text
외부 링크
최종 redirect
HTTP 상태
반복 실패
```

## 결과 정책

```text
1회 실패 → 기록
연속 실패 → warning
핵심 출처 반복 실패 → 수동 검토
```

## 완료 조건

- 외부 네트워크 장애가 일반 배포를 막지 않음
- 반복 실패 링크는 추적됨
- 핵심 사양·소스 링크는 높은 우선순위로 표시됨

## 우선순위

```text
P1
```
