# 이번 단계의 핵심 결론

수백 개의 기존 글을 한 번에 완벽하게 정리하려는 계획은 성공하기 어렵다.

가장 현실적인 방식은 다음이다.

```text
전체 Inventory
→ 대표 문서 우선
→ Topic별 작은 Batch
→ Metadata와 본문 분리
→ 기존 URL 보존
→ Historical·Superseded 적극 활용
→ Legacy Adapter로 공존
```

즉, 마이그레이션의 목표는 모든 과거 글을 새 글처럼 만드는 것이 아니다.

> 좋은 글을 대표 경로로 끌어올리고, 과거 글에는 정확한 역할을 부여하며, 약한 콘텐츠가 사이트 전체의 인상을 결정하지 못하게 만드는 것이다.
