# 55. AI 기능 공개 사이트 삽입

“내 글에 질문하기” 같은 AI Chat을 넣으면 흥미로워 보이지만 다음이 필요하다.

```text
Embedding
Vector DB
API 비용
Prompt Injection 대응
잘못된 답변
출처 표시
개인정보
Rate Limit
```

현재 문제인 콘텐츠 내용과 탐색 품질을 해결하기 전에 AI 인터페이스를 추가하면 본질을 흐릴 수 있다.

먼저 검색·Hub·대표 문서를 완성한다.
