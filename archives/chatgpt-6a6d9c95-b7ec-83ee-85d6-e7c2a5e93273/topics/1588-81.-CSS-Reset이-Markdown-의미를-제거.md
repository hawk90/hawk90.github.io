# 81. CSS Reset이 Markdown 의미를 제거

전역 Reset이:

```css
ul {
  list-style: none;
}
```

```css
button {
  background: none;
}
```

를 적용한 뒤 Prose에서 복구를 잊을 수 있다.

Navigation List와 Article List는 요구가 다르다.

Reset은 최소화하고 Component에서 명시적으로 스타일링한다.
