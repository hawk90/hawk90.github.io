# 3. 거대한 `global.css`

다음처럼 한 파일이 계속 커질 수 있다.

```text
Reset
Header
Footer
Article
Card
Search
Code
Table
Dark Mode
Mobile
Print
Admin
Legacy
```

수천 줄짜리 전역 CSS는 Selector 영향 범위를 판단하기 어렵다.

권장 구조 예:

```text
src/styles/
├── tokens.css
├── reset.css
├── base.css
├── typography.css
├── prose.css
├── utilities.css
└── print.css
```

페이지·컴포넌트별 스타일은 해당 컴포넌트에 둔다.

단, 파일을 50개로 잘게 나누는 것도 목적이 아니다.

구분 기준은 **변경 이유가 같은가**이다.
