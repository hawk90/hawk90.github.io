# 97. Migration 종료 조건

전체 문서가 모두 `current`가 되는 것이 종료 조건이 아니다.

다음이면 1차 종료다.

```text
대표 문서와 Hub가 완성됨
중요 검색 경로에 Legacy 구판이 방해하지 않음
빈·중복·Placeholder가 정리됨
나머지 Legacy 문서가 안전하게 렌더됨
새 문서는 새 Workflow로 작성됨
정기 Review Queue가 작동함
```
