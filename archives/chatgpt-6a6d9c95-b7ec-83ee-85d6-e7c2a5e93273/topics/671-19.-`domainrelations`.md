## 관계 모델

```ts
export interface DocumentRelations {
  parentTopicId: string;
  prerequisites: string[];
  next: string[];
  related: string[];
  supersededBy?: string;
}
```

그래프 데이터베이스는 필요 없다.

Map과 Set이면 충분하다.

```ts
export interface RelationGraph {
  prerequisitesByDocument:
    ReadonlyMap<string, ReadonlySet<string>>;

  dependentsByDocument:
    ReadonlyMap<string, ReadonlySet<string>>;

  relatedByDocument:
    ReadonlyMap<string, ReadonlySet<string>>;
}
```
