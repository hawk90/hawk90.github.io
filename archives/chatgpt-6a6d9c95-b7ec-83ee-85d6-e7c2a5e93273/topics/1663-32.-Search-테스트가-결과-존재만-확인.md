# 32. Search 테스트가 결과 존재만 확인

```ts
expect(results.length)
  .toBeGreaterThan(0);
```

는 검색 품질을 보장하지 않는다.

중요한 것은:

```text
대표 문서가 상위에 있는가
구판이 앞서지 않는가
Symbol 검색이 정확한가
한글 Alias가 연결되는가
```

이다.

Golden Query 테스트는 Top-N과 제외 문서를 확인한다.
