# 27. 도구 페이지에 설명이 없음

향후 계산기나 Analyzer Demo를 추가할 수 있다.

예:

```text
BAR Size Calculator
```

입력창과 버튼만 있고 설명이 없다면 행동 목적 화면에 가깝다.

## 도구 페이지에 필요한 콘텐츠

```text
도구가 해결하는 문제
입력값 의미
계산 원리
예제
제한
관련 기술 설명
```

도구 자체가 유용해도 광고를 둘 페이지라면 게시자 설명 콘텐츠가 충분히 존재해야 한다.
