# 71. 반대로 매 변경에 모든 Visual Test 실행

오탈자 수정 하나에도 전체 브라우저 Matrix와 Visual Test를 돌리면 비용이 과하다.

변경 범위 분류:

```text
콘텐츠 본문
Metadata
CSS
검색
Markdown Pipeline
Layout
```

에 따라 추가 Test Suite를 실행할 수 있다.

그러나 조건 로직이 너무 복잡해지면 단순히 핵심 Smoke는 항상 실행하는 편이 낫다.
