# 23. Callout 예

```text
관찰

BAR2를 mmap하는 작업 자체는 성공했지만,
읽은 값은 모두 0xffffffff였다.
```

```text
가설

장치 내부 DDR Controller가 아직 초기화되지 않아
유효한 데이터가 노출되지 않았을 가능성이 있다.

해당 상태 Register를 직접 확인하지 못했으므로
확정된 원인으로 보지는 않는다.
```

이런 구분은 문서 신뢰도를 크게 높인다.
