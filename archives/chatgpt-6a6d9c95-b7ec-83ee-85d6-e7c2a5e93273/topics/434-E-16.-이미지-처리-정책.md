# E-16. 이미지 처리 정책

모든 이미지를 매번 다시 최적화하지 않는다.

## 원본과 파생물

```text
assets/source/
assets/generated/
```

또는 논리적으로라도 구분한다.

## 입력 hash

```text
원본 파일 hash
출력 크기
format
quality
transformer version
```

## 문서별 검사

변경된 문서의 이미지에 대해서만:

```text
존재 여부
width·height
대형 파일
alt 후보
```

를 확인한다.

전체 미사용 이미지 감사는 정기 작업으로 돌린다.

## 우선순위

```text
P1
```
