# 31. Broad Topic 검색

Topic title 또는 alias와 정확히 일치하면 Hub를 특별한 결과로 보여준다.

```ts
export interface TopicSearchResult {
  kind: "topic";
  topicId: string;
  href: string;
  title: string;
  description: string;
}
```

문서 결과와 구분한다.

```text
TOPIC

PCIe & CXL

PCIe 장치 초기화, BAR, MSI-X, DMA와
CXL 메모리 주소 변환을 학습 순서로 살펴봅니다.
```
