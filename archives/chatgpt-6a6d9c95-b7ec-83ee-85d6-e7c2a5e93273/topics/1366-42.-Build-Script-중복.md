# 42. Build Script 중복

`package.json`에 비슷한 명령이 쌓일 수 있다.

```text
build
build:prod
build:production
build:full
build:all
release
deploy-build
```

실제 차이가 불명확하면 사람과 CI가 서로 다른 경로를 실행한다.

권장 핵심 명령:

```text
check
build
audit
test:smoke
deploy
```
