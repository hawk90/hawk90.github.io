# 25. 로그 Redaction 검수

발행 전 다음을 검사한다.

```text
사내 hostname
IP 주소
사용자명
홈 디렉터리
이메일
내부 GitLab·Jira URL
고객명
장치 Serial
Token
절대 경로
```

예:

```text
/home/sangdeok/project
```

대신:

```text
/home/user/project
```

로 일반화한다.
