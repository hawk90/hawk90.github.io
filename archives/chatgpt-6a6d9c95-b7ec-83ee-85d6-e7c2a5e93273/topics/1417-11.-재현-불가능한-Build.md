# 11. 재현 불가능한 Build

같은 Commit을 다시 Build했는데 결과가 달라질 수 있는 원인:

```text
고정되지 않은 Node 버전
Lockfile 무시
외부 API
현재 시간
랜덤 ID
파일 순서
OS Locale
Timezone
```

최소한 다음을 고정한다.

```text
Node Version
Package Manager Version
Lockfile
Locale
Timezone
```

예:

```text
TZ=Asia/Seoul
LANG=ko_KR.UTF-8
```

또는 날짜 생성은 명시적인 UTC·ISO 규칙을 사용한다.
