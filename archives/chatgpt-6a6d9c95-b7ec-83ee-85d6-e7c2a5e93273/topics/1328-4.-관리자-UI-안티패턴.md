# 4. 관리자 UI 안티패턴

개인 블로그에 관리자 페이지를 만들면 다음 요구가 연쇄적으로 따라온다.

```text
로그인
권한
Session
CSRF
Content API
저장 실패 처리
이미지 업로드
Preview
Revision
배포 Trigger
Secret 관리
```

처음에는 “Markdown을 편하게 수정하려고” 시작했는데, 블로그보다 관리 도구 유지 비용이 커진다.

GitHub 저장소와 IDE를 이미 사용한다면 대부분 다음이면 충분하다.

```text
Markdown
Git
Preview server
CLI validator
GitHub Actions
```

관리자 UI가 실제로 매주 사용되지 않는다면 삭제 후보가 맞다.
