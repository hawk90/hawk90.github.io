# 80. Canonical이 `localhost`나 Preview Domain

`SITE.origin` 설정이 빠지면 다음이 생성될 수 있다.

```text
http://localhost:4321/...
preview-branch.example/...
```

Production Build에서는 Canonical Origin Allowlist를 검증한다.

```text
https://hawk90.github.io
또는 실제 Custom Domain
```

이외 Origin이면 Build Error 처리한다.
