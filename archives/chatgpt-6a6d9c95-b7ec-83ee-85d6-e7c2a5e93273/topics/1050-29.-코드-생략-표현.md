# 29. 코드 생략 표현

무작정:

```cpp
// ...
```

만 쓰면 무엇이 생략됐는지 알기 어렵다.

권장:

```cpp
// Error handling omitted for clarity.
// Descriptor initialization continues here.
```

또는:

```cpp
// Remaining queue entries are initialized identically.
```

생략 이유와 범위를 설명한다.
