# 76. Copy Heading Link

Heading에 Permalink 기능을 제공할 수 있다.

권장 동작:

```text
Heading Focus 또는 Hover
→ 작은 링크 버튼 표시
→ 클릭하면 URL 복사 또는 해당 Anchor 이동
```

모바일에서는 버튼이 Heading을 가리지 않게 한다.

링크 아이콘만 있고 accessible name이 없는 상태를 피한다.
