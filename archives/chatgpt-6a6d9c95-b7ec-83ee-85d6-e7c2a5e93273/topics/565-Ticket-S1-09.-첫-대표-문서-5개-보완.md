# Ticket S1-09. 첫 대표 문서 5개 보완

## 목적

홈과 Topic Hub에서 실제로 사용할 수 있는 문서를 확보한다.

## 선택 조건

```text
보완량이 낮거나 중간
서로 다른 Topic을 대표
구판 가능성이 낮음
실제 경험이나 분석이 있음
```

## 각 문서 작업

### 1. 제목

한 가지 질문에 집중한다.

### 2. Description

제목을 반복하지 않고 범위와 결과를 설명한다.

### 3. Metadata

```yaml
type:
topic:
status:
updated:
lastVerified:
```

### 4. 환경·버전

필요한 글만 추가한다.

### 5. 근거 구분

```text
확인된 사실
직접 관찰
해석
가설
```

### 6. 한계

확인하지 않은 조건을 명시한다.

### 7. 다음 경로

```text
상위 Topic
필요한 선행 글
다음에 읽을 글
관련 실전 사례
```

## 완료 조건

```text
[ ] 5개 모두 status=current
[ ] 기술적으로 다시 읽고 확인
[ ] description 고유
[ ] Topic과 Type 지정
[ ] 범위·한계 표시
[ ] 다음 문서 연결
```

## 예상 작업량

문서당:

```text
1~3시간
```

전체:

```text
5~15시간
```
