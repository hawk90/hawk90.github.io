# 36. 범용 `Card` 컴포넌트

다음 Props가 늘어나면 잘못된 추상화다.

```ts
<Card
  variant="featured"
  horizontal
  compact
  bordered
  interactive
  showTopic
  showDate
  showStatus
  imagePosition="left"
/>
```

하나의 Card가 모든 화면을 처리하면서 내부 조건문이 폭발한다.

대신 역할 중심 컴포넌트를 둔다.

```text
FeaturedGuideCard
ArticleListItem
TopicCard
```

공통 시각 Primitive만 공유한다.
