# 8. 한국어 제목과 ID

한글 제목 전체를 로마자 변환하는 방식은 예측하기 어렵다.

피해야 할 예:

```text
pcie-bareul-eoddeohge...
```

권장:

```text
영문 기술 고유명
+
문서 핵심 역할
```

예:

```text
pcie-bar-size-probing
linux-driver-probe-flow
cuda-bank-conflict
```

사용자가 직접 수정할 수 있는 생성 후보를 제공한다.
