### 문제

수정과 재생성이 어렵다.

### 개선

```text
diagram source
generator version
generated output
```

관계를 보존한다.

### 개선

## R-47. No Original Image Preservation

### WebP 변환 후 원본 삭제

### 문제

## R-48. Font-Dependent SVG

### 특정 시스템 폰트가 없으면 라벨 위치가 깨짐

### 개선

---

## R-49. Diagram Text as Paths Only

### 모든 글자를 path로 변환

### 장점

렌더링 일관성.

### 단점

- 검색 불가
- 접근성 저하
- 수정 어려움
- 파일 크기 증가

### 개선

장기 보존과 접근성 요구를 고려해 선택한다.

## R-50. Media Without Checksums
