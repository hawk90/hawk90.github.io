# 28. Analytics Provider 다중화

다음이 동시에 설치될 수 있다.

```text
Google Analytics
Search Console
Cloudflare Analytics
GitHub Pages 통계
Custom events
AdSense metrics
```

각 Script가 성능과 개인정보 부담을 추가한다.

측정 목적을 먼저 정의한다.

```text
검색 유입
상위 문서
내부 다음 글 이동
```

이 세 가지에 필요한 최소 도구만 유지한다.
