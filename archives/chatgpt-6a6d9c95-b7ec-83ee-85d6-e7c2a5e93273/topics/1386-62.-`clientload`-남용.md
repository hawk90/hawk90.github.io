# 62. `client:load` 남용

초기 화면에 즉시 필요하지 않은 컴포넌트까지 `client:load`하면 JavaScript가 한꺼번에 실행된다.

선택:

```text
검색 Dialog → 클릭 후 동적 import
댓글 → client:visible 또는 사용자 요청
이미지 확대 → 필요 페이지에서만
```

정적 카드·목록에는 Client Directive를 사용하지 않는다.
