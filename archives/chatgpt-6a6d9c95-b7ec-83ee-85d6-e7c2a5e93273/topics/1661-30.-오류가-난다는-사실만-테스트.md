# 30. 오류가 난다는 사실만 테스트

```ts
expect(() =>
  createManifest(documents)
).toThrow();
```

만 검사하면 엉뚱한 오류로 실패해도 통과한다.

최소한 Rule ID나 핵심 메시지를 검사한다.

```ts
expect(error.issues).toContainEqual(
  expect.objectContaining({
    ruleId: "content/duplicate-id",
  }),
);
```
