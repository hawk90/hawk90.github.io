# 4. 태그 페이지를 콘텐츠 페이지로 착각

다음 페이지가 색인될 수 있다.

```text
/tag/cpp/
/tag/cuda/
/tag/linux/
/tag/debug/
/tag/study/
```

페이지 내용:

```text
C++ 태그

글 32개

[글 카드]
[글 카드]
[글 카드]
```

이 페이지는 탐색에는 도움을 줄 수 있다.

하지만 고유한 설명이나 큐레이션 없이 목록만 보여준다면 검색 결과 페이지와 큰 차이가 없다.

AdSense 정책은 광고가 표시되는 화면이 단순 탐색이나 행동 목적의 화면이거나 게시자 콘텐츠가 부족한 화면이어서는 안 된다고 안내한다. citeturn517910search1

## 위험한 조합

```text
태그 페이지 색인 허용
+
광고 표시
+
고유 설명 없음
+
글 카드만 존재
```

## 선택지

### 중요한 태그

Topic Hub로 승격한다.

```text
PCIe & CXL
CUDA
Linux Kernel
Firmware
```

고유 설명과 학습 경로를 제공한다.

### 세부 태그

탐색에는 유지하되:

```text
noindex,follow
광고 제외
Sitemap 제외
```

를 고려한다.

### 사용되지 않는 태그

제거하거나 상위 태그에 합친다.
