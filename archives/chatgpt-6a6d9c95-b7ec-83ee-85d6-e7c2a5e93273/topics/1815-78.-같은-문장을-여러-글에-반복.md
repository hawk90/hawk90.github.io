# 78. 같은 문장을 여러 글에 반복

모든 글의 서론과 결론에 다음이 반복될 수 있다.

```text
성능 최적화는 매우 중요합니다.
기본 원리를 이해하는 것이 중요합니다.
실제 환경에 따라 결과가 달라질 수 있습니다.
```

이런 공통 문구가 페이지의 상당 부분을 차지하면 실질적인 고유 콘텐츠 비율이 낮아진다.

## 공통 문구 최소화

```text
Site Header
작성자 소개
긴 Disclaimer
Newsletter
관련 글 설명
```

보다 문서 고유 본문이 중심이 되게 한다.
