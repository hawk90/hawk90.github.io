# 96. 최신 CSS 기능의 Fallback 미검토

다음 기능을 사용할 수 있다.

```text
subgrid
container queries
color-mix()
:has()
```

현재 지원 브라우저 범위에서 적절한지 확인한다.

기술 블로그 독자는 최신 브라우저 비율이 높을 수 있지만, 실제 Analytics 없이 단정하지 않는다.

Fallback이 없어도 콘텐츠 읽기가 가능한 Progressive Enhancement 구조가 이상적이다.
