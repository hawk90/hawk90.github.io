# 35. Tag Migration

기존 태그를 모두 새 Topic으로 변환하지 않는다.

Topic은 사이트 상위 학습 영역이고, Tag는 세부 검색·필터 정보다.

예:

```text
Topic:
pcie-cxl

Tags:
bar
msi-x
dma
u250
```

다음처럼 태그 하나마다 Topic을 만들지 않는다.

```text
BAR Topic
MSI Topic
DMA Topic
U250 Topic
```
