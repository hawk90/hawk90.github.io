# 81. Open Graph URL과 Canonical 차이

OG URL·이미지 URL은 절대 URL이어야 하고 Canonical과 같은 Production Origin을 사용해야 한다.

Preview Build에서는 검색엔진에 노출되지 않도록 `noindex`를 유지한다.

Preview URL을 Social Metadata의 영구 URL로 저장하지 않는다.
