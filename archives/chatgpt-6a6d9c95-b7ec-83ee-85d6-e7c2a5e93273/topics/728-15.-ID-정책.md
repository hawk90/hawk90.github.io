# 15. ID 정책

ID는 URL이나 파일명보다 안정적인 문서 정체성이다.

## 좋은 ID

```text
pcie-bar-sizing
linux-pci-enumeration
cuda-pinned-memory
```

## 피해야 할 ID

```text
post-183
2026-08-01-pcie-bar
src-content-pcie-bar-md
```

날짜와 물리 경로는 바뀔 수 있다.

## ID 불변 원칙

제목이나 URL이 바뀌어도 ID는 유지한다.

```text
ID: pcie-bar-sizing
Old URL: /posts/pcie-bar/
New URL: /articles/pcie-bar-sizing/
```

관계와 큐레이션은 계속 같은 ID를 사용한다.
