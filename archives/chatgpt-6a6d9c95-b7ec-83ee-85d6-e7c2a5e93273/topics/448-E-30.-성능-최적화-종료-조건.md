# E-30. 성능 최적화 종료 조건

최적화가 끝없이 이어지면 안 된다.

이번 Epic은 다음이 충족되면 1차 완료로 본다.

```text
병목 단계가 측정된다
공통 manifest가 존재한다
중복 Markdown 파싱이 줄었다
Shiki 범위가 정리됐다
빌드·감사 명령이 분리됐다
검색·OG·다이어그램이 변경 기반으로 동작한다
CI에서 build가 한 번만 실행된다
Peak RSS와 시간 회귀를 확인할 수 있다
```

Lighthouse 100이나 모든 작업의 완전 증분화는 완료 조건이 아니다.
