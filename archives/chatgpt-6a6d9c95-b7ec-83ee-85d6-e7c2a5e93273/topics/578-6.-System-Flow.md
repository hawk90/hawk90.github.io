# 6. System Flow

이 Hub의 차별점으로, 카드 목록보다 먼저 **전체 시스템 흐름**을 보여준다.

## 섹션 제목

```text
Host에서 장치와 메모리까지
```

## 설명

```text
PCIe와 CXL 문제는 하나의 레지스터나 드라이버 함수만 봐서는 이해하기 어렵습니다. 아래 흐름은 Firmware, 운영체제, Driver와 장치가 어떤 순서로 연결되는지를 보여줍니다.
```

## 권장 흐름도

```text
Firmware
  ├─ Root Complex 초기화
  ├─ Bus·Device·Function 열거
  └─ 주소 공간 할당
            ↓
Linux PCI Core
  ├─ pci_dev 생성
  ├─ Resource 등록
  └─ Driver binding
            ↓
Device Driver
  ├─ BAR mapping
  ├─ MSI-X 설정
  ├─ DMA buffer 준비
  └─ Device initialization
            ↓
PCIe / CXL Device
  ├─ MMIO register
  ├─ DMA engine
  ├─ Device memory
  └─ HDM Decoder
```

초기에는 정적 HTML과 CSS로 구현하고, 무거운 그래프 라이브러리는 사용하지 않는다.
