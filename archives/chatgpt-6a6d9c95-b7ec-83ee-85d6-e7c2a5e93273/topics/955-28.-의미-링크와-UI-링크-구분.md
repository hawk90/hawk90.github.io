# 28. 의미 링크와 UI 링크 구분

모든 `<a>`를 inbound link로 계산하면 다음이 포함된다.

```text
Header
Footer
Archive
Tag
Pagination
Latest Posts
```

이 링크는 지식 관계가 아니다.

따라서 Manifest에서 다음을 구분한다.

```ts
export interface InternalContentLink {
  href: string;
  targetDocumentId?: string;
  semantic: boolean;
}
```

또는 추출 단계에서 본문과 큐레이션 링크만 의미 링크로 본다.
