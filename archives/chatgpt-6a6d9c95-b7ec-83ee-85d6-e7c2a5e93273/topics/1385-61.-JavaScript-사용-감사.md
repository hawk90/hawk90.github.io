# 61. JavaScript 사용 감사

최종 HTML에서 페이지별 Script를 조사한다.

```text
어떤 Script가 로드되는가
압축 크기
어떤 컴포넌트가 원인인가
실제 상호작용이 있는가
```

Astro Island Directive를 검색한다.

```text
client:load
client:idle
client:visible
client:only
```

각 사용에 이유가 있어야 한다.
