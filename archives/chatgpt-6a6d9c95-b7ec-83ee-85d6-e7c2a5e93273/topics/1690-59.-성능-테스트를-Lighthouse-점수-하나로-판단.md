# 59. 성능 테스트를 Lighthouse 점수 하나로 판단

Lighthouse 100을 목표로 하면 실제 사용성과 무관한 미세 최적화에 빠질 수 있다.

성능 계약을 직접 정의한다.

```text
검색을 열기 전 Index 미요청
Article에서 불필요한 Hydration 없음
LCP 후보 이미지 크기 지정
전체 페이지 JS 예산
CLS 제한
```

점수는 참고 지표다.
