# B-22. 대표 문서 상단 UI

대표 글 상단에는 정보가 너무 많아지지 않도록 다음만 우선 표시한다.

```text
Content Type
Primary Topic
Status
Updated
```

환경 정보가 중요한 글은 별도 compact 영역:

```text
Tested on
Linux 6.x
GCC 13
U250 / XRT 2.13
```

모든 글에 같은 환경 필드를 강제하지 않는다.
