# 61. Freshness Policy

Topic·Type별 검토 주기를 둘 수 있다.

```ts
export interface FreshnessPolicy {
  topicId?: string;
  type?: ContentType;
  reviewAfterMonths: number;
}
```

예:

```text
Tool 설치 Guide: 6개월
Source Walkthrough: 12개월
Debug Note: 18개월
Stable Concept: 36개월
```

이는 자동 상태 변경이 아니라 검토 후보 생성에 사용한다.
