# 24. 일치 문맥 생성

검색어와 무관한 첫 문장을 snippet으로 보여주면 도움이 적다.

우선순위:

```text
일치 Heading
>
일치 Alias
>
일치 Symbol
>
일치 Error Message
>
Description
```

본문 전체를 브라우저에 보내지 않으므로 자유로운 문맥 추출은 제한된다.

대신 매칭된 구조화 필드를 표시한다.

예:

```text
일치한 항목: BAR Size Probing
```

이는 길고 불안정한 본문 snippet보다 명확할 수 있다.
