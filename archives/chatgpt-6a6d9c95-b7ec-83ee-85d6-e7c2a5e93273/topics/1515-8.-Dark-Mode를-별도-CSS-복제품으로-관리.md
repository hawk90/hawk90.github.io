# 8. Dark Mode를 별도 CSS 복제품으로 관리

나쁜 구조:

```css
.card { ... }
.article { ... }
.code { ... }

.dark .card { ... }
.dark .article { ... }
.dark .code { ... }
```

Light와 Dark 규칙이 병렬로 커지며 누락이 생긴다.

권장:

```css
:root {
  --surface: ...;
  --text: ...;
}

[data-theme="dark"] {
  --surface: ...;
  --text: ...;
}
```

컴포넌트 구조 CSS는 공통으로 유지하고, 주로 Token만 교체한다.
