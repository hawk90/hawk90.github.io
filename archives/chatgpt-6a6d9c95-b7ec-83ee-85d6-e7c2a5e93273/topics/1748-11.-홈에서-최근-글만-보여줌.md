# 11. 홈에서 최근 글만 보여줌

최근 글 순서는 콘텐츠 품질과 관계가 없다.

최근 게시물이 다음과 같을 수 있다.

```text
짧은 Git 명령
일상 메모
단답형 C++ 질문
오래된 설치 오류
```

방문자와 심사 시스템이 홈에서 처음 보는 콘텐츠가 이것이면 사이트의 강점을 알기 어렵다.

## 권장 순서

```text
대표 전문 영역
대표 문서
Topic
최근 글
```

최근 글은 보조 영역이다.
